# 발표자료 강제 주문서

> **이 문서는 혼자서는 아무것도 못 막는다.** 짝이 되는 두 명령이 본체다.
>
> ```bash
> python -m databook report --asof 2026-09-01   # ① 스캐폴드 — 표·차트·문헌을 자동 배치
> #   … WRITE 슬롯을 채운다 (해석은 사람 몫) …
> python -m databook audit <완성본>              # ② 검사 — 미달이면 exit 1
> ```
>
> **`report`가 없으면 `audit`는 채점표일 뿐이다.** 답안 쓰는 법을 안 주면
> 다음 사람은 또 지표 20개짜리를 낸다. 실제로 2026-08-30에 그랬다.
>
> 규칙을 글로만 써두는 방식은 **이미 두 번 실패했다.** 볼트가 그 실패를
> [[결정과 규칙문서의 표류]]로 기록해 두었고, 2026-08-30에도 같은 일이 났다 —
> 지표 331개 중 **21개만** 쓰고, 그중 **57%가 한 팀**이었고, 4팀은 **0개**였다.
> 작성자가 멈추고 싶을 때 멈출 수 있으면 반드시 거기서 멈춘다.
> 그래서 판정을 성실성이 아니라 **종료 코드**에 건다.

## 0. 제출 조건

`python -m databook audit <파일>`이 **exit 0**을 내야 제출할 수 있다.
하나라도 FAIL이면 그 자료는 미완성이다. 기준을 낮추려면
`databook/audit.py`의 `GATES`를 고치고 **왜 낮췄는지 커밋 메시지에 남긴다.**

| 항목 | 기준 | 왜 이 숫자인가 |
|---|---|---|
| 지표 커버리지 | **40개 이상** | 300개 넘게 수집해 두고 20개로 쓰면 수집이 무의미하다 |
| 팀별 최소 | 1·2·3팀 각 **8개**, 4팀 **3개** | 4팀(글로벌·지정학·무역)이 늘 0개였다 |
| 한 팀 비중 | **45% 이하** | 편한 축 하나만 긁는 것을 막는다 |
| 문헌 | **5편 이상** | 「추세·사례·이론」의 이론 축 |
| 계수·통계량 | **3회 이상** | 논문을 제목만 인용하는 것을 막는다 |
| 그림 | **4개 이상** | 표만 있으면 추세가 전달되지 않는다 |
| 기준일 병기 | **25회 이상** | 지표마다 기준일이 다르다 |
| 기저율 표본 | 방향을 말했으면 **n ≥ 20** | 배열로 방향을 부르는 것을 막는다 |
| 금지문장 | **0건** | [[시황 분석 진입점]] §2 |
| 한계 명시 | 필수 | 미검증·표본한계·못 보는 것 |
| **미작성 슬롯** | **0개** | `WRITE:`가 남으면 스캐폴드지 자료가 아니다 |
| **해석 분량** | **2,500자** | 표·차트·문헌 박스를 뺀 **내가 쓴 문장** |
| **필수 절** | 3종 | Red Team · 무효화 조건 · 다음 세션 |

## 0-1. `report`가 대신 해주는 것

전에는 축별 목록을 손으로 훑어야 했다. 이제 스캐폴드가 **125개 지표를 표로 깔고**
차트 9종을 그리고 축마다 문헌 계수를 박아 넣은 상태로 나온다.
남는 일은 **해석뿐**이다.

```bash
python -m databook report --asof 2026-09-01
#   기준 시점(as-of)  2026-09-01  (직전 세션 자동 / --asof로 고정)
#   지표              331개 중 325개 수집 · 본문 배치 125개
#   차트              9개
#   문헌 계수         16편 (papers.yaml)
#   기저율 표본       n=57
```

**as-of는 기본이 직전 세션(화요일)이다.** 준비를 언제 하든 같은 자료가 나온다.
큰 사건이 as-of 뒤에 있으면 그때만 `--asof`로 옮기고 **보고서 첫 줄에 그 사실을 적는다.**

## 1. 커버리지를 채우는 법 — 축을 훑는 순서

**변경분 목록에서 고르지 않는다.** 그건 "어디를 볼지"이지 "무엇을 쓸지"가 아니다.
아래 순서로 **팀별 전체 목록을 열어** 각 축에서 최소 개수를 채운다.

```bash
python -m databook audit <파일> --unused 60    # 아직 안 쓴 지표를 보여준다
```

### 1팀 · 성장·경기 (최소 8)
수준 → 모멘텀 → 노동 → 심리 순으로 본다.
`실질 GDP` `GDPNow` `산업생산` `소매판매` `설비투자` `주택 착공`
`NFP` `실업률` `v/u 비율` `신규 실업수당` `Sahm Rule` `침체확률`
`미국 TFP` `설비가동률` `재고 사이클` `주간경제지수 WEI`
`유로존 실질GDP` `일본 실질GDP` `일본 단칸` `독일 산업생산`

⚠ **침체확률(Chauvet-Piger)은 퍼센트다** — 0.6은 60%가 아니라 0.6%.
⚠ 실업률 대신 **v/u**를 본다(Bernanke &amp; Blanchard 2023).

### 2팀 · 물가·정책·금리 (최소 8)
근거리와 원거리를 **갈라서** 본다.
`근원 PCE` `절사평균 PCE` `중위 CPI` `CPI 서비스ex에너지` `PPI`
`BEI 10Y` `5y5y` `기대인플레 서베이` `한국 기대인플레이션`
`미 국채 2Y/10Y/30Y` `커브 2s10s` `커브 3m10y` `실질금리` `텀프리미엄`
`한국은행 기준금리` `국고채 3Y/10Y` `CD 91일` `한미 금리차`
`ECB 예금금리` `BOJ 정책금리` `PBOC LPR` `유로존 HICP` `일본 CPI` `중국 CPI`

⚠ **중위·절사평균 CPI는 월간 변화율의 연율**이라 YoY와 같은 표에 놓지 않는다.

### 3팀 · 유동성·신용·심리 (최소 8)
가격(스프레드)과 **수량**(지준·RRP·레포)을 함께 본다.
`EBP` `GZ 신용스프레드` `HY OAS` `IG OAS` `Baa−10Y` `NFCI`
`순유동성` `은행 지준` `RRP 잔고` `TGA` `SOFR−IORB` `EFFR−IORB` `연준 레포 SRF`
`은행 대출태도 SLOOS` `BIS DSR` `credit-to-GDP gap`
`VIX` `VIX 텀스트럭처` `MOVE` `SKEW` `Put/Call` `CNN Fear &amp; Greed`
`엔캐리 잔고` `국채선물 레버리지펀드 숏` `AI 캐펙스 3종`
`외국인 수급` `주식 대차잔고` `원/달러` `DXY`

⚠ **토스 수급만 긁는 것이 이 검사기가 막으려는 바로 그 행태다.**
수급은 3팀의 일부일 뿐이고, 3팀 안에서도 스프레드·수량·변동성을 먼저 본다.

### 4팀 · 글로벌·지정학·무역 (최소 3)
가장 자주 빠지는 축이다.
`GPR 지정학위험지수` `GSCPI 공급망압력` `해운 운임` `유가 WTI/Brent`
`천연가스` `EU 천연가스` `미 원유재고·생산` `농산물`
`중국 무역 총액` `중국 원자재 수입` `일본 무역수지` `미 관세 수입`
`니치 원자재 ETF` `중국 외환보유액`

## 2. 문헌을 쓰는 법 — 제목이 아니라 계수

**금지**: "GZ(2012)에 따르면 신용스프레드가 중요하다."
**필수**: 계수·표본·크기를 그대로 옮기고, **이 자료의 숫자에 적용**한다.

> EBP **+100bp**는 4분기 실질GDP를 **−1.5%p 이상** 낮춘다(기대부도 성분은 −0.5%p, **3배 차이**).
> 현재 EBP **−0.319%p** → 약 **+0.48%p 순풍**.
> — Gilchrist & Zakrajšek(2012), NBER WP 17021 / AER 102(4), 표2

축마다 붙일 문헌은 [[제텔 소환 인덱스]] §2에 있다. 자주 쓰는 것:

| 축 | 문헌 | 무엇을 준다 |
|---|---|---|
| 신용 | Gilchrist &amp; Zakrajšek(2012) | EBP → GDP 계수, 예측성분과의 3배 차이 |
| 신용 | 자체 재현(2026-07) | VIX 1%↑ → Baa +1.7bp (α₁=1.6705, R²=0.693) |
| 커브 | 김석진(2024) | 물가는 10년물, 실물은 1~5년물 |
| 한국 정책 | 주현도(2024) | 반응함수 비대칭 — 물가 상회 시 물가만 본다 |
| 한국 정책 | 표상원(2016) | 인상은 환율 제약 + 생산 바닥 통과 |
| 기대 | 이명수(2023) | 기대→CPI 미국 F=10.80 유의 / 한국 F=0.58 기각 |
| 유동성 | 송종운(2019) | 지준 공급>수요면 전통 OMO가 멈춘다 |
| 물가지표 | Ball &amp; Mankiw(1995) | 코어는 열등, 중위·절사평균이 낫다 |
| 노동 | Bernanke &amp; Blanchard(2023) | 실업률이 아니라 v/u |

**계수를 다른 나라·다른 방향으로 옮길 때는 그 사실을 적는다.**
이명수(2023)가 한국에서 기각한 고리를 미국 논리로 쓰면 안 되고, 그 반대도 안 된다.

## 3. 그림을 만드는 법

`databook/charts.py`가 다섯 종류를 만든다. 외부 라이브러리 없이 인라인 SVG다.

| 함수 | 언제 |
|---|---|
| `line()` | 시계열. 임계 구간은 `bands=`로 음영 |
| `diverging()` | 창별 변화. **부호가 갈리는 것**을 보일 때 |
| `percentile()` | 수준이 아니라 위치 |
| `dotplot()` | 기저율 분포. 중앙값·0선 자동 |
| `mirror()` | 방향이 반대인 두 계열(외국인 vs 개인) |

**표에 있는 값으로만 그린다.** 없는 데이터는 그리지 말고 그 사실을 쓴다.

## 4. 자주 나는 사고

| 사고 | 원인 | 막는 법 |
|---|---|---|
| 지표 20개로 "분석" | 서사가 성립하면 멈춘다 | `audit` 커버리지 게이트 |
| 한 축만 긁기 | 익숙한 데이터부터 손이 간다 | `audit` 편식 게이트 |
| 논문 제목만 인용 | 계수를 찾는 게 귀찮다 | `audit` 계수 게이트 |
| 표만 있고 그림 없음 | 그림이 손이 많이 간다 | `audit` 그림 게이트 |
| 배열로 방향 부르기 | 기저율을 안 센다 | `audit` 기저율 게이트 |
| **부분 수집이 전체를 덮어씀** | `run --only X --render-anyway` | `audit`이 깨진 스냅샷을 건너뛴다 |
| 죽은 코드 지우다 상수까지 삭제 | 그 코드만 쓰던 상수인지 확인 안 함 | 정리 후 **전체 수집 1회** |

## 5. 붙여넣는 주문서

```text
아래 순서를 그대로 지켜 이번 세션 발표자료를 만든다.
중간에 "충분하다"고 판단하지 마라 — 판단은 마지막 검사기가 한다.

【1】 자료 — 스캐폴드부터 만든다
    cd ~/macro-databook-team
    python -m databook report --asof <세션일>     # 표·차트·문헌이 이미 채워져 나온다
    python -m databook weekly                     # 변경분·기사·손댈 자리
    출력의 §1 DataBook 경로를 열어 **팀별 지표 목록 전체**를 훑는다.
    §2 변경분은 "어디를 볼지"일 뿐 여기서 고르지 않는다.

【2】 규칙
    03_MOC/좋은 시황의 규칙 · 시황 분석 진입점 §1·§2 · 제텔 소환 인덱스 §1
    05_Regime/ 최신 RegimeView · 지난주 노트

【3】 커버리지 — 팀별 최소를 반드시 채운다
    1팀 성장·경기 8개 / 2팀 물가·정책·금리 8개 /
    3팀 유동성·신용·심리 8개 / 4팀 글로벌·지정학·무역 3개
    한 팀이 전체 인용의 45%를 넘지 않게 한다.

【4】 문헌 — 5편 이상, **계수를 이 자료의 숫자에 적용**해서
    "논문이 이렇게 말했다"로 끝내지 마라. 계수 × 현재값 = 크기를 내라.

【5】 그림 — 4개 이상, databook/charts.py로. 표에 있는 값으로만.

【6】 주장 규칙
    근거는 추세·사례·이론 중 최소 둘. 셋 다 없으면 "관측"으로 강등.
    방향을 말하려면 기저율을 먼저 세라(n ≥ 20). 못 셌으면 방향을 말하지 마라.
    모든 수치에 기준일. 확신도(상/중/하). 모르면 "관측 없음".

【7】 마지막
    Red Team 2개 · 무효화 조건(숫자) · 다음 세션에 볼 것 3개

【8】 검사 — 통과할 때까지 제출하지 않는다
    python -m databook audit <만든 파일>
    슬롯이 하나라도 남아 있으면 실패한다. Red Team·무효화 조건·다음 세션이 없어도 실패한다.
    FAIL이 하나라도 있으면 그 항목을 채워서 다시 만든다.
    `--unused 60` 으로 아직 안 쓴 지표를 확인할 수 있다.

【형식】
    발표자료다. 방법론·자기검사·신선도표를 본문에 넣지 마라.
    한계는 맨 끝 부록에만. 결론 H1 한 줄 먼저.
```
