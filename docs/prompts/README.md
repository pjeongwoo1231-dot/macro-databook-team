# 발표자료를 만드는 법

여기 세 문서는 **볼트(`MacroVault/_System/Prompts/`)의 사본**이다.
원본은 Obsidian Sync로 팀원에게 가지만, 볼트 초대를 아직 못 받은 사람도
저장소만으로 시작할 수 있게 여기에 둔다.

> ⚠ **원본이 바뀌면 여기도 같이 고친다.** 두 벌이 갈라지면 둘 다 무시된다 —
> 이 볼트가 「결정과 규칙문서의 표류」로 이미 두 번 기록한 실패다.

## 순서

```bash
# ① 스캐폴드 — 표·차트·문헌이 이미 채워진 상태로 나온다
python -m databook report --asof 2026-09-01

# ② 해석을 쓴다 (WRITE 슬롯을 채운다)
#    무엇을 어떻게 쓸지는 「발표자료 강제 주문서」에 있다

# ③ 검사 — 19개 게이트. 미달이면 exit 1이라 낼 수 없다
python -m databook audit <만든 파일>
```

| 문서 | 언제 |
|---|---|
| **발표자료 강제 주문서** | 세션 자료를 만들 때. 게이트 기준과 축별 지표 목록이 여기 있다 |
| 시황 요청 프롬프트 (팀원용) | 일간 시황·과외 모드·저장 절차 |
| 시황 HTML 디자인 요청서 | 다 쓴 분석을 남에게 조판시킬 때 |

## 게이트 19종이 막는 것

내용 16종 + 형식 3종이다. 각각 **실제로 저지른 사고**에서 나왔다.

| 게이트 | 어떤 사고에서 나왔나 |
|---|---|
| 지표 커버리지 40개 · 팀별 최소 · 편식 45% | 331개 중 21개만 쓰고, 그중 57%가 한 팀, 4팀은 0개였다 |
| 문헌 5편 · 계수 3회 | 논문을 제목만 인용했다 |
| 그림 4개 | 표만 늘어놓았다 |
| 기저율 n≥20 | 배열로 방향을 불렀다 |
| 금지문장 0건 | 볼트가 반박해둔 문장을 그대로 썼다 |
| 미작성 슬롯 0 · 해석 분량 · 필수 절 | 스캐폴드가 프로즈 없이 통과했다 |
| 투자자 함의 · 과거 사례 | 함의가 방향 전망이거나 사례가 날짜 나열뿐이었다 |
| **HTML 구조** | 내용 18종을 다 통과한 자료가 `<div>` 하나 때문에 **열리지 않았다** |

기준을 낮추려면 `databook/audit.py`의 `GATES`를 고치고
**왜 낮췄는지 커밋 메시지에 남긴다.**

## 예시

`examples/주간매크로_2026-09-01.html` — 게이트 19종을 통과한 실제 자료.
지표 71개 · 4팀 전부 · 문헌 13편 · 그림 11개 · 조건부 함의 3개 · 과거 사례 10건.
브라우저로 바로 열린다(완전 자립, 외부 요청은 글꼴뿐).
