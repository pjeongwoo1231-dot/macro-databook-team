# 수집 결측 메우기 — **규칙은 있는데 계열이 없던 것들**

> [[문헌 연결 감사 (판정 경로)]]로 판정 규칙 79개를 전부 §1에 걸어 놓고 나니
> 다음 병목이 드러났다 — **규칙이 요구하는 계열을 수집하지 않고 있다.**
> 볼트가 스스로 *"못 보는 것"* · *"계열이 없다"* · *"수집기 후보"* 로 적어둔 곳을
> **전수로 긁어(44건)** 실제로 받아올 수 있는지 하나씩 호출해봤다.

## 1. 메운 것 (5건) — 전부 무료·키 불필요 또는 기존 키

| 신규 계열 | 출처 | 어느 규칙이 요구했나 |
|---|---|---|
| **미 관세 수입(월별)** | 재무부 MTS 표9 (`fiscaldata`, **키 불필요**) | [[무역분쟁·관세]] *"볼트에 계열이 없다 → 수집기 후보"* |
| **잠재GDP·산출갭** | FRED `GDPPOT`+`GDPC1` | [[잠재성장률]]·[[산출갭]] *"Data Book 미수집"* |
| **설비가동률** | FRED `TCU` | [[설비가동률]] *"status: proposed · 미수집"* |
| **자연실업률** | FRED `NROU` | [[실업률]] 실업갭 계산 |
| **기대인플레 모형추정** | FRED `EXPINF10YR` (클리블랜드 연준) | [[BEI (기대인플레이션)]] *"유동성 프리미엄 과다"* |

**파생 핸들러 1건도 복구했다** — **v/u 비율**(구인÷실업자).
원계열 `JTSJOL`·`UNEMPLOY`를 **진작 둘 다 수집하고 있었는데 계산기가 없어** 매 실행 실패로 남아 있었다.
[[실업률로는 노동시장 과열이 보이지 않는다 — v_u를 봐야 한다]]가 요구하던 바로 그 지표다.

수집 실패 **15건 → 3건**, 지표 **271개**.

### 새로 계산되는 값 (2026-08-21)

| 값 | 결과 |
|---|---|
| **산출갭** | **+0.29%** (실질GDP 24,271 / 잠재 24,200, 2026Q2) |
| **실업갭** | **−0.29%p** (실업률 4.1 − 자연실업률 4.39) |
| **v/u 비율** | **1.064** (구인 7,359천 ÷ 실업 6,916천) |
| 설비가동률 | 76.29 (2026-07) |
| 기대인플레(모형) | 2.49% vs 시장 BEI 2.24% — **모형이 0.25%p 높다** |

## 2. 관세 계열에서 바로 나온 발견

**회계연도 누계가 줄고 있다.**

| 기준월 | 당월(억달러) | FYTD(억달러) | 전년 FYTD |
|---|---:|---:|---:|
| 2026-04 | +221 | 1,886 | 592 |
| 2026-05 | −0 | 1,886 | 814 |
| 2026-06 | **−256** | 1,630 | 1,080 |
| 2026-07 | **−85** | **1,545** | 1,357 |

**누계가 1,886억 → 1,545억으로 감소했다.** 누계는 원래 줄지 않는다 —
**대규모 환급(refund)이 일어났다는 뜻**이다.

> [!warning] 부호 규약을 먼저 확인할 것
> 필드가 `rcpt_outly`(수입/지출 겸용)라 **환급이 크면 당월이 음수**가 된다.
> **당월값만 보고 "관세가 줄었다"로 쓰지 말 것** — 누계·전년 동기와 함께 읽는다.
> 그리고 이 계열은 **징수액이지 관세율이 아니다.** 수입물량이 줄어도 같이 준다.

이 관측은 볼트가 이미 큐에 담아둔 두 문헌과 직접 맞물린다 —
Liberty Street **「More Tariff Pass-Through Is in the Pipeline」** 과
**「Who Is Paying for the 2025 U.S. Tariffs?」**. **본문 판독 우선순위를 올린다.**

## 3. 고친 버그 — CBO 계열이 미래를 최신값으로 보여줬다

`GDPPOT`·`NROU`는 **CBO 전망이라 미래 구간까지 값이 있다.**
FRED 수집기가 최신순 `limit`으로 받다 보니 **2036년 전망치만 담겨 왔다.**

`observation_end=오늘`을 붙여 API 단에서 자르도록 고쳤다.
→ 최신값이 2036-10 → **2026-07**로 정정됐다.

**이건 신규 계열만의 문제가 아니다.** 앞으로 전망치를 포함한 어떤 FRED 계열을 붙여도
같은 함정에 빠지지 않는다.

## 4. 메우지 못한 것 — **왜 못 하는지 기록한다**

| 결측 | 요구한 노드 | 왜 못 메우나 |
|---|---|---|
| **TC-RC 스팟** | [[제련수수료 (TC-RC)]] | Fastmarkets·SMM **유료**. ICSG 공개 페이지는 404, 중국 해관은 412 차단 |
| **ISM PMI 수치** | [[PMI (구매관리자지수)]] | **유료 라이선스**. 지역 연준 서베이 합성이 대안이나 재척도 계수 미검증 |
| **FR 2420 참가자 구성** | [[글로벌 유동성]] | **비공개** — 연구 목적 접근 자료 |
| **FX 스왑베이시스·CRS** | [[원·달러 환율]] | 공개 시계열 없음. 유료 단말 필요 |
| **사모신용 직접 계열** | [[신용사이클]] | BIZD/HYG **프록시로 대체 중**. 직접 계열은 유료(Cliffwater 등) |
| **AI 자본지출 직접 계열** | [[AI 자본지출]] | 기업 공시 집계 필요 — 자동 수집 경로 없음 |
| **ETH 현물 ETF 순유입** | 크립토 축 | Farside가 HTML만 제공 — 스크랩 가능하나 **미구현**(다음 후보) |
| **전력사용량(산업경기)** | [[산업생산]] | 한국전력 통계 별도. FRED `IPUTIL`은 **미국 유틸리티 생산**이라 대용이 다르다 |

> **"메우지 못했다"도 판정이다.** 다음에 같은 질문이 올 때 다시 찾아 헤매지 않도록
> **어디까지 시도했고 무엇에 막혔는지**를 남긴다.

## 5. 남은 실패 3건

| 지표 | 원인 | 조치 |
|---|---|---|
| 일본 국채 (JGB) | `mof_jgb` 소스 미구현 | 수집기 작성 필요 |
| ICI 펀드+ETF 순유입 | HTTP 403 | UA·경로 변경 확인 |
| 글로벌 공급망압력지수 GSCPI | 파싱 실패(포맷 변경) | NY연준 파일 형식 재확인 |

## 6. 2차 — 실패 3건 중 2건 수리 + 1건 신설 (같은 날 오후)

### ① GSCPI 복구 — **시트가 둘로 쪼개졌다**

원인은 포맷이 아니라 **시트 구성 변경**이었다. 2026-08 개편으로 1번 시트가
안내문(`GSCPI Overview`)이 되고 데이터가 `GSCPI Monthly Data`로 옮겨갔는데,
수집기가 **`sheet_by_index(0)`을 고정으로 읽고** 있었다.

설정에 시트 이름을 두고, 없으면 **데이터가 가장 많은 시트**를 고르도록 고쳤다 —
다음에 시트가 또 늘어나도 조용히 실패하지 않는다.
→ 최신값 **2026-07 GSCPI 0.805**(6월 1.185에서 하락)

### ② JGB 수집기 신설 — **매핑이 없는 함수를 가리키고 있었다**

`mof_jgb`가 `intl.fetch_mof_jgb`로 매핑돼 있었는데 **그 함수가 존재하지 않았다.**
`databook/fetchers/japan.py`를 새로 만들었다.

| 함정 | 처리 |
|---|---|
| 인코딩이 **Shift-JIS** | UTF-8로 읽으면 깨진다 — 명시적으로 디코드 |
| 날짜가 **일본 연호** (`R8.8.20`) | 레이와=2018+년, 헤이세이=1988+년으로 환산 |
| 휴장일 빈 칸 | **건너뛴다** — 0으로 채우지 않는다 |
| yaml은 `2Y`, MOF는 `2年` | 양쪽 표기 모두 수용 |

실측 2026-08-20: **2Y 1.682 · 10Y 2.854 · 30Y 3.995**,
커브 **10Y−2Y +1.172%p · 30Y−10Y +1.141%p**.
[[일본 국채 (JGB)]] 규칙 *"커브가 이미 반영한 것을 먼저 뺀다"* 를 이제 실제로 적용할 수 있다.

### ③ ETH 현물 ETF 신설 — 비대칭 해소

farside 수집기가 **BTC 전용 하드코딩**이었다. 자산별로 일반화해 ETH를 붙였다.
실측 2026-08-20: BTC **+606.3** · ETH **+219.5**($mn).

> ⚠ **두 계열을 합쳐 "크립토 ETF 유입"으로 쓰지 말 것** —
> 투자자 구성과 도입 시기가 다르다. 표의 **마지막 열이 Total**이라는 가정에도 기대고 있다.

### 결과

수집 실패 **15건 → 3건 → 2건**(EIA 429는 일시적 rate limit), 지표 **272개**.

## 7. ICI는 포기한다 — **간헐적 봇 차단**

| 시도 | 결과 |
|---|---|
| 브라우저 UA | 403 |
| `macro-databook/0.1` | **처음엔 200**, 수 초 뒤 같은 요청이 **403** |
| 파일 직접 경로 | 403 또는 404 |

UA 규칙이 아니라 **요청 빈도·핑거프린트 기반 차단**으로 보인다.
우회를 시도할 수는 있으나 **안정적으로 유지되지 않을 수집기를 만드는 것이 더 나쁘다.**
[[데이터북 인용 주의 목록]]에 **"펀드 흐름은 ICI로 못 본다"** 로 남기고,
대체가 필요하면 **EPFR(유료)** 또는 FRED의 뮤추얼펀드 계열을 검토한다.
