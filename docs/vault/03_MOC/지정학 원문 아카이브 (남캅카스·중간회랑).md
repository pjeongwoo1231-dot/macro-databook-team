# 지정학 원문 아카이브 — **제목이 아니라 본문을 받았다**

> **왜 만들었나.** 지정학 축은 계열이 **뉴스 헤드라인과 GPR 지수뿐**이었다.
> 피드를 붙여도 제목만 오면 볼트 규약상(“본문 판독 없이 승격 금지”) 아무것도 못 한다.
