# 매크로 분석 레이어 설계

> 원 논의 문서는 **수집 위에 얹는 분석·활용 레이어**로 프로젝트 가치를 정의했다.
> 이 노트는 그 계획에 **vault가 이미 가진 증거**를 붙인 것이다.
> 핵심 메시지 하나 — **회귀로 새로 추정하기 전에, 이미 추정된 것들이 무엇을 말하는지부터 볼 것.**

## 0. 먼저 짚을 것 — 스코프 근거에 반증이 있다

원 문서는 매크로 이벤트로 스코프를 좁힌 근거로
**"코스피 외국인 보유비중 40.24%(2026.7, 사상 최고) → 외국인 비중 높은 업종이 지수를 주도"** 를 든다.

**이 vault는 그 인과에 반대되는 증거를 갖고 있다** →
[[외국인이 주가를 이끄는 게 아니라 주가가 외국인을 끈다]]

- **보유비중이 높다**는 것은 **노출(exposure)** 이지 **인과(causation)** 가 아니다
- [[2010 국제투자심리지표간의 연관성 분석 (이상원)]] — 분산분해 기준 VKOSPI 변화의 **약 25%만** 해외 지수 합계로 설명되고, **VIX 단독은 10% 안팎**
- [[2016 미국 기준금리 인상이 국내경제에 미치는 영향 - FAVAR (표상원)]] — 미 금리 인상 시 코스피 하락을 예측했으나 **2016~2017년 실제로는 상승**(사후 채점)

**그래도 스코프 결정 자체는 유지할 만하다.** 다만 근거를 바꾸는 게 정직하다 —
"외국인이 지수를 이끌기 때문"이 아니라 **"국내 이벤트(DART 분기 1회)보다 관측치가 많고 시점이 명확하기 때문"** 이다.
이건 ③ 회귀 툴의 **표본 부족 문제**와도 직결된다.

## 1. 데이터 소스 — 파서는 마크다운이 아니라 JSON을 읽어야 한다

원 문서의 다음 액션 1번(**frontmatter 구조 확인 후 파서 설계**)에 대한 답이다.

### 결론 : `04_DataBook/snapshots/snapshot_YYYY-MM-DD.json` 을 파싱하라

마크다운 표는 사람이 읽는 산출물이라 셀 안에 `<br>`·위키링크·뉴스 헤드라인이 섞여 있다.
**같은 실행이 구조화된 JSON을 같이 뱉는다.** 파서는 이쪽을 쓴다.

```json
{
  "generated_at_utc": "2026-08-05T01:57:27Z",
  "indicator_count": 200,
  "indicators": [
    {
      "name": "HY 스프레드 (OAS)",
      "team": "team_3",
      "tier": 1,
      "method": "api",
      "source": "fred",
      "status": "ok",
      "observations": [
        {"date": "2026-08-03", "value": 2.78, "label": "BAMLH0A0HYM2"},
        {"date": "2026-07-31", "value": 2.85, "label": "BAMLH0A0HYM2"}
      ],
      "unit": "",
      "source_url": "https://fred.stlouisfed.org/series/BAMLH0A0HYM2",
      "error": "",
      "note": ""
    }
  ]
}
```

**파서가 알아야 할 것**

| 항목 | 내용 |
|---|---|
| 식별자 | `name`은 한글 표시명. **조인 키로는 `observations[].label`(=시리즈 ID)을 쓸 것** |
| 관측치 | `observations`는 **최신 6개만** 담긴다. 장기 시계열은 여기 없다 — 백테스트용 히스토리는 **FRED API를 따로 호출**해야 한다 |
| 결측 | `status != "ok"`인 항목이 존재한다(2026-08-05 기준 `fail` 1 · `manual` 2). `error` 필드 확인 필수 |
| 장기 시계열 | 스냅샷에는 없다. `output/history/{SERIES_ID}.csv`(date,value) + `_manifest.json`을 별도로 읽을 것 |
| 다계열 항목 | 한 지표가 여러 계열을 가질 수 있다(`label`로 구분). 예: 은행 예금·대출 = `DPSACBW027SBOG` + `TOTLL` |
| 비수치 항목 | `method: news`인 항목은 값이 아니라 **헤드라인 텍스트**다. 수치 파이프라인에서 걸러낼 것 |
| 파생 항목 | `method: derived`는 원계열이 아니라 계산값(예: 순유동성, 김치프리미엄) |

**팀 노트 frontmatter**(마크다운 쪽을 굳이 읽을 경우)

```yaml
date: 2026-08-05
type: databook          # 인덱스 노트는 databook-index
team: 3
team_name: 유동성·신용·심리 (Liquidity·Credit·Sentiment)
collected_utc: 2026-08-05T01:57:27Z
indicators_ok: 61
indicators_total: 63
tags: [macro/databook]
```

**지표 노트 쪽 조인 고리**(`01_Indicators/`)

```yaml
status: linked          # linked(계열 확정) / unlinked(코드 미확인) / mapped(개념 노드)
series_id: [BAMLH0A0HYM2, BAMLC0A0CM]
data_source: fred
```

→ **`series_id` 하나로 세 층이 이어진다** : `indicators.yaml` 정의 ↔ 스냅샷 JSON ↔ 지표 노트의 해석·판정 규칙.

⚠ **주의** : `04_DataBook/`은 파이프라인이 덮어쓰는 영역이다. 분석 스크립트의 산출물을 여기 쓰지 말 것.
그리고 **`--dry-run`도 파일을 쓴다** — 수집 직후 dry-run을 돌리면 실데이터가 빈 파일로 덮인다(2026-08-05 실제 발생).

## 1-b. 장기 시계열 — 2026-08-05 구축 완료

`python -m databook history` 로 **FRED 계열 95개 · 21만 행**을 CSV로 축적했다.

| 항목 | 내용 |
|---|---|
| 경로 | `deploy_macro-databook/output/history/{SERIES_ID}.csv` (`date,value`) |
| 목록 | 같은 폴더의 `_manifest.json` — 계열별 name·team·tier·rows·start·end |
| 기본 구간 | 2000-01-01 ~ (일별 계열은 6,600여 행) |
| 갱신 | 재실행 시 마지막 날짜 **400일 전부터 이어받아 개정값을 덮어쓴다** |
| 위치 | Obsidian에 쓰지 않는다. 분석 스크립트용 데이터이고 `output/`은 gitignore다 |

**2026-08-05 확장** — `history`가 FRED만 받던 것을 **Yahoo 심볼까지** 받도록 고쳤다.
이제 한국 가격 시계열이 1급 데이터로 저장된다.

| 계열 | 구간 | 행 |
|---|---|---|
| `KS11` 코스피 | 2000-01-04 ~ | 6,547 |
| `KQ11` 코스닥 | 2000-10-16 ~ | 6,358 |
| `HG_F` 구리 · `GC_F` 금 · `ES_F` S&P선물 · `ZN_F` 국채선물 | 2000-08~ | 각 6,500 내외 |

**왜 필요했나**: 그전까지 코스피 히스토리는 `events` 모듈이 매번 새로 받아 쓰고 버렸다.
**백테스트를 하려면 한국 가격 데이터가 미국 계열과 같은 자리에 저장돼 있어야 한다.**
(OHLC 분해가 필요하면 여전히 `events`를 쓴다 — `history`는 종가만 담는다.)

### ⚠ 백테스트 구간을 실제로 제약하는 것들 (수집해 보고 알게 된 사실)

**① ICE BofA 신용스프레드는 3년치뿐이다**
`BAMLH0A0HYM2`(HY)·`BAMLC0A0CM`(IG)은 FRED API가 **2023-08-07부터만** 준다.
FRED 시리즈 메타 자체가 그렇게 잡혀 있어(`observation_start: 2023-08-07`) 우회가 불가능하다 — **ICE 라이선스 제약**이다.
→ [[2023 글로벌 회사채 신용위험에 대한 시장지표의 선행성 (최재용)]]의 표본(2008.5~2020.12)을 **재현할 수 없다.**

**대응**: `indicators.yaml`에 **Moody's 기반 장기 대용**을 추가했다(2026-08-05).

```yaml
- name: 신용스프레드 장기 대용 (Moody's Baa−10Y)
  series_id: ['BAA10Y', 'AAA10Y']   # 1986-01-02 ~ , 각 10,146행
```

Baa−10Y는 **IG 하단의 신용위험**이고 HY OAS와 등급대가 다르다. **같은 지표가 아니다** —
겹치는 2023-08 이후 구간에서 상관을 확인한 뒤 대용 여부를 판단할 것.

**② OECD 경기선행지수(CLI)가 2024-01에서 멈췄다**
`USALOLITONOSTSAM`·`KORLOLITONOSTSAM`·`CHNLOLITONOSTSAM` 모두 최신값이 **2024-01-01**이다.
[[경기선행지수 (CLI)]]를 현재 국면 판단에 쓸 수 없다는 뜻이다. 대체 계열 검토 필요.

**③ 그 밖의 짧은 계열**
`SOFR`(2018~) · `IORB`(2021~) · `GDPNOW`(2011~, 61행뿐) · `PPIFIS`(2009~) ·
`DTWEXBGS`(2006~) · `DFEDTARU`(2008-12~, 제로금리 도입 시점부터).
**2008년 이전을 포함하는 회귀에는 이 계열들을 넣을 수 없다.**

**④ 갱신이 느린 계열**: 영국 CPI(~2025-03) · 중국 CPI(~2025-04) · 카드 연체율·일본 GDP(~2026-01).

> 이 목록은 원 문서 3장의 **표본 부족 리스크가 이론이 아니라 실제**임을 보여준다.
> "기간을 5~10년으로 확대"가 **계열에 따라 불가능**하다.

## 1-c. 이벤트 캘린더 — 2026-08-05 구축 완료

`python -m databook events --since 2005-01-01`

**발표일은 추정하지 않는다.** FRED 릴리스 일정 API에서 BLS/BEA의 **실제 발표일**을 받는다.

| 이벤트 | 코드 | 건수(2005~) |
|---|---|---|
| 소비자물가 | CPI | 276 |
| 고용상황 | NFP | 263 |
| GDP | GDP | 288 |
| 개인소득·지출(PCE) | PCE | 264 |
| 생산자물가 | PPI | 274 |
| 소매판매 | RETAIL | 275 |
| 산업생산 | INDPRO | 276 |
| 구인·이직 | JOLTS | 191 |

**산출물** (`output/events/`)
- `calendar.csv` — 발표일 · 코드 · **반응일**
- `KS11_returns.csv` — 갭 / 장중 / 종가-종가 로그수익률 + `suspect` 플래그
- `event_panel.csv` — 회귀용 wide 패널. 거래일 5,319일 중 **이벤트가 붙은 날 1,742일**

**반응일 정의** : 발표일 **다음** 한국 거래일. 미국 발표는 한국시간 밤이라 당일 종가에 반영될 수 없다 → look-ahead 방지.

### 갭/장중 분해가 실제로 작동한다 — 예비 확인 (2026-08-05)

표준편차(%), 2005~2026 코스피:

| 구분 | 갭 | 장중 | 종가-종가 |
|---|---|---|---|
| **이벤트 없는 날** | **0.860** | 1.064 | 1.360 |
| **이벤트 있는 날** | **0.927** | 1.085 | 1.458 |
| PPI | **1.181** | 0.985 | 1.582 |
| NFP | **1.005** | 1.160 | 1.710 |
| RETAIL | 1.012 | 1.089 | 1.548 |
| CPI | 0.975 | 1.015 | 1.425 |
| **GDP** | **0.780** | **1.310** | 1.577 |

**읽는 법**
- 미국 발표가 있는 날 **갭 변동성이 커진다**(0.860 → 0.927). 예측대로 **밤 사이 정보가 시가에 실린다**
- **PPI·NFP·소매판매·CPI가 갭을 크게 만든다** — 서프라이즈가 큰 지표들
- **GDP는 정반대다** — 갭이 오히려 전체 평균보다 **작고**(0.780) 장중이 크다(1.310).
  GDP는 이미 월별 지표로 대부분 예고돼 있어 **발표 자체의 뉴스 가치가 낮다**는 해석과 맞는다

⚠ **이건 상관이지 인과가 아니다.** 유의성 검정을 하지 않았고, 발표일이 특정 요일·월초에 몰리는 효과가 섞여 있다.
정식 회귀에서 요일·월 더미를 통제해야 한다. 다만 **분해 설계가 옳다는 것은 확인됐다.**

⚠ `suspect=1`인 날 3건(2024-09-12, 2026-06-29, 2026-08-04)은 일중 변동폭이 0이다 — Yahoo 데이터 결손으로 보인다. **회귀에서 제외할 것.**

## 1-d. 실적발표 캘린더 — 2026-08-05 구축

`python -m databook earnings`

**바스켓 정의** (2026년 기준, 근거는 Forbes/Fast Company 보도)
- **MANGOS** = Meta · Anthropic · Nvidia · Google · OpenAI · SpaceX — AI 스택 중심. Apple·MS·Amazon·Tesla를 뺀다
- **Fab 10** (Vanda Research, "Frontier AI & Big Tech 10") = Magnificent 7 + SpaceX + OpenAI + Anthropic

**산출물** (`output/earnings/`)
- `surprise.csv` — 최근 4분기 EPS · 컨센서스 · **서프라이즈%**
- `upcoming.csv` — 향후 일정
- `earnings_reaction.csv` — 발표일 → **다음 한국 거래일**의 코스피 갭/장중/종가 수익률

**다음 이벤트**: **2026-08-26 NVDA (장 마감 후)** — 한국은 8월 27일 갭으로 받는다.

### ⚠ 이 데이터로 하면 안 되는 것

**① 비상장이 바스켓의 3분의 1이다**
MANGOS 6곳 중 **Anthropic·OpenAI는 비상장**이라 실적발표가 없다. `SPCX`는 2026-06 상장이라 이력이 없다.
→ **MANGOS를 지표로 쓰면 실제로는 META·NVDA·GOOGL 3종목만 보는 것**이다. 이름값과 관측 범위가 다르다.

**② 과거가 4분기치뿐이다**
Nasdaq API는 최근 4분기만 준다. **이벤트 스터디의 표본이 종목당 4개**다.
원 문서 3장의 표본 부족 리스크가 여기서 가장 심하다 — 유의성을 논할 수 있는 수준이 아니다.

**③ 같은 날 여러 종목이 발표한다 — 관측치가 독립이 아니다**
2025-10-29에 GOOGL·META·MSFT가 함께 발표했고, 셋 다 반응일이 2025-10-30으로 같아
**코스피 수익률 행이 그대로 3번 복제**된다. 회귀에서 독립 관측치로 넣으면 **표준오차가 과소추정**된다.
→ 처방: 반응일 기준으로 **집계**(가중평균 서프라이즈)하거나, **클러스터 표준오차**를 쓸 것.

## 1-e. 원천 스프레드시트 지표 — GSCPI · 한국 EPU

FRED에 없거나 FRED판이 끊긴 계열을 원천에서 직접 받는 fetcher(`spreadsheet.py`)를 추가했다.

| 지표 | 구간 | 상태 |
|---|---|---|
| **GSCPI** (NY연은 공급망압력) | 1998-01 ~ **2026-06** | 정상. [[글로벌 공급망]] 노트가 요구하던 표준 지표 |
| **한국 EPU** (policyuncertainty.com) | 1990-01 ~ **2021-01** | ⚠ **67개월째 갱신 없음** |

**구현 메모**
- GSCPI는 확장자가 `.xlsx`인데 실제로는 **구형 .xls(OLE2)** 다. xlrd로 읽는다
- policyuncertainty.com은 진짜 xlsx라 **의존성 없는 자체 리더**(`fetchers/xlsx.py`)를 만들어 읽는다.
  배포 도구라 `pip install` 목록을 늘리지 않는 편이 낫다
- fetcher에 **6개월 이상 갱신이 없으면 경고를 자동으로 붙이는 로직**을 넣었다.
  한국 EPU가 죽어 있다는 걸 이 장치가 잡았다

**FRED에서 추가로 확보한 불확실성 계열** (`history`로 1985년부터 15,190행)
- `USEPUINDXD` 미국 EPU 일별 · `EPUMONETARY` 미 통화정책 불확실성 · `WLEMUINDXD` 주식시장 관련 불확실성

→ [[2026 한국의 주요 환율 변동성과 글로벌 불확실성 (이은희)]] 재현이 가능해졌다.

## 1-l. 서프라이즈 회귀 — 2026-08-05. **방향은 잡혔고, 경로가 드러났다**

`python -m databook surprise` — 원 문서 리스크 ④(무료 컨센서스 없음)의 우회.

**설계**: 발표일의 **미 2년물 금리 변동(ΔDGS2)** 을 서프라이즈 대용으로 쓴다.
통화정책 서프라이즈 문헌의 표준 접근(Kuttner 2001은 연방기금선물, 여기선 무료로 얻는 2Y).
ΔDGS2>0 = 예상보다 강한 지표. **순환이 아니다** — 서프라이즈는 미국, 종속변수는 다음 날 한국이다.

### A. 서프라이즈만 — 방향이 잡힌다

| 종속변수 | β | t |
|---|---|---|
| **갭** | **+0.0188** | **4.81\*\*\*** |
| 장중 | −0.0076 | −1.68\* |
| 종가-종가 | +0.0113 | 1.84\* |

**미 2년물 10bp 상승 → 다음날 코스피 갭 +0.19%.**
부호가 양(+)인 것은 **"좋은 지표 → 금리↑ + 주가↑"의 경기 채널**이 표본 전체에서 우세하다는 뜻이다.
원 문서가 걱정한 *"Bad news is good news"* 는 **평균적으로는 지배적이지 않다.**

### B. 미 주가를 통제하면 서프라이즈가 사라진다 ← 이게 핵심

```

```

**S&P500 선물 야간 수익률 하나가 코스피 갭의 거의 전부를 설명한다**(β=0.59).

→ **전달 경로**: 미 지표 서프라이즈 → 미 금리·주가 재평가 → (야간) → 코스피 시가 갭.

즉 **한국 증시는 미국 지표가 아니라 미국 주가에 반응한다.** 지표는 그 앞단일 뿐이다.

### 문헌 대조 (2026-08-05 추가)

β=0.59를 국내 전이 문헌 6편과 대조했다 → [[미국→한국 증시 전이 MOC]]

**일치** : 미국 → 한국 **단일방향**이라는 방향성은 4편이 방법·표본을 달리하며 같은 결론.
**불일치 아님, 그러나 확인도 아님** : **직접 비교 가능한 계수(미 주가 1% → 코스피 몇 %)를 주는 논문이 없다.**
대부분 그랜저 인과·전이지수 비율·GARCH 계수를 보고한다.
**추가된 조건** : 전이 강도는 **위기·테이퍼링에 커지고 QE기에 작아진다.**
→ β=0.59는 **표본 평균**이며 국면별로 다를 수 있다.

### C. 이벤트별 잔여 효과 — 신뢰하기 어렵다

이벤트 8개를 검정했으므로 **다중검정 보정 없이는 우연을 배제할 수 없다.**

## 1-m. 동태적 NMF — 2026-08-05. 부분 개선, **결론은 그대로**

`python -m databook dyntopics` — Greene·Cross(2016) 방식.
코퍼스를 5개 창으로 나눠 **창 안에서** NMF(창당 4토픽) → 창-토픽 벡터를 쌓아 **2차 NMF**(4토픽).
창 내부에서는 어휘가 안정적이라 진짜 주제가 잡힐 것이라는 기대.

### 개선된 점 — 토픽이 창을 넘기 시작했다

```
D1  W1 0.66 · W2 0.33                    분산도 0.44
D2                    W4 0.18 · W5 0.78  분산도 0.41
D3  W2 0.45 · W3 0.50                    분산도 0.56
D4            W3 0.35 · W4 0.61          분산도 0.51
                                평균 0.48
```

정적 NMF에서는 토픽이 **한 시대에 0.99씩 갇혀** 있었다. 이제 **각 토픽이 인접 두 창에 걸친다.**
(분산도 = 창 분포의 정규화 엔트로피. 1이면 고르게, 0이면 한 창에 집중)

### 남은 한계 — 인접 2창이 끝이다

**어떤 토픽도 W1~W5를 관통하지 못한다.** 1999년 어휘와 2026년 어휘는 2차 NMF로도 안 묶인다.
이건 방법의 한계라기보다 **코퍼스의 성질**이다 — FOMC 성명서는 20년 사이 형식·어휘·길이가
근본적으로 바뀌어 "같은 주제의 다른 표현"이 아니라 **아예 다른 문서**에 가깝다.

### 회귀 — 곡률은 세 번째 사양에서도 안 나온다

| 요인 | 유의한 동태적 토픽 |
|---|---|
| level | **dT3\*\*** (t=2.31) |
| slope | **dT1\*\*** (t=2.40) · \|dT1\|\* (t=1.88) |
| **curvature** | **없음** (전부 p>0.16) |

| 사양 | 곡률 |
|---|---|
| 정적 k=2 (1999~) | 비유의 |
| 정적 k=3 (2009~) | 비유의 |
| **동태적 k=4** | **비유의** |

**방법을 세 번 바꿔도 결과가 안 바뀌었다.**
→ 원인이 방법이 아니라 **데이터이거나, 원 논문 결과가 표본 특수적**일 가능성이 커진다.
다만 내 재현이 **Diebold-Li 칼만필터 대신 버터플라이 프록시**를 쓰는 한계가 남아 있어
"논문이 틀렸다"고 단정할 수는 없다. 여전히 신용스프레드가 곡률을 지배한다(t=4.73).

### 방법론 소득

**"토픽이 시대에 갇혔는가"를 재는 진단 지표(분산도)를 만들었다.**
텍스트 분석을 할 때 토픽 상위어만 보지 말고 **시간 분포의 엔트로피를 함께 봐야** 한다 —
상위어만 보면 그럴듯한데 실은 시대 더미인 경우를 잡아낸다.

## 1-n. Nelson-Siegel 요인 — 2026-08-05. **재현 실패의 진범이었다**

`python -m databook curve` — Diebold-Li(2006) 3요인.
λ=0.0609 고정, 만기 **11개(1M~30Y)** 횡단면 OLS. 6,900일(1999~2026), 적합 RMSE 평균 10.2bp.

> 만기 3개(DGS2/10/30)로는 3요인이 **정확식별되어 잔차가 0**이 된다.
> 그래서 `DGS1MO·3MO·6MO·1·3·5·7·20`을 추가로 수집했다.

### 프록시가 곡률을 재지 못하고 있었다

| 요인 | 수준 상관 | **일간 변화 상관** |
|---|---|---|
| level | +0.990 | +0.971 |
| slope | −0.935 | −0.433 |
| **curvature** | −0.659 | **−0.087** |

1-i·1-m의 회귀는 종속변수가 `|Δcurvature|`였는데, **그 프록시의 일간 변화가 진짜 곡률 변화와 상관 0**이었다.
→ **앞선 세 사양의 곡률 결과는 애초에 곡률을 재고 있지 않았다.**

### 제대로 재니 결과가 바뀐다

발표일 `|Δ|` 비율: 프록시에서는 slope 1.45x가 1위였으나 **NS에서는 curvature 1.46x가 1위**다.

회귀에서도 **동태적 NMF + NS 조합에서 처음으로 곡률에 유의 항**이 나왔다
(`|dT1|` β=49.7, t=2.01, p=0.044). **⑴ 요인 추정 ⑵ 시대 편중 완화가 동시에 필요**하다.

### 이번 건의 진짜 교훈

**"결과가 다르면 내 코드부터 의심하라"가 정확히 작동했다.**
세 사양 연속 실패했을 때 "논문이 틀렸다"로 가지 않고 **마지막 남은 의심(프록시)** 을 검증한 것이 답이었다.
→ **파생 변수를 쓸 때는 원본과의 상관을 수준이 아니라 "변화"로 확인할 것.**
수준 상관 −0.659는 그럴듯해 보이지만 변화 상관 −0.087은 쓸 수 없는 수준이다.

## 2. 원 문서의 리스크 4개 — vault가 이미 답을 갖고 있는 부분

원 문서 3장이 든 리스크는 정확하다. 다만 **일부는 이미 다른 사람들이 겪고 기록해 둔 문제**다.

### ① 표본 부족 → "이벤트를 묶어라"는 맞지만, 묶으면 다른 게 깨진다

원 문서 처방은 **상위 카테고리로 묶기 + 기간 5~10년 확대**다. 방향은 맞다.
그런데 vault에 **정반대 교훈**이 있다 →
[[2023 Dissipation of Relation between Inflation and Business Cycles in Korea (Huh In)]]는
7년 롤링 추정에서 **관계가 2017Q3 이후 소멸**했음을 보였다.

**기간을 늘리면 표본은 늘지만 레짐이 섞인다.** 두 요구가 정면으로 충돌한다.
→ **처방** : 전체 표본 계수 하나를 내놓지 말고, **롤링 윈도우로 계수의 시간 경로를 그릴 것.**
계수가 안정적이면 그때 평균을 말한다.

### ② 타이밍 정합성 → 이건 vault에서 이미 아티팩트로 잡힌 적이 있다

원 문서가 지적한 look-ahead bias는 실재한다. 구체적 사례가 vault에 있다 —
[[2010 국제투자심리지표간의 연관성 분석 (이상원)]]에서 **VIX 변화의 27.48%가 VCAC(프랑스)로 설명**되는
기묘한 결과가 나오는데, 유력한 원인이 **유럽 종가가 미국 종가보다 앞서는 시간대 정렬 문제**다.

관련 제텔 : [[밤과 낮으로 쪼개면 결론이 바뀐다 — 일별 수익률은 상쇄된 값이다]]
→ **처방** : 코스피 익일 수익률을 쓸 때 **종가-종가가 아니라 시가-종가(장중)와 전일종가-당일시가(갭)로 분해**할 것.
미국 새벽 발표의 효과는 **갭에 대부분 들어간다.** 합쳐 놓으면 상쇄되어 계수가 0으로 보인다.
✅ **2026-08-05 실증 확인** — 갭에서 유의하던 PPI·CPI가 종가-종가에서는 소멸했다(위 1-j).

### ③ 비선형 반응(Bad news is good news) → 종속변수를 절대값으로 두는 우회로가 있다

[[중앙은행 커뮤니케이션과 수익률곡선 (NMF 토픽모델링, Crayton 2018)]]이 정확히 이 문제를 만나
**종속변수를 |Δ|(절대변화 = 변동성)로 바꿨다.** 방향 코딩의 자의성을 피하는 정직한 설계다.

**대가도 분명하다** — "올랐나 내렸나"는 답할 수 없게 되고, "영향이 있다"가 곧 **"변동성이 커졌다"** 로만 남는다.
→ **처방** : 1차는 **|Δ코스피|** 로 "이벤트가 반응을 만드는가"를 먼저 확인하고,
방향은 **레짐(금리 인상기/인하기)으로 나눈 뒤에** 따로 추정할 것.

### ④ 컨센서스 부재 → "전월 대비 변화량"은 서프라이즈가 아니다

원 문서의 1차 방안(컨센서스 없이 전월 대비 실제치 변화)은 현실적이지만, **측정하는 대상이 다르다.**
시장은 **예상 대비 차이**에 반응하지 실제치의 변화에 반응하지 않는다.

✅ **2026-08-05 해결** — BEI 대신 **ΔDGS2(발표일 2년물 변동)** 를 서프라이즈 대용으로 써서 방향 추정에 성공했다(위 1-l).
→ **차선책** : `T10YIE`(BEI)·`GDPNOW` 같은 **시장/모형 기반 실시간 기대치**를 컨센서스 대용으로 쓸 수 있다.
CPI 발표일의 서프라이즈 대용 = `실제 CPI − 직전 BEI 내재 기대`. 완벽하지 않지만 **"전월 대비 변화"보다는 낫다.**
단 [[BEI (기대인플레이션)]]의 판정 규칙대로 **한국 BEI는 시장이 얇아 쓸 수 없다.** 미국 이벤트에만 적용.
