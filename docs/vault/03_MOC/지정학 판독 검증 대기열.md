# 지정학 판독 검증 대기열

> **이 노트는 결론이 아니라 대기열이다.**
> 마누스 납품물은 **동료심사 없는 기고·논평의 판독 결과**다. 등급은 `commentary` 고정이고,
> **1차 자료와 대조를 통과한 것만** 지표 노드의 판정 규칙 후보로 올라간다.
> 여기 적힌 숫자는 **"필자가 그렇게 말했다"이지 "사실이다"가 아니다.**

> [!warning] 여기서 인용하기 전에
> 인용 위치(`page N`)는 **PDF 물리 쪽**이다(표지가 1쪽). 지면 인쇄 쪽번호와 다르다.
> [[지정학 원문 아카이브 (남캅카스·중간회랑)]] §3-4 규칙대로 **원본 PDF의 해당 쪽을 확인**하고 쓴다.

## 4. 이 대기열을 쓰는 규칙

1. **☐ 상태의 주장은 인용하지 않는다.** 발표·시황 노트에 넣지 않는다
2. 대조를 통과하면 **☑ + 1차 자료 링크**를 달고, 해당 지표 노드로 옮긴다
3. 대조에 **실패**하면 지우지 말고 **"기각 (날짜·사유)"** 로 남긴다 — 재등장 여부를 봐야 한다
4. 서로 어긋나는 숫자(F1↔F2, F6↔F7)는 **둘 다 보류**한다. 하나를 고르지 않는다
5. 배치가 추가되면 §1 표에 행을 붙이고, `type: fact` 주장을 §2에 누적한다
6. **상태 서술은 `as-of` 기준일과 함께 옮긴다.** 18개월 초과분은 재확인 전 인용 금지 (§5-1)
7. **만기 도래 예측은 그 자리에서 채점한다.** 미채점 상태로 쌓아 두지 않는다 (§5-2)

### 5-1. 시점 없는 주장은 재료가 아니다 (개정조항 v3)

인용과 위치가 맞아도 **사건 시점**이 없으면 판정에 못 쓴다. 발행일은 '필자가 언제 썼나'이지
'사건이 언제 일어났나'가 아니다. 그래서 주장마다 세 필드를 붙였다 —
`event_time` / `event_time_basis` / `event_status`(8종). 규약: `_verify/요청서_개정조항_v3.md`.

실측 225건: **본문에 시점이 적힌 것은 99건뿐**, 85건은 시점 표기가 없는 상태 서술이라
**발행일을 as-of 기준점으로 못 박았다**(지어내지 않고 근거란에 그렇게 적었다고 남긴다).

> [!warning] as-of 상태 서술은 유통기한이 있다
> 시점 없는 상태 문장은 **발행일에 묶인 스냅숏**이다. 볼트에 옮길 때 반드시 `as-of YYYY-MM`을 같이 적고,
> **18개월을 넘으면 1차 자료 재확인 전 인용 금지**.
> 현재 해당: **3건(전부 b05, as-of 2023-12-03, 32개월 경과)** — EU 12개 조건 이행 현황 서술.

### 5-3. 조건부 시한 6건 — 기산점부터 확인한다

"흑해 휴전 발효 후 12개월" 류는 **기산점이 다른 사건에 걸려 있다.** 발행일로 만기를 재면 안 된다
(초기 자동판정이 실제로 그렇게 잘못 찍었다). 기산점은 **코퍼스 내부의 뒷 기사로 교차 확인**했다.
