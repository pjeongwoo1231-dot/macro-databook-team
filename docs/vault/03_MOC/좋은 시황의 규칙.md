# 좋은 시황의 규칙

> **왜 이 노트가 필요한가.** [[시황 분석 진입점]]은 *무엇을 읽을지*를,
> [[시황 노트 작성 형식 (템플릿)]]은 *볼트 노트를 어떤 절로 쓸지*를 정한다.
> 빠져 있던 건 **"사람에게 내놓는 보고서는 어떻게 쓰는가"**다.
> 2026-08-25에 같은 시황을 세 번 고쳐 쓰면서 그 규칙이 드러났다.

## 0. 산출물은 둘이고 목적이 다르다

| | 볼트 노트 | 보고서 |
|---|---|---|
| 목적 | 기록·감사 | **판단 전달** |
| 독자 | 미래의 나 | 사람 |
| 데이터 신선도표 · 규칙 대조 · 자기검사 · 정정 이력 | **필수** | **금지** |
| 분량 | 길어도 됨 | 근거는 셋까지 |

**볼트 노트를 예쁘게 만들어 보고서라고 내지 않는다.** 2026-08-25 초안이 그 실수였고,
절반이 "내가 어떻게 일했는가"였다.

## 1. 주장 하나에 근거 셋 — **추세 · 사례 · 이론**

이게 이 노트의 핵심이다. **"B다"라고 쓰지 않는다. "A이고 A였으니 B다"라고 쓴다.**

| 축 | 무엇을 대는가 | 없으면 |
|---|---|---|
| **추세** | 시계열 그래프 + 변화분. 수준이 아니라 **어디서 어디로 갔는지** | 스냅샷 하나로 방향을 말하게 된다 |
| **사례** | 과거에 같은 배열이 언제였고 **그 뒤 무엇이 왔나**. 기저율을 숫자로 | 서사가 데이터를 이긴다 |
| **이론** | 논문의 **계수**. 방향이 아니라 크기 | "영향을 준다"에서 멈춘다 |

**최소 둘은 있어야 주장을 쓴다.** 셋 다 없으면 그건 관측이지 주장이 아니다.

### 실행 예 (2026-08-25 「기간프리미엄」 절)

- **추세** — 12개월 +35bp, 3년 99%ile. 2003~2026 차트에 과거 국면 표시
- **사례** — 같은 배열 13개 구간 표. 나빴던 셋은 전부 진입 시 42~50%ile이었다
- **이론** — Plante·Richter·Zubairy(2025): 부채/GDP +1%p → +3bp, **그 3/4이 기간프리미엄**
- **→ 그래서** — +35bp는 부채/GDP +15%p에 해당(상한). **FOMC가 되돌릴 변수가 아니다**

## 2. 기저율을 먼저 재고, 그것과 다르게 말하려면 이유를 대라

**"X니까 주식이 떨어진다"를 쓰기 전에 X가 있었던 과거에 실제로 떨어졌는지 센다.**

2026-08-25에 이 규칙이 내 결론 하나를 죽였다. "실질금리 주도 긴축 → 한국 주식 하락"을
쓰려다 재보니 13개 구간에서 코스피 3개월 **중앙값 −0.1%, 7/13만 음수** — 동전던지기였다.
**초안의 결론을 철회하고 조건부 서술로 바꿨다.**

- 기저율이 중립이면 **거기서 멈추지 말고 유형을 갈라본다.**
  2026-08-25에 배열 기저율은 −0.1%(동전던지기)였지만, **원인별로 A/B/C 세 유형으로 가르니**
  A +10.7% · B −0.1% · **C −3.2%(3/4 음수)** 로 갈렸다.
  → `_System/Analysis/real_led_typology.py`
  **"기저율이 중립이다"는 결론이 아니라 다음 질문의 시작이다** — *무엇이 갈랐나*
- 그래도 갈리지 않으면 **방향을 단정하지 않는다**
- 그래도 다르게 말하려면 **이번을 다르게 만드는 변수 하나를 지목**하고 그것이 표본 밖임을 보인다
- 표본이 작으면(n<30) **"법칙"이라 부르지 않는다.** 점 13개는 시사지 증명이 아니다

## 3. 그래프는 장식이 아니라 논증이다

- **발산·수렴을 보여줄 땐 누적 변화분**으로 그린다(수준 그래프는 두 선의 스케일이 달라 안 보인다)
- **장기 계열엔 과거 국면을 표시**한다. 지금이 어디쯤인지는 그 표시가 만든다
- **산점도는 조건을 가를 때** 쓴다 — "무엇이 좋은 사례와 나쁜 사례를 갈랐나"
- 일간 노이즈가 큰 계열(EPU·불확실성 지수)은 **MA로만** 그린다. 원계열은 하루에 16→440까지 튄다

## 4. 크기를 말하라

*"금리에 영향을 준다"*는 아무 말도 아니다. **논문 계수를 대서 몇 bp인지 말한다.**
계수가 없으면 **없다고 적는다** — 그것도 정보다.

환산할 때는 **상한임을 밝힌다.** 기간프리미엄 +35bp를 전부 재정 탓으로 돌리면
QT·해외수요 변화를 재정에 떠넘기는 것이다.

## 5. 결론은 "그래서 무엇이 달라지나"까지 간다

분해는 **근거**지 결론이 아니다. 2026-08-25 2차 개정 전까지
"실질금리가 명목을 밀었다"를 증명해놓고 **그게 무엇을 바꾸는지는 한 줄도 없었다.**

각 주장은 **누구에게 무엇이 달라지는가**로 닫는다 —
정책이 되돌릴 수 있는가 / 어느 자산에 걸리는가 / 무엇을 하지 말아야 하는가.

## 6. 무효화 조건을 숫자로 먼저 적는다

[[시황 노트 작성 형식 (템플릿)]]에서 이어받는다. **주장마다 뒤집는 임계**를 붙이고,
그중 **가장 먼저 깨질 후보**를 지목한다. 이건 보고서에도 남긴다 — 유일하게
"과정"인데 보고서에 남기는 항목이다. **판단의 유효기간을 알려주기 때문**이다.

## 7. 보고서 5절

1. **판단** — 3~4문장. 무슨 일 → 왜 → 그래서 뭐가 달라지나
2. **주장** — 각각 [추세 그래프 → 사례/기저율 → 이론 계수 → 그래서]
3. **한국** — 위 축들의 **결과**로 배치 → [[feedback-macro-axes-first]]
4. **관전** — 날짜 박힌 이벤트 + 볼 것("방향보다 폭과 표결")
5. **무효화** — 숫자 임계

## 8. 내가 틀린 것을 결론으로 내놓지 않는다

**"재보니 내 판단이 틀렸다" 는 보고가 아니다.** 읽는 사람이 가져갈 게 없다.
틀린 것을 발견했으면 **거기서 한 걸음 더 가서 배울 것을 만들어 낸다.**

| 이렇게 쓰지 않는다 | 이렇게 쓴다 |
|---|---|
| "기저율을 재보니 내 결론이 틀렸다" | **"배열은 방향을 주지 않는다 — 원인이 준다"** + 유형별 결과 |
| "n이 작아서 확신할 수 없다" | **"이 분류는 2008-08을 놓쳤다 → 분류는 금리의 원인을 잡지 시스템 위험을 못 잡는다"** |
| "데이터가 어긋나서 고쳤다" | (보고서에 쓰지 않는다. 볼트에만) |

**차이는 주어다.** 앞은 주어가 나이고, 뒤는 주어가 세계다.
보고서의 주어는 항상 **세계**여야 한다.

## 자기검사

- [ ] 근거 없이 단정한 문장이 있는가
- [ ] 주장마다 추세·사례·이론 중 **둘 이상**이 붙었는가
- [ ] **기저율을 재봤는가.** 재본 결과와 다르게 말하고 있다면 이유를 댔는가
- [ ] 크기를 말했는가, 방향만 말했는가
- [ ] 각 주장이 "그래서 무엇이 달라지나"로 닫혔는가
- [ ] 내 작업 과정·오류 정정이 보고서에 섞여 있지 않은가
- [ ] **틀린 것을 발견했다면 거기서 배울 것까지 뽑았는가** (§8)
- [ ] 기저율이 중립이었다면 **유형을 갈라봤는가**
