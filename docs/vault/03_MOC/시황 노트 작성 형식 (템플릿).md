# 시황 노트는 **이 순서로 쓴다**

> **출처**: 사용자가 준 시황 영상(만쥬, *"주린이를 위한 주식바이블, 시황 보는 꿀팁"* ep.50-1, 2025-11-14)의
> 구성을 2026-08-19에 채택했다. 영상의 뼈대는
> **① 어제 왜 그렇게 봤나 → ② 오늘 시나리오(A면 B, 아니면 패스) → ③ 실시간 확인 → ④ 복기**다.
> 축별 판정을 나열하던 이전 형식(2026-08-18 노트)을 대체한다.

## 왜 이 형식인가

이전 형식의 문제는 **사후에 말을 바꿀 수 있다는 것**이었다.
축별로 "이렇다"고 적어두면 결과가 나온 뒤 강조점만 옮겨도 틀린 티가 안 난다.
**시나리오를 먼저 등록하면 그게 안 된다.** 영상의 두 문장이 그 이유를 그대로 말한다.

> **"매수보다 손절 기준이 명확해야 한다."**
> **"흐름이 안 나오면 그냥 패스한다."**

볼트 언어로 옮기면 — **판정보다 기각 조건이 먼저**이고, **판정하지 않는 것도 결론**이다.

## 절 구성

| 절 | 내용 | 필수 |
|---|---|---|
| **0. 데이터 신선도** | 인용하는 계열의 **기준일**을 표로 먼저 적는다 | **필수(신설)** |
| **1. 무슨 일이 있었나** | 사건을 **한 줄**로. 이어서 근거 표 | 필수 |
| **2. 규칙이 설명하는가 / 못 하는가** | 볼트 규칙을 대보고 **어긋나면 어긋난다고 적는다** | **필수(신설)** |
| **3. 시나리오 (A면 B, 아니면 패스)** | 관찰 대상 · 조건 · 그러면 — **사전 등록** | 필수 |
| **4. 축별 관측** | 계열값과 판정. **판정 규칙을 링크로 소환** | 필수 |
| **5. 관측 없음** | 오늘 쓰지 못한 축과 **그 이유** | **필수(신설)** |
| **6. 어제 판정 복기** | 유지 / 보강 / 정정 세 가지로만 | 필수 |
| **7. 자기검사** | [[시황 분석 진입점]] §2 금지 문장 체크 | 필수 |
| **8. 채점 대상** | 예측 · 등록값 · 채점 시점 | 필수 |

## 영상에서 **가져온 것**

1. **시나리오를 먼저 등록한다** — "원전 섹터 보고, 대장이 이 정도 가면 2등주를 매매하고,
   그 흐름이 안 나오면 패스" 같은 **조건부 문장**. 볼트는 이걸 §3 표로 쓴다
2. **패스도 결론이다** — 영상은 실제로 *"오늘은 원전 매매 패스"* 로 끝난다.
   볼트도 **"오늘은 새 판정을 붙이지 않는다"** 를 결론으로 쓸 수 있다
3. **기각 기준을 매수 근거보다 먼저** — §8 채점 대상에 **뒤집는 조건**을 반드시 넣는다
4. **복기를 같은 노트에** — 영상 마지막이 매매 복기다. §6이 그 자리

## 영상에서 **가져오지 않은 것** (의도적으로 뺌)

1. **개별 종목·섹터 매매 판단** — 볼트는 **레짐 판정 도구**다. 종목을 고르지 않는다.
   같은 수급 데이터를 쓰되 **"무엇을 살까"가 아니라 "무엇이 국면을 바꾸나"** 를 묻는다
2. **장중 실시간 중계** — 볼트는 하루 1회 기록이다. 분 단위 흐름은 담지 않는다
3. **손절가 같은 가격 기준** — 대신 **지표 임계**(5y5y 2.4%, ANFCI 0, HY OAS 백분위 30%)를 쓴다

## 이전 형식에서 **버린 것**

- **축별 판정 나열**(물가·성장·유동성·재정·한국·일본을 순서대로) →
  §4로 남기되 **시나리오(§3)에 걸리는 축만** 자세히 쓴다. 안 걸리는 축은 한 줄
- **긴 서사** — 근거 표와 판정 문장으로 대체

## 이전 형식에서 **살린 것**

- **〔왜 이렇게 읽나〕 각주** — 공부용으로 가장 값어치가 있었다. §4에서 계속 쓴다
- **금지 문장 자기검사**(§7)
- **사후 보정 절** — §6 복기로 이름만 바꿔 유지

## 새로 넣은 세 절과 그 이유

**§0 데이터 신선도.** 2026-08-19에 실제로 겪은 문제다 — 커브(월별, 2026-07)와
코스피(당일)를 같은 표에 놓으면 **오늘 값처럼 읽힌다.** 기준일을 먼저 박아둔다.

**§2 규칙이 설명하는가.** 2026-08-19에 **글로벌 여건은 멀쩡한데 코스피만 −7.2%** 가 나왔다.
볼트 규칙(신흥국 주가는 글로벌 여건에 좌우)이 설명하지 못했고, **그 사실을 적는 자리가 없었다.**
어긋남은 규칙을 고칠 재료이므로 **덮으면 손해다.**

**§5 관측 없음.** 담보 헤어컷·엔 헤지비용처럼 **원천이 없는 축**이 있다.
매번 "왜 안 썼나"를 다시 설명하지 않도록 고정 자리를 준다.
