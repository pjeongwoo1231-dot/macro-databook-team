# 지정학 코멘터리 MOC — 국제정세·에너지·정책 원문 학습 노트

> **성격**: [[헤지펀드 뷰 MOC|헤지펀드 뷰]]가 헤지펀드/투자자의 **시장 뷰**를 다룬다면, 이쪽은 정책기관·의회·정치 콘텐츠 등 **정책·지정학 원문**을 다룬다.
> 파이프라인(지표 → 해석 → 레짐) **안의 입력**이다. 공급망·에너지·통화패권·연준 인사는 전부 매크로 변수이지 곁가지가 아니다.
> 논문과 다른 것은 신뢰도 등급(Primary Source ~ Opinion)이지 용도가 아니다.
> 노트 실물은 `02_Papers/`에 있고 `type: analyst_view` / `primary_source`로 구분한다.
> 모든 노트에 신뢰도(reliability) 평가와 "검증 필요/반박 포인트(Red Team)" 섹션 필수 — 특히 이 폴더는 **의견/해석 콘텐츠와 1차 사료(청문회 원문 등)가 섞여 있으므로 유형 구분에 유의**.

## 교차 읽기 추천

- **① vs ④**: 동일한 "미국 에너지 패권" 사실관계를 정책연구소 톤(CSIS)과 냉소적 해설 톤(국내 채널)이 각각 어떻게 다르게 프레이밍하는지 비교 — 같은 사실, 다른 서사의 좋은 사례.
- **② vs 12_HedgeFund_Views/Warren_Buffett**: 워시에 대한 버핏의 개인적 호평과 청문회에서의 정치적 공방을 나란히 두고 균형있게 판단.
- **③ vs 12_HedgeFund_Views/RealVision_Guests/Michael-Howell**: BIS(학계)와 헤지펀드(실무) 양쪽이 독립적으로 "정부채권시장+그림자금융"을 글로벌 유동성의 핵심으로 지목 — 드물게 교차검증된 프레임.
- **④~⑨는 반드시 세트로 읽을 것**: 동일 채널의 반복되는 3단계 해석 구조(사실 나열 → 미국 우위 재해석 → 엘리트 각본론)를 인지한 상태로 사실관계만 추출. 특히 ⑨는 반유대주의 인접 서사가 있어 배경지식화하지 않고 걸러낼 부분이 많음.

## 사용 원칙

1. 이 폴더의 콘텐츠 중 "1차 사료"(청문회, 공식 웨비나)와 "해설/의견 콘텐츠"(유튜브 채널)를 프론트매터의 `type` 필드로 구분(`primary_source` vs `analyst_view`).
2. 음모론적 프레임이 섞인 콘텐츠는 사실관계만 추출하고 해석은 별도 폐기 — 두 국내 채널 노트가 그 처리 방식의 예시.
3. 학회 4팀(지정학) DataBook에 인용 시 항상 출처 유형과 신뢰도를 함께 표기.
