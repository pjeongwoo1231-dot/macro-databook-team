## Ⅰ. 신규 지표 6건

### 1. CPTG (소비자−생산자 온도차) — `method: derived`, team_1

`CPTG = UMCSENT/20 − 합성PMI/10` (양수=확장, 음수=수축). [[설비가동률]]을 **4개월 선행**.
근거: [[2026 소비자-생산자 온도차 CPTG (Jonath, Khorasani & O'Connell)]]

**★ 블로커** — [[PMI (구매관리자지수)]]가 `method: news`라 **숫자가 없다**. 생산자 온도를 계산할 입력이 없음.
**우회**: 지역 연준 제조업 서베이(필라델피아·엠파이어·댈러스·캔자스시티·리치먼드, FRED 무료)를
50 기준으로 재척도해 평균 → 합성 PMI. **재척도 계수는 ISM 실측 회귀로 고정**해야 하며 그 전까지는 임시값.

```python
# databook/derived.py — compute() 안에 추가
if "CPTG" in name:
    csi, pmi = _latest(results, "UMCSENT"), _latest(results, "합성 제조업 PMI")
    if not (csi and pmi):
        return result(ind, "fail", error="구성요소 미수집 (UMCSENT·합성 PMI 필요)")
    cptg = csi[1] / 20 - pmi[1] / 10
    obs = [{"date": max(csi[0], pmi[0]), "value": round(cptg, 3),
            "label": "CPTG(°G) — 양수=확장, 음수=수축, 설비가동률 4개월 선행"}]
    return result(ind, "ok", observations=obs, source_url="FRED UMCSENT + 지역 연준 서베이")
```

⚠ **채택 전 8주차 Red Team 안건으로 상정.** 단순회귀 R²는 **0.47**이고 96%는 사후 군집화 산물이다.
