# 제텔 → 트리거 변환 큐

> **무엇을 스캔했나.** 제텔 **177개**의 주장을 라이브 수집기 **225슬롯**과 맞춰,
> *"측정 가능한데 판정 장치가 없는 것"* 을 뽑았다. 제텔 파일은 **하나도 수정하지 않았다.**
>
> ⚠ **방법의 한계**: 이 볼트는 **제목이 곧 주장**이라 제목 기준 트리아지가 성립하지만,
> 개별 임계값은 아래 후보를 실제로 편입할 때 **원 제텔 본문에서 확인해야 한다.**
> 아래 "제안 임계"는 확정값이 아니라 **작업 지시**다. **확신도: 중상** (분류) / **중** (임계 제안).

## §3. 제안하는 `operational` 스키마

**스캔을 먼저 돌린 이유가 여기 있다.** 필드를 미리 정했으면 177개를 두 번 고쳤을 것이다.
실제 분포(A 다수 · C 10 · D 8)를 보고 나니 필요한 필드는 **네 개뿐**이다.

```yaml
operational:
  measurable: no                  # A면 여기서 끝. 대다수가 A다
  # measurable: yes 일 때만 아래를 쓴다
  series: [SOFR, IORB, WRESBAL]   # 라이브 indicators.yaml 기준 이름
  device: trigger | 판정규칙 | 보조지표
  status: 미편입 | 편입됨(T14) | 계열없음
```

**설계 원칙 세 가지**

1. **`measurable: no`가 기본값이다.** A가 다수인데 모두에게 5개 필드를 채우게 하면
   빈칸이 생기고, CLAUDE.md 3조(*"사람이 채울 빈칸을 남기지 않는다"*)에 걸린다.
2. **`device`를 나눈다.** 스캔에서 드러난 것 — C 10개 중 트리거로 만들 수 있는 건 절반이고,
   나머지는 **판정 규칙**(VIX 충격 분류·금통위 반응함수)이거나 **보조 지표**다.
   전부 트리거로 만들려 하면 [[매크로 해석 프레임]] 7단계의 "판정 불가" 사고가 반복된다.
3. **전수 소급 적용을 하지 않는다.** C·D **18개에만** 먼저 붙이고,
   나머지는 **제텔을 새로 쓰거나 고칠 때 채운다.** 확신도 재집계에서 배운 것과 같다 —
   **집계를 완성하느라 판정을 미루지 않는다.**

## §6. C-3 이행에서 나온 것 (2026-08-18)

**① 이 큐의 「쓸 계열」 칸은 검증된 값이 아니다.** C-3에 적어둔 `2s10s · 3m10y`는 **미국 커브**인데

## §7. C-4 이행에서 나온 것 (2026-08-18)

**① 임계가 없는 제텔이 있다.** C-4의 근거 논문은 1973·2008을 역사적 분해로 지목했을 뿐 **숫자를 주지 않는다.**
볼트 규칙("근거 없으면 비워둔다")대로면 여기서 멈춰야 하지만, **임계는 논문에서 베끼는 것이 아니라 재는 것**이다.
→ 핑크시트 1960~ + NBER 침체로 직접 측정: **직전 12개월 최고치 대비 −35%/−40%**. 출처는 논문이 아니라 **자체 실측**이라고 노트에 명시했다.

**② 이행이 제텔의 주장을 깎았다.** 「급락기에만 경기를 **말한다**」 → 실측은 **동행**이다.
침체 배수가 당월 ×7.0에서 12개월 지평 ×3.3으로 **줄어든다**(선행이면 반대 모양이어야 한다).
**제텔이 든 1973 사례부터가 침체 시작보다 7개월 늦었다.**
→ 그래서 트리거가 아니라 **게이트**로 만들었다 — 구리를 성장 축에 넣을지 말지만 결정한다.

**③ 큐가 묶어 놓은 두 계열이 같은 등급이 아니다.** C-4는 `구리 · 구리/금`을 나란히 적었지만
같은 시험에서 **구리/금이 더 자주 켜지고 덜 맞는다**(−40% 기준 51개월 ×4.4 vs 27개월 ×5.7).
→ 구리/금은 성장 게이트에서 **뺐다.** 큐의 계열 칸은 후보 나열이지 동급 표시가 아니다.

**④ 라이브 계열이 임계를 잰 계열과 다르다.** 수집기는 **COMEX `HG=F`**, 임계는 **LME**에서 쟀다.
괴리 최신 **+4.8%**(5년 중앙값 +1.3%) — 미국 관세 국면에서 벌어졌다.
→ **임계를 만들 때는 그 임계를 잰 계열과 라이브 계열이 같은지 확인한다.** C-3의 ②(계열이 수집기에 없었다)와 같은 유형의 구멍이다.

**⑤ 규칙이 놓치는 것을 규칙 옆에 적었다.** 2020-03 침체는 임계 미도달 — 월평균이 빠른 충격을 뭉갠다.
**규칙의 침묵을 '이상 없음'으로 읽지 않는다.**

## §8. C-5 이행에서 나온 것 (2026-08-18) — **처음으로 이행을 기각했다**

**① 큐의 작업 지시가 틀릴 수 있다.** C-5는 *"누적 순매수를 환율 트리거의 선행 입력으로"* 라고 지시했다.
겉보기 t = **7.33**이라 그대로 만들었으면 트리거가 하나 늘었을 것이다. 두 번 확인하고 버렸다 —
**겹친 창을 걷어내니 t 0.91**, **표본을 반으로 가르니 부호가 뒤집혔다**(−0.050 / +0.028, 둘 다 '유의').
→ **유지 규칙 추가: 전방 수익률을 쓰는 회귀는 겹친 창과 반쪽 표본 두 검사를 통과해야 한다.**

**② 큐를 비우는 것이 목적이 아니다.** C-5는 **✅가 아니라 ⛔로 닫혔다.**
"만들지 않기로 했다"도 이행 결과이며, 근거를 적어두지 않으면 **다음에 같은 t=7.33을 보고 다시 만들 것이다.**

**③ 근거 제텔이 15년 만에 반쯤 틀렸다.** 이한재(2012)의 「외국인은 주가를 못 움직인다」(F=0.887)는
현 표본에서 **F=9.03(1%)** 으로 뒤집혔고, 당일 설명력도 **주식 R² 0.229 vs 환율 0.005**로 **크기 순서가 반대**다.
→ 제텔 두 건의 주장을 좁혀 적고 [[KOSPI]] 노드의 금지 문구도 *"선행지표로 쓰지 말 것"* 에서
*"주가가 더 강한 원인이므로 단독 신호로 쓰지 말 것"* 으로 고쳤다.
**이행은 제텔을 장치로 옮기는 일이면서 제텔을 재검정하는 일이다** — C-4에 이어 두 번째 사례다.

## §9. C 큐를 다 비웠다 (2026-08-18) — 10건의 결산

| | 건수 | 항목 |
|---|---:|---|
| ✅ 그대로 편입 | 5 | C-1(T14) · C-2(VIX 분류) · C-3(커브) · C-6(금통위 절차) · C-9·C-10 중 채택분 |
| ⚠ 지시를 바꿔 편입 | 3 | **C-4** 트리거→게이트 · **C-7** 판별기→사건탐지기 · **C-8** 트리거→확인지표 |
| ⛔ 기각 | 1 | **C-5** 누적 순매수의 환율 선행성 |
| ✂ 경로만 잘라내고 결론 채택 | 1 | **C-9** "기대를 통해"가 끊김 |

**여덟 번 중 네 번, 큐가 적어둔 대로 만들 수 없었다.** 계열이 틀렸거나(C-3),
임계가 없거나(C-4), 지표가 그 지표가 아니거나(C-7), 방향이 반대였다(C-5·C-8·C-9).
→ **스캔은 후보를 고르는 데까지만 정확했다.** 이행은 재검정과 같은 일이다.

**반복해서 나온 하나의 패턴 — 따라오는 변수를 선행 지표로 착각한다**

| 변수 | 실측 |
|---|---|
| 구리 급락 (C-4) | 침체를 **예고**하지 않고 동행 (배수 당월 ×7.0 → 12개월 ×3.3) |
| 외국인 순매수 (C-5) | 주가가 순매수를 끈다 (F 22.99 vs 9.03) |
| 임금·ECI (C-8) | 물가가 임금을 끈다 (F 9.55 vs **0.93**) |
| 기대인플레 FMB (C-9) | 물가가 기대를 끈다 (F 10.80 vs **0.58**) |
| 크립토 수익률 (C-10) | 주식과 **양방향 모두 비유의** |

→ **볼트 규칙으로 승격**: *"이 지표가 X를 예고한다"는 서술을 만들 때는 **역방향 F를 같이 적는다.**
역방향이 더 크면 그것은 예고가 아니라 확인이다."*
살아남은 선행 관계는 **집값 → 한국 CPI**(6~12개월)와 **한국 커브 → 금통위** 둘뿐이다.

**남은 진도**: C 큐는 비었다. 유지 규칙대로라면 **D 큐(5~7)를 수집기에 붙이거나 문헌을 더 읽을 차례**다.
D-5(크립토 거래량)는 C-10에서 "크립토는 유동성 지표"라는 판정이 나왔으므로 **우선순위가 올라간다** —
가격보다 거래량이 유동성을 직접 잰다.

## §10. D 큐도 닫았다 (2026-08-18) — 8건 결산

| | 건수 | 항목 |
|---|---:|---|
| ✅ 계열 편입 | 5 | D-1(기대인플레) · D-3(딜러 레포) · D-3′(SOMA WAM) · D-4(재할인창구) · **D-5(크립토 거래량)** |
| ⚠ 부분·대체 편입 | 2 | D-2(만기 아닌 상품별 구성) · **D-7(참가자 구성 대신 수량·스프레드)** |
| ⛔ 보류 (근거 기록 후 닫음) | 2 | **D-6(전력 — 자료가 더 느림)** · **D-8(지배구조 — 정기 계열 없음)** |

**① 없는 것은 만들 수 없다. 대신 무엇이 없는지를 적어 닫는다.**
D-7의 FHLB 78%는 **FR 2420 개별 보고**에 접근한 연구 결과다. 공개 시계열이 아니므로
**그 숫자를 현재값처럼 인용하는 것 자체가 오류**다. D-8도 같은 이유로 보류를 확정했다.
→ 보류 행을 지우지 않고 **이유와 함께 남긴다** — 다음에 같은 후보가 올라오면 여기서 멈춘다.

**② 속보 지표라는 말은 자료 공표 시차를 확인하고 써야 한다.**
D-6은 "산업생산의 1~2개월 시차를 메운다"는 제안이었는데, 무료로 잡히는 유일한 계열이
**산업생산보다 6개월 늦었다.** 기제가 옳아도 **파이프라인에서 성립하지 않으면 지표가 아니다.**

**③ 편입과 용도는 별개 결정이다.** D-5는 **계열은 붙이고 용도는 기각**했다 —
거래량은 유동성 상태를 보는 데 쓰고, 제텔이 말한 중국 자본유출 대리로는 쓰지 않는다.
(원 논문 F=7.942 → 재검정 **F=1.09**.) **"수집할 가치"와 "그 논문이 말한 용도"를 같이 승인하지 않는다.**

**④ C 큐에서 얻은 교훈이 D에서도 반복됐다** — D-7의 FF 거래량은 2019-09 스트레스 때
**오히려 작았다**(66 vs 현재 113 $bn). 큐가 "수량을 보자"고 했지만 신호는 **스프레드**에 있었다.
**수량이 곧 압력은 아니다.**

**남은 진도**: C·D 큐가 모두 닫혔다. 유지 규칙대로 **문헌을 더 읽을 차례**다.
대기 중인 작업은 ① **8/27 금통위 채점**(서술 판정 vs 반응함수 모형, [[기준금리]]) ②
D-6의 KPX 일별 계열 **활용신청**(사용자 조치) ③ 05_Library 미승격 후보.

## 유지 규칙

- C에서 하나를 만들면 **여기서 지우지 말고 `→ T14 편입 (날짜)`로 표시**한다. 이력이 곧 진도다.
- D는 수집기 편입이 끝나면 **C로 옮긴다** (계열이 생겼으므로 트리거 차례).
- 새 제텔이 C·D에 해당하면 **여기에 먼저 적고** 제텔 본문에 `operational`을 채운다.
- **이 큐가 비면 문헌을 더 읽을 차례다.** 큐가 차 있는 동안은 읽는 것보다 옮기는 것이 이득이다.
- **이행 전에 「쓸 계열」 칸을 제텔 본문과 대조한다** (2026-08-18 추가). 이 칸은 스캔 당시의 추정이고, C-3에서 실제로 틀렸다.
- **판정 장치를 만들면 정확도를 같이 잰다.** 임계만 있고 채점이 없으면 트리거가 아니라 의견이다.
- **임계가 논문에 없으면 재서 만들고, 출처를 '자체 실측'이라고 쓴다** (2026-08-18 추가). 논문에서 못 찾았다고 비워두면 제텔이 영원히 장치가 되지 못한다 — 대신 **누가 어느 표본으로 쟀는지**를 임계 옆에 적는다.
- **임계를 잰 계열과 라이브 계열이 같은지 확인한다.** C-3·C-4에서 연속으로 어긋났다.
- **전방 수익률 회귀는 두 검사를 통과해야 채택한다** (2026-08-18 추가): ① 창이 겹치지 않게 뽑아도 t가 남는가 ② 표본을 반으로 갈라도 부호가 같은가. C-5는 둘 다 실패해 기각됐다.
- **기각도 이행이다.** ⛔로 닫고 근거를 남긴다 — 안 그러면 같은 숫자를 보고 다시 만든다.
- **"X를 예고한다"고 쓸 때는 역방향 검정을 같이 적는다** (2026-08-18 추가). 역방향이 더 크면 예고가 아니라 확인이다. C-4·C-5·C-8·C-9·C-10이 전부 이 함정이었다.
