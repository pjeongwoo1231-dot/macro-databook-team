`RESEARCH_METHOD.md`가 **작업 순서**(수집 → 해석 → 검증 → 트리거)라면,
이 문서는 **논증 자체를 어떻게 짜느냐**다. 둘은 다른 축이다.

이 기법들은 특정 화자의 것이 아니라 **좋은 매크로 논증의 공통 골격**이다.
아래 §12에 **따라 하면 안 되는 부분**을 따로 적었다. 그것까지 봐야 학습이 끝난다.

---

# 1. 결론을 먼저 놓는다

> *"일단 결론부터 그냥 먼저 말씀드리자면, 1940년대의 핵심은 YCC만으로 부채를 녹였다가 아닙니다."*

배경 설명으로 시작하지 않는다. **반박 명제를 첫 문장에 놓고 나머지를 근거로 쓴다.**
독자는 결론을 알고 읽어야 근거의 무게를 잴 수 있다.

# 2. 반박 대상을 실명으로 특정한다

> *"장기금리 몇 % 넘어가면 무조건 YCC 하면 되지, 미국은 절대 그렇게 높아지게 하지 않을 거야"*

**허수아비를 세우지 않는다.** 시장에서 실제로 유통 중인 문장을 그대로 인용해 과녁으로 삼는다.
과녁이 흐릿하면 반박이 아무것도 못 맞힌다.

# 3. ★ 유비를 부정하지 말고 **조건으로 분해**한다 (이 문서의 핵심 기법)

"1940년대와 지금은 다르다"고 말하는 건 아무 정보가 없다.
**"1940년대의 성공을 만든 조건이 무엇이었나"를 낱낱이 분해한 뒤, 조건별로 현재 성립 여부를 채점한다.**

| 1940년대 성공 조건 | 현재 성립? |
|---|---|
| YCC(장기금리 2.5% 상한) | 부분 — "소프트 YCC"에 그침 |
| 가격·임금 통제 | ✗ 정치적으로 불가능 |
| 배급제(휘발유 1942~45) | ✗ 전시 동원 명분 없음 |
| 금융억압(민간 금태환·보유 금지, 자본이동 봉쇄) | ✗ 자본이동 자유 |
| **압도적 원유 공급** | ✗ 공급탄력성 낮음 |

**유비는 결론이 아니라 감사 대상이다.** 이렇게 하면 "같다/다르다" 말싸움이
**조건 체크리스트**로 바뀌고, 반박 가능한 형태가 된다.

# 4. ★ 정책 변수와 물리 변수를 가른다

> *"금리는 중앙은행하고 재무부가 직접 영향을 줄 수 있지만, 원유는 물리적 공급을 만들 수 없다."*

**당국이 통제 가능한 것 / 불가능한 것**을 나누고, **불가능한 쪽에 취약점을 놓는다.**
정책 논쟁의 대부분은 통제 가능한 변수만 세다가 틀린다.
→ 볼트 판정 장치: [[YCC가 성공하느냐는 금리가 아니라 에너지 공급탄력성이 정한다]]

# 5. ★ 같은 정책 · 다른 결과를 비교한다 (자연실험적 사고)

1940년대와 1970년대는 **화폐 환경이 비슷한데 결과가 갈렸다.**
그러면 **갈린 원인이 진짜 변수**다. 여기서는 원유 공급 탄력성이었다.

> 40년대: 유가 상승 → 신규 산유국 생산 폭증 → 유가 정지
> 70년대: 유가 상승 → 미국 생산 정점 + OPEC 결집 → 오일쇼크

**"A일 때 B였다"는 근거가 약하다. "A일 때 B였고, A인데 C였던 적이 있다"가 강하다.**

# 6. 자기 논지의 반례를 먼저 꺼낸다

> *"그럼 유가는 어땠냐, 유가 안 올랐냐? 아니, 유가도 올랐습니다."*

논지에 불리한 사실을 **상대가 꺼내기 전에 내가 꺼내고** 그 자리에서 처리한다.
(유가는 올랐다 → 그런데 1948년에 멈췄다 → 왜? → 신규 공급)
이걸 안 하면 청중이 그 반례를 들고 논지 전체를 버린다.

# 7. ★ 비율 지표와 수준 지표를 반드시 같이 본다

미국 원유 점유율은 1948년 60% → 1970년 20%대로 **떨어졌다.**
여기서 "미국 공급이 줄었다"고 읽으면 정반대다. **같은 기간 미국 생산량은 늘었다.**
세계 총생산이 더 크게 늘어서 점유율이 희석된 것이다.

> **비율이 떨어졌다 ≠ 절대량이 줄었다.** 차트 두 장(점유율 / 생산량)을 나란히 놓아야 보인다.

이 함정은 볼트에서 이미 반복 확인됐다 →
[[헤드라인 PPI 플러스 전환은 디플레 수출 종료가 아니다]](총지수 vs 구성),
[[확장 Solow의 설명력 78퍼센트는 OECD 표본에서 무너진다 — R² 0.01]](전체 표본 vs 하위 표본).

# 8. AND 조건 체크리스트를 세우고 최약 고리를 지목한다

성공 시나리오를 **동시에 성립해야 하는 조건 N개**로 쪼갠다.
① 인플레 통제 ② 장기금리 < 명목GDP ③ 실질성장 플러스 ④ **에너지 안정** ⑤ 달러·국채 신뢰

**AND로 묶으면 하나만 깨져도 전체가 깨진다.** 그다음 "가장 취약한 고리는 ④"라고 지목한다.
→ 논쟁이 시나리오 전체가 아니라 **한 지점**으로 좁혀진다. 반박도 쉬워지고 관찰도 쉬워진다.

# 9. 당국이 무엇을 방어하는지 보면 급소가 보인다

> *"왜 베센트나 트럼프가 유가에 집착하냐 — 그래서 저 난리를 치는 거다."*

**정책 당국의 집착 대상을 그들의 취약점 신호로 역산한다.**
그들은 자기 계획의 급소를 안다. 무엇을 지키려 애쓰는지가 그 급소를 알려준다.

# 10. 경로를 건너뛴 결론을 금지한다

> *"40년대가 오니까 금 매수 — 이것조차 한두 단계, 세 단계를 건너뛴 것일 수 있다."*

"인플레 → 금"은 단축이다. 화자는 **순서**를 강제한다:
먼저 (B) 금리 상승 허용 국면이 오고, **그 뒤에** (A) 억압·통화절하 국면이 온다.
**결론이 맞아도 순서가 틀리면 포지션은 죽는다.**

# 11. 자산의 반응함수를 정확히 규정한다

> *"금은 단순히 CPI가 오른다고 헤지해 주는 게 아니다. 실질금리와 통화체제 신뢰에 민감하다."*

"인플레 헤지 자산"처럼 뭉뚱그리지 않는다.
**그 자산이 실제로 무엇에 반응하는지**를 적고, 그 변수로 시나리오를 나눈다.
→ 유가 급등 + 금리 억제 = 금 강세 / 유가 급등 + 실질금리 상승 허용 = 금 약세

# 12. 명목을 실질로 환원하는 습관

전사본 전체에서 반복된다 — *명목금리 = 실질금리 + 인플레*, *명목GDP = 실질 + 인플레*,
*"시장이 화폐착각을 많이 한다"*. 관찰 지표도 **10년 실질금리(명목 − BEI)**로 잡는다.
**명목으로 말하는 상대의 문장을 실질로 바꿔 다시 읽는 것**이 첫 검증이다.

# ✗ 따라 하면 안 되는 것 (같은 전사본의 결함)

기법만 배우고 아래는 배우지 않는다. **볼트가 이 화자를 `primary-source-biased`로 분류한 이유다.**

1. **핵심 주장에 정량 근거가 없다.** *"공급탄력성이 70년대보다도 낮다"* 가 논지 전체를 지탱하는데,
   근거는 "베네수엘라 리그 수가 1~2개"라는 일화 하나다. 셰일은 리드타임이 짧아 탄력성이
   **높다**는 반대 견해가 존재한다. **가장 중요한 전제일수록 숫자를 붙여야 한다.**
   → **2026-08-25 부분 해소**: 같은 화자의 다른 회차가 그 숫자를 제시한다 —
   **프런트 스프레드**(백워데이션 깊이 = 공급 비탄력성의 시장가격).
   [[2026-08-25_원유-선물곡선-캐리-대담]] 참조. **한 회차에서 빠진 근거가 다른 회차에 있을 수 있다** —
   같은 화자의 시리즈는 묶어서 감사한다.
2. **자기 논지에는 반증 조건을 걸지 않는다.** 상대 시나리오에는 5조건 체크리스트를 씌우면서,
   *"유가는 오른다"* 는 자기 주장이 **틀렸다고 인정할 조건**은 제시하지 않는다.
   → 볼트 규칙: 상대에게 씌운 체크리스트는 **자기 논지에도 씌운다.**
3. ~~수치를 표본·출처 없이 던진다~~ **→ 2026-08-25 철회. 이 화자의 수치는 정확했다.**
   1942 10.9 / 1943 6 / 1944 1.6 / 1945 2.3 / 1946 8.5 / 1947평균 14.4 / **1947-06 17%대** —
   FRED 실측과 **전부 0.2%p 이내**로 일치한다.
   **틀린 쪽은 볼트였다.** 잘린 전사본에서 *"47년 6월"* 이라는 시점 특정이 빠진 판본을 읽고
   "17%는 고점이 아니다"라고 반박했다. → 아래 §13 신설.
4. **결론이 보유 포지션과 일치한다.** 에너지 롱을 보유한 상태에서 "지금은 에너지가 가장 매력적"이라는
   결론을 낸다. 본문 중간에 자사 상품 광고가 들어간다. **논지의 질과 별개로 가중치를 낮춘다.**
5. **AND 조건의 필요성 자체는 논증하지 않는다.** 5개를 나열하고 하나가 어렵다고 전체를 기각하는데,
   **각 조건이 정말 필요조건인지**는 보이지 않는다. 조건을 많이 세울수록 기각은 쉬워진다.

# 13. ★ 잘린 텍스트로 반박하지 않는다 (2026-08-25 신설 — 볼트 자체 실패에서)

**볼트가 실제로 저지른 오류다.** YCC 대담의 *"CPI 전년비 17%"* 를 오류로 판정했는데,
당시 읽은 전사본에 **"47년 6월"이라는 시점 특정 대목이 잘려 있었다.** 완전본을 보니
화자가 맞았고 볼트가 틀렸다.

**교훈 세 가지:**
- **반박 전에 원문 완전성을 확인한다.** 특히 STT 전사본은 판본마다 잘린 위치가 다르다.
  같은 영상의 파일이 여러 개면 **가장 긴 것을 기준본으로 삼는다.**
- **"틀렸다"는 판정은 "맞다"보다 높은 증거 기준을 요구한다.** 반박은 인용보다 위험하다.
- **비교 도구를 검증하고 쓴다.** 같은 사건에서 파일 동일성 판정에 `difflib.quick_ratio()`를
  썼는데, 그건 **문자 빈도만** 비교한다. 같은 언어·같은 주제면 서로 다른 글도 0.999가 나온다.
  → 동일성은 **연속 구간 일치**(공통 부분문자열 · 실제 `ratio()`)로 판정한다.

# 압축 체크리스트 (분석 쓰기 전에 이 순서로 자문)

```
1.  결론을 첫 문장에 놓았나
2.  반박 대상을 실제 유통 중인 문장으로 특정했나
3.  역사 유비를 쓴다면 → 조건으로 분해하고 조건별로 채점했나
4.  통제 가능한 변수 / 불가능한 변수를 갈랐나
5.  같은 조건에서 다른 결과가 났던 시기를 찾았나
6.  내 논지의 가장 강한 반례를 내가 먼저 꺼냈나
7.  비율 지표를 썼다면 수준 지표도 같이 봤나
8.  성공 조건을 AND 리스트로 세우고 최약 고리를 지목했나
9.  당국이 무엇을 방어하는지 확인했나
10. 결론까지의 순서를 건너뛰지 않았나
11. 자산의 반응함수를 변수 단위로 규정했나
12. 명목을 실질로 환원해 봤나
13. ★ 내 논지가 틀렸다고 인정할 조건을 적었나   ← 전사본이 빠뜨린 것
14. ★ 인용한 숫자의 출처·표본·시점을 적었나     ← 전사본이 빠뜨린 것
15. ★ 내 결론이 내 포지션과 일치하는가          ← 일치하면 가중치를 낮춘다
16. ★ 남을 "틀렸다"고 하기 전에 원문 완전본을 봤나  ← 볼트가 실제로 틀렸던 지점(§13)
```

**13~15는 원 전사본에 없다. 볼트가 추가한 것이다.**
