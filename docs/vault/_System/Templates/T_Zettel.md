## 작성 규칙

1. **원자성** — 하나의 인과관계만. "그리고"가 두 번 들어가면 쪼갠다.
2. **노드 소환** — 지표·개념은 반드시 `[[ ]]`. 별칭이 있어 자연스러운 이름으로 써도 붙는다.
3. **지어내지 않는다** — 비유는 만들어도 되지만 사실은 만들지 않는다. 없으면 "원문에 없음".
4. **방향** — 화살표로 쓴다. 부호와 크기를 알면 적는다.
5. **출처 연결** — `related:`에 원 논문 노트를 걸어 제텔이 어디서 왔는지 추적 가능하게 한다.
