# 월별 지표를 이용한 분기예측모형

> 통계청이 1993년 개발한 증가율변수 공급모형과 1998년 개발한 수준변수 수요모형을
> 수정·보완한 **관청 실무 모형**이다. 학술논문이 아니라 통계기관의 운용 모형 문서로 읽어야 한다.

## 핵심 결과

- 목적: GDP 속보 발표 시차(당시 **분기 종료 후 1개월 20여일**)를 우회해
  **분기 종료 후 1개월 이내** 당분기 GDP를 예측
- 추정: 1990Q1~2000Q4 / 검증: 2001Q1~2002Q2 (6분기) post-sample + one-step ahead
- 두 계열 × 두 접근 = 4개 모형 비교 (증가율변수 / 수준(계절조정)변수 × 공급 / 수요)

**결과 요약**
1. **공급예측모형 > 수요예측모형** → 공급모형으로 전체 GDP를 먼저 예측한 뒤
   그 값을 전제로 수요모형을 운용하는 것이 바람직
2. 공급모형에서는 증가율 vs 수준 우열 판정 불가. **수요모형에서는 수준(계절조정) > 증가율**
3. **one-step ahead 오차 < post-sample 오차** → 새 데이터로 회귀계수를 갱신하며
   운용하는 편이 더 안정적
4. GDP 항등식 방법과 GDP 회귀모형 방법은 예측능력 차이 없음

**설명변수별 RMSE (표 4-4)**

| 부문 | 구성항목 | 설명변수 | RMSE |
|---|---|---|---|
| 공급 | 서비스업 | 서비스업취업자수 | **0.2%** |
| 공급 | 도소매·음식숙박 | **경기동행지수** | **0.2%** |
| 공급 | 도소매·음식숙박 | 도소매업판매액지수 | 0.8% |
| 공급 | 광공업 | 소매업판매액지수 | 0.9% |
| 공급 | 전기가스수도업 | 전기가스업생산지수 | 1.0% |
| 공급 | 광공업 | 광공업생산지수 | 1.2% |
| 공급 | 건설업 | 자본재수입액 | 1.1% / 건축허가면적 1.6% |
| 수요 | 설비투자 | 건설용중간재내수출하지수 | 2.2% |
| 수요 | 민간소비 | 도시근로자가계소득 | 2.3% |
| 수요 | 설비투자 | 기계류내수출하지수 | 2.7% |
| 수요 | 민간소비 | 자동차·연료판매액지수 | 2.9% |

→ 공급 쪽 설명변수는 대체로 RMSE 1% 내외, **수요 쪽은 2%대**. 이것이 결과 1의 실체다.

## 인과 사슬

월별 지표(생산지수·판매액지수·취업자수) → (부문별 회귀) → 부문 GDP
→ 합산 → 당분기 [[GDP 성장률]] 예측 → 판단시차 축소

공급 경로 오차(≈1%) < 수요 경로 오차(≈2~3%)
→ 공급 추정치를 먼저 확정하고 수요를 그 제약 아래 배분

**Comment**: 이 논문의 값은 **"GDP를 어느 쪽에서 추정하느냐가 정확도를 가른다"** 는 것이다.
같은 GDP인데 생산 쪽 월별 지표가 지출 쪽 월별 지표보다 훨씬 정확하다.
소비·투자는 월별 대리지표와의 연결이 느슨하고, 생산은 촘촘하다.
[[GDP 성장률]] 나우캐스팅 설계 시 **공급 쪽에 가중치를 두라**는 실무 지침으로 읽힌다.

## 현재 유효성 검증 (2026-07-27)

**전제는 절반 무효화됐다.** 논문의 출발점은 "GDP 속보가 분기 종료 후 1개월 20여일
(≈50일) 뒤 발표되어 경기판단이 1~2개월 지연된다"였다.
현재 한국은행 실질GDP 속보치는 **분기 종료 후 약 23일**에 발표된다
(2026Q1 → 4월 23일, 2026Q2 → 7월 23일). **시차가 절반 이하로 단축됐다.**

→ 논문의 **동기는 약해졌고 방법론은 유효하다.** 23일도 시차이며,
   분기 중 실시간 판단 수요는 그대로다. 다만 "1개월 이내 예측"이라는 목표 설정은
   이제 속보치 발표와 겨우 1주 차이라 실무적 이점이 작다.
   현재의 문제는 "속보보다 빨리"가 아니라 **"분기 중 매주 갱신"**(진정한 나우캐스팅)이다.

## 저자가 밝힌 한계

"GDP 구성항목에 더욱 근접한 통계자료를 설명변수로 채택하면 예측능력이 크게 개선될 것"이라며
유의성·포괄성 기준에 맞는 월별 자료의 지속 탐색을 후속 과제로 제시한다.
한계 절을 별도로 두지는 않았다.

## 검증 필요 · 반박 포인트 (Red Team)

**① 검증 표본이 6분기다** — 2001Q1~2002Q2. 4개 모형의 우열을 6개 관측치로 가렸다.
RMSE 0.2% vs 0.8% 같은 차이가 6분기 표본에서 안정적일지 알 수 없다.

**② 도소매·음식숙박업의 최우수 설명변수가 [[동행종합지수 (CCI·CCCI)]]다 (RMSE 0.2%)**
그런데 이 vault의 [[2012 월별 GDP의 추정과 경기지표 활용 가능성 (김명기·백웅기)]]는
동행종합지수가 **3년간 월평균 2.2p 상향조정**됐다고 실증했다.
→ **실시간 값과 확정 값이 다른 지표로 얻은 RMSE 0.2%는 실시간 성과가 아니다.**
   사후 확정된 동행지수를 설명변수로 쓰면 당연히 잘 맞는다. 이것이 **실시간 데이터 문제**
   (real-time data problem)이며, 논문은 이를 다루지 않는다.

**③ 공적분 검정을 했으나 구조변화는 다루지 않는다** — 1990~2000년은 IMF 외환위기를 포함한다.
1997~98년의 급격한 구조변화를 단일 회귀식으로 추정했다.

**④ 서비스업취업자수 RMSE 0.2%의 해석 주의** — 취업자수는 GDP의 **투입**이지 산출이 아니다.
서비스업 부가가치를 취업자수로 설명하면 생산성 변화를 상수로 가정하는 셈이다.
2000년대 이후 서비스업 생산성 변화가 컸다면 이 관계는 약해진다.
