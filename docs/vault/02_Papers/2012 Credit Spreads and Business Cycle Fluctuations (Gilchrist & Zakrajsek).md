# Credit Spreads and Business Cycle Fluctuations

> 📎 **Library 중복**: [[L424 Credit Spreads and Business Cycle Fluctuations]]에 같은 논문의 2차 요약(Manus AI 생성)이 있다.
> **이 노트가 정본이며, 수치는 여기서만 가져온다.**

## 1. 서지 · 한 줄 명제

> **한 줄 명제**: 이 논문은 **신용스프레드 중 기대부도로 설명되지 않는 잔차(초과채권프리미엄)**가
> **금융중개기관의 위험부담능력 축소**를 통해 **3~12개월 뒤 실물경제**에 영향을 준다는 것을 보여준다.

## 2~3. 연구 질문 · 문헌 공백

기존 문헌은 Baa–Aaa·CP–Bill 같은 **총계 지수**를 썼다. 문제는 이들이 (a) 만기·신용등급 구성이
고정돼 있고 (b) **기대부도 성분과 위험가격 성분이 섞여 있다**는 것.
이 논문은 **개별 채권 미시데이터**로 지수를 새로 만들고, 그것을 **두 조각으로 쪼갠다.**

## 4. 핵심 메커니즘

```
금융중개기관(브로커-딜러) 자기자본 훼손
        ↓
실효 위험부담능력(risk-bearing capacity) 축소
        ↓
**EBP ↑** (기대부도와 무관한 위험가격 상승)
        ↓
신용공급 축소
        ↓
소비·투자·고용 ↓ · 주가 ↓   [3~12개월 시차]
```

Bernanke-Gertler(1989)·Kiyotaki-Moore(1997) 금융가속기의 **가격 측 대리변수**를 만든 것이다.

## 5. 충격 분류

**주 충격 = 신용충격(Credit Shock)** — 정확히는 **신용공급충격**.
수요·기술 충격이 아니다. 핵심은 EBP 혁신이 *"orthogonal to the current state of the economy"*
라는 점 — 경기 상태를 통제한 뒤에도 남는 성분이다.

## 6. 전달경로

```
[[신용사이클]] 악화 → 중개기관 자본 ↓ → **EBP ↑** → 신용공급 ↓
   → [[산업생산]] ↓ · [[실업률]] ↑ · [[GDP 성장률]] ↓ · [[KOSPI|주가]] ↓
```

## 7. 핵심 변수

- **GZ 스프레드** — 개별 회사채 스프레드의 산술평균 (5,982개 증권, 1973:M1–2010:M9)
- **예측성분 $S^GZ** — Merton **distance-to-default**(DD)로 설명되는 부분
- **EBP = GZ − 예측성분** — 잔차. **이 논문의 발명품**
- 통제: 기간스프레드(3M−10Y), 실질 FF금리

**선행성**: GZ·EBP 모두 **선행**. 3개월·12개월 시계에서 유의.

## 8. 실증 전략

| | |
|---|---|
| 데이터 | 개별 회사채 5,982종 × Compustat × CRSP, 1973:M1–2010:M9 |
| 표본 처리 | 스프레드 5bp 미만·3,500bp 초과 제외, 액면 $1M 미만 제외, 잔존만기 1~30년 |
| 방법 | 예측회귀(OLS, 시차 AIC, Hodrick(1992) 표준오차) + 식별 VAR |
| **상관인가 인과인가** | 예측회귀는 **예측력**(인과 아님). VAR 부분만 **식별된 충격**으로 인과 주장 |

⚠ **벤치마크 점검 통과** — baseline(기간스프레드 + 실질FF + 자기시차)을 두고 **증분**으로 평가했다.
[[대안데이터의 기여는 Lag 벤치마크 대비 증분으로만 주장할 수 있다]]의 요구를 충족한다.

## 9. 주요 결과 (표에서 직접 옮김, 표준화계수 [|t|])

### 표2 — GZ 스프레드 vs 기존 지표

| 시계 | 지표 | 고용 | 실업률 | 산업생산 |
|---|---|---|---|---|
| **3개월** | CP–Bill | −0.165 [3.80] | 0.268 [13.8] | −0.332 [4.75] |
| | Baa–Aaa | −0.075 [2.05] | 0.198 [10.4] | −0.211 [3.08] |
| | **GZ** | **−0.322 [8.50]** | **0.351 [19.5]** | **−0.386 [5.28]** |
| **12개월** | CP–Bill | −0.080 [2.29] | 0.191 [36.0] | −0.226 [3.67] |
| | **Baa–Aaa** | **0.054 [1.15]** ✗ | 0.074 [11.2] | **0.004 [0.05]** ✗ |
| | **GZ** | **−0.497 [13.4]** | **0.453 [83.0]** | **−0.412 [5.11]** |

**12개월 시계에서 Baa–Aaa는 죽는다** (고용 t=1.15, 산업생산 t=0.05 — 부호마저 뒤집힘).
같은 시계에서 GZ는 t=13.4~83.0.

**설명력 증분** (고용 12개월): baseline Adj.R² **0.422 → GZ 포함 0.579** (+15.7%p).

### 실질 GDP (4분기 시계)

- **EBP +100bp → 향후 4분기 실질GDP 성장률 −1.5%p 이상**
- 예측성분 +100bp → **−0.5%p** (3배 차이)

- **GZ와 CP–Bill 상관 −0.17** (음수!) — 두 "신용지표"가 다른 것을 재고 있다

## 10. 레짐 의존성

**강해지는 국면**: 금융중개기관 자본이 훼손된 국면. 2007–09 위기에서 브로커-딜러 신용도 악화 →
CDS 프리미엄 급등 → **EBP가 거의 1:1로 따라 상승**.

**약해지는 국면 / 불안정**: 저자 본인이 각주11에서 **구조변화 가능성**을 인정한다 —
특히 **실질 FF금리 계수**. 1970년대말~80년대초 통화정책 운영방식 변화 때문.
그래서 1985–2010 부분표본 강건성 검정을 따로 돌렸다.

→ [[거시에서 관계는 구간별로만 안정적이다|확립 명제 6]]과 정합. 저자가 스스로 검사했다는 점이 이 논문의 품질 신호다.

## 11. 자산가격 함의

- **[논문 주장]** EBP 충격 → 소비·투자·고용·**주가** 유의하게 하락
- **[우리의 추론]** 원지수(HY OAS·Baa–Aaa)로 "신용시장이 침체를 가격에 안 넣었다"고 말하는 것은
  **이 논문이 기각한 독법**이다. 분해 전 스프레드는 기대부도와 위험가격이 섞여 있다
- **[우리의 추론]** 연준이 **EBP 시계열을 공표**하고 있으므로 대시보드에 직접 넣을 수 있다

## 12. 반증 조건

- **확증**: EBP 상승 후 3~12개월 내 고용·산업생산 둔화
- **반증**: EBP가 오르는데 12개월 뒤 실물이 멀쩡하거나, **원지수(Baa–Aaa)가 EBP만큼 예측한다면**
  분해의 존재 이유가 사라진다
- **감시 변수**: **EBP**(연준 공표) · GZ 스프레드 · 브로커-딜러 자기자본·CDS

**⚠ 볼트 내부 충돌 — [[신용스프레드의 조기경보 유효기간은 2주다]] (최재용 2023)**

| | 최재용(2023) | GZ(2012) |
|---|---|---|
| 종속변수 | **부도확률(Bloomberg DP)** | **실물경제**(고용·실업률·IP·GDP) |
| 빈도 | 일별 | 월별·분기별 |
| 유의 시계 | **−10영업일**, −12~−18일 비유의 | **3개월·12개월** 강력 |
| 표본 | 2008–2020, OAS>500bp 채권 선택 | 1973–2010, 5,982종 전수 |

**모순이 아니다 — 잰 대상이 다르다.** 최재용은 **가격 → 가격**(DP는 Merton형 구조모형 산출물),
GZ는 **가격 → 실물**이다. 최재용 제텔에 적어둔 *"두 시장가격 간의 선후 관계일 뿐"* 이라는
순환 가능성 지적이 **GZ로 확인된다** — GZ의 예측성분도 Merton DD로 만든다.

→ **신용스프레드의 시계는 "2주"가 아니다. 무엇을 예측하느냐에 따라 2주이기도 하고 12개월이기도 하다.**

## 15. 원문 대조에서 발견한 것

- **네 층 대조: 이상 없음.** 초록·본문·표가 일치한다. 초록의 "primarily"가 표6에서
  EBP 계수 > 예측성분 계수로 뒷받침된다
- **한계 절 존재** — 구조변화(각주11) · 콜옵션부 채권 처리(p18) · 표본 선택 기준 명시
- **종속변수 표본선택 없음** — 최재용(2023)의 치명적 결함이 여기엔 없다
- **✗ 단, 표본 외 검정이 없다.** 전부 **in-sample adjusted R²**다. 저자도 *"in-sample
  goodness-of-fit"* 이라고 정확히 쓴다. **"예측력"이라는 단어가 표본 외 성과를 뜻하지 않는다** —
  [[표본 내 1등이 표본 외에서도 1등이었다 — 단 방향은 셋 다 틀렸다]] 참조. **인용 시 반드시 명시**
- 표본이 **2010년 9월에 끝난다.** QE·마이너스금리·2020 코로나·2022 긴축이 전부 빠져 있다

## 17. 한 문장 요약 · 확신도

> **신용스프레드가 경기를 예측하는 이유는 부도를 알아서가 아니라, 부도로 설명 안 되는 부분이
> 금융기관의 위험부담능력을 드러내기 때문이다.**

**확신도: 상.** 표본 5,982종·37년, 벤치마크 명시, 한계 절 존재, 네 층 정합.
**유보 2가지**: ① 전부 표본 내 적합도 ② 표본이 2010년에 끝나 QE 이후 국면 미검증.
