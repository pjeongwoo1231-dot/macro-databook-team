# 해운은 어떻게 충격을 흡수하는가 — 2009년과 2020년의 비교 (Notteboom, Pallis & Rodrigue, 2021)

> *Maritime Economics & Logistics* 23(2). 같은 산업이 **수요 붕괴(2009)** 와 **공급·수요 연쇄 충격(2020)** 에
> 각각 어떻게 반응했는지를 같은 지표로 나란히 놓는다.

## 2008–09 금융위기 — 수요가 무너진 경우

| 지표 | 값 |
|---|---|
| 세계 컨테이너 수요(TEU-마일) | **2009년 −12.4%** |
| 신조 발주 취소 | 2008년 10월 기준 발주잔량의 **6.7%** |
| 계선(laid-up) 선복 | 2009년 4월 **130만 TEU = 선대의 10.4%**, 가을엔 **12% 초과** |
| 극동–유럽 항로 선복 | 2008년 10월~2009년 3월 **−21%** |
| 감속운항이 흡수한 선복 | 약 **30만 TEU = 선대의 2.3%** |
| 업계 영업손실 | 2009년 **200억 달러 이상**, 영업이익률 1~3분기 **−17~−19%** |

## 2020 팬데믹 — 공급 충격이 먼저 온 경우

- **2020년 2월**: 중국발 공급 충격 → 1차 결항. 아시아–유럽 항차의 **약 36%**, 태평양 왕항 선복의 **28%** 철회
- **2020년 4~5월**: 유럽·북미 봉쇄로 수요까지 붕괴 → 주요 항로 선복의 **최대 20%** 철회
- 아시아–미국 항로 결항률 **5월 19%**(249항차 중 47항차 취소)
- 일부 항만은 4~6월 기항이 **20%, 많게는 50%까지** 감소
- **그리고 반전**: 유휴 선복 비중이 **2020년 5월 11.6% → 10월 1.8%** 로 급락

## 이 논문이 주는 것 — '탄력적 공급조절'이라는 산업 특성

두 위기에서 선사가 쓴 도구는 같다 — **결항·계선·감속운항**. 다만 속도가 달랐다.
2009년에는 회복이 느려 계선이 1년 넘게 두 자릿수였던 반면,
2020년에는 **반년 만에 11.6%에서 1.8%로** 되돌렸다.

**즉 해운 운임은 수요만의 함수가 아니라 선사의 선복 회수 속도의 함수다.**
같은 수요 감소라도 공급조절이 빠르면 운임은 오히려 오른다 — 2020년 하반기 운임 급등이 그렇게 나왔다.

## 우리 문제와의 연결

[[지정학 판독 검증 대기열]]의 중간회랑·해운 축은 **물동량 경로 변화**를 본다.
이 논문은 그 축을 읽을 때 필요한 교정 장치를 준다 —
**"기항 감소 = 교역 감소"가 아니다.** 결항은 수요 신호이면서 동시에 **가격 방어를 위한 전략적 공급조절**이다.
홍해 우회·해협 봉쇄 같은 지정학 충격을 물동량으로 읽을 때, 선사의 의도적 선복 조절과 분리해야 한다.

## Red Team

1. **서술적 비교연구**다. 반사실(counterfactual)이 없어 "공급조절이 없었다면 운임이 어땠을지"는 알 수 없다.
2. 2020년 자료는 **연중 시점의 집계**라, 2021~22년의 극단적 운임 급등과 항만 적체는 범위 밖이다.
3. 컨테이너 부문 중심이다 — 벌크·탱커(우리 지정학 축에서 더 중요한)는 구조가 다르다.
4. 출처가 업계 데이터(Alphaliner 등)라 정의·집계 기준이 학술 표준화돼 있지 않다.
