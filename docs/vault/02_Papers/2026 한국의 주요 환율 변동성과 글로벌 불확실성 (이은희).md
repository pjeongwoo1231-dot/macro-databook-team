# 한국의 주요 환율 변동성과 글로벌 불확실성 (이은희, 2026)

> **2026년 2월 게재. 이 vault에서 가장 최근 논문 중 하나다.**
> 앞 논문([[2017 글로벌 금융변수를 고려한 원달러·엔달러·유로달러·위안달러 상호관계 (장한익)]])이
> 환율의 **수준 관계**를 봤다면, 이 논문은 같은 대상의 **변동성 구조**를 본다.

## 핵심 결과

**설계 (전문 확인)**
- 대상: **원/달러 · 원/엔 · 원/유로 · 원/위안** 4개 환율의 로그 수익률(평균 제거, %)
- 기간: **2016년 1월 ~ 2025년 8월, 일별**(자료 FRED). 2016년 시작 이유는 **2015년 8월 중국 환율제도 개편**(복수통화 바스켓 참고) 이후를 보기 위함 — 장한익(2024) 인용
- 모형 3종: ① 단일요인 **MSV** ② **2요인 MSV** ③ 개별요인에도 확률변동성을 허용한 **SMSVI**
- 추정: 베이지안 MCMC **10만 회**(번인 EUR 3만·나머지 2만), **Geweke CD 전부 |CD|<2**로 수렴 확인
- SV를 택한 이유: GARCH는 변동성이 과거 수익률에만 의존하나 SV는 **외생 교란항**을 허용

**① 사전 분석 — MSV를 쓸 근거를 먼저 만든다**
- 일변량 SV 추정: 변동성 지속성 **φ ≈ 0.94~0.97**, 로그변동성의 변동성은 **엔 0.045(최대) · 위안 0.029(최소)**
- 로그변동성 평균은 **JPY 최대 · CNY 최소**
- **레버리지 효과(비대칭성) 계수는 0.06~0.15로 전부 양수지만 90% 신뢰구간에서 비유의** → MSV에서 비대칭성 제외
- **PCA: 제1주성분이 환율 변동성의 약 85%를 설명** ← 공통요인 존재의 직접 근거

**② 공통요인의 설명력은 환율마다 크게 다르다 — 전문 정독으로 확보한 핵심 수치**

| 환율 | 공통요인이 설명하는 비중 |
|---|---|
| **USD** | **약 91%** |
| CNY | 약 72% |
| EUR | 약 54% |
| **JPY** | **약 46%** |

→ "공통요인이 상당 부분 설명한다"는 **USD에 한정된 이야기**에 가깝고, **JPY는 절반도 안 된다.**

**③ 공통요인을 늘리는 것은 답이 아니었다 (2요인 MSV의 실패)**
- 단일요인 SMSV 진단: 표준화 잔차 첨도 **5~6**, USD 제외 전 환율에서 **1% 수준 정규성 기각**,
  잔차 교차곱의 Ljung–Box 자기상관도 세 경우 빼고 **기각** → 이차 모멘트 결합 동태를 설명 못 함
- **JPY에 정규화한 두 번째 공통요인은 EUR·CNY에 미치는 영향이 크지 않다** → 요인 추가로는 개선 한계
- 반면 **개별요인 확률변동성을 넣은 SMSVI**: 왜도 ≈ 0, 첨도 ≈ 3, **KS 검정은 전 환율에서 정규성 기각 불가**,
  Ljung–Box도 **두 경우 빼고 기각되지 않음** → 결합 동태를 상당 부분 설명
→ 결론: **요인을 늘리기보다 환율별 고유 변동성을 허용하는 것이 정답**

**④ 개별요인 변동성의 시기별 특징**
- **CNY는 2022년에 개별요인 변동성이 가장 크게 상승** — 코로나 국면의 변동성은 공통요인으로 충분히 설명됐다는 뜻
- 2022년 미 긴축·2023년 이후 금융불안기에 개별요인 변동성이 전반적으로 상승했으나 **환율별 폭과 크기가 상이**
→ 같은 글로벌 충격에도 **환율별 민감도가 다르다**

**⑤ 공통요인과 불확실성 지표의 상관 — 유의하지만 크지 않다**

| 대상 | 상관계수 |
|---|---|
| **VIX** | **0.33** |
| 미국 EPU(전체) | **0.20** |
| 미국 **통화정책** 불확실성 | **0.44 (최대)** |
| 미국 국가부채·통화위기 | 0.32 |
| 미국 금융규제 | 0.31 |
| 미국 국가안보 / 정부지출 | 0.24 / 0.20 |
| 미국 **통상정책** | 0.16 (10% 유의) |
| **한국 EPU(전체)** | **0.25** |
| 한국 통화정책 / 외환정책 / 재정정책 | **0.39 / 0.35 / 0.27** |
| **한국 통상정책** | **0.085 — 비유의** |

→ 전부 양(+)이고 유의하지만 **0.2~0.44 수준으로 강한 상관은 아니다.**
→ 가장 강한 것은 **미국 통화정책 불확실성(0.44)** 이고, **한국 통상정책만 비유의**다.
→ EPU는 월별 자료라 일별 공통요인 변동성을 **월평균**해 비교했다(Bush·Noria 2021 방식).

## 모형 선택의 근거

저자가 밝힌 이유는 두 가지다. ① 변동성은 **비관측 변수**이므로 정의와 모형에 따라 결과가 달라지는데,
SV 계열이 ARCH/GARCH 계열보다 우수한 성과를 보인다는 선행연구(Danielsson 1994, Kim et al. 1998, Yu 2002, Poon·Granger 2003)가 축적돼 있다.
② 그럼에도 한국 환율에 SV를 적용한 연구는 **상대적으로 드물다** — 우도함수를 명시적으로 쓸 수 없어 추정이 어렵기 때문이다.
이 난점을 베이지안 MCMC로 우회한다.

## 인과 사슬

글로벌 위험·미국 경제 여건 → **비관측 공통요인 변동성** ↑
→ 원화 기준 대미·대일·대유로·대중 환율의 **변동성 동시 상승**
→ 공통요인 변동성은 [[VIX]] · EPU와 유의한 상관

**단, 공통요인만으로는 공분산 동태가 설명되지 않는다**
→ 각 환율의 **고유 변동성**을 허용해야 적합도가 개선
→ **"환율은 다 같이 움직인다"와 "각자 사정이 있다"가 동시에 참**

**Comment**: 이 논문은 [[원·달러 환율]] 노드에 **분해의 원칙**을 더한다 —
환율 변동성을 볼 때 **공통(글로벌 위험) + 고유(개별국 요인)** 로 나눠 봐야 하며,
공통 부분은 [[VIX]]·EPU로 **대리 관측이 가능**하다.
실무적으로는, VIX가 안정적인데 원화 변동성만 커지는 국면은 **고유 요인이 작동 중**이라는 신호로 읽을 수 있다.
다만 전문 정독으로 확인된 상관계수가 **0.33(VIX)·0.20(미 EPU)** 수준이라 **공통요인을 VIX로 대리하는 것은 거칠다.**
차라리 **미국 통화정책 불확실성(0.44)** 이 더 나은 대리지표다.
2026년처럼 미국 금리·관세·지정학이 동시에 움직이는 국면에서 이 분해는 특히 쓸모가 있다.

## 저자가 밝힌 한계

- SV 모형은 **우도함수를 명시적 형태로 쓸 수 없어** 추정이 어렵다는 점을 서론에서 명시한다(모형 선택의 제약 조건).
- 적합도 평가를 **표준화 잔차**에 의존한다(정보기준·예측력 비교는 주된 판단 근거가 아니다).

## 검증 필요 · 반박 포인트 (Red Team)

**① 상관관계이지 인과가 아니다**
공통요인 변동성이 VIX·EPU와 상관된다는 결과는 **해석의 근거**이지 방향성의 증거가 아니다.
VIX가 원화 변동성을 만드는지, 둘 다 제3의 요인에 반응하는지는 이 설계로 구분되지 않는다.

**② 공통요인이 USD에 정규화돼 있다 — 순환 위험**
저자 스스로 밝히듯 **공통요인은 USD 환율을 기준으로 정규화**되어 있고, 추정 결과에서도 USD 기여도가 가장 크다(91%).
"한국 외환시장은 미국에 민감하다"는 결론이 **부분적으로는 정규화 선택의 결과**일 수 있다.
JPY에 정규화한 두 번째 요인이 EUR·CNY를 잘 설명하지 못한 것도 같은 맥락에서 읽어야 한다.
→ USD가 아닌 다른 통화에 정규화했을 때도 같은 서열이 나오는지 확인이 필요하다.

**③ 모형 선택 기준이 적합도에 한정된다**
세 사양의 우열을 **표준화 잔차의 정규성·Ljung–Box 자기상관**으로만 판정한다.
**표본외 예측력(RMSE)이나 정보기준(DIC·WAIC) 비교는 제시되지 않는다.**
→ 이 vault의 반복 원칙: **적합도와 예측력은 다른 질문이다.**

**④ EPU 지수 자체의 한계**
EPU는 신문 기사 빈도 기반 지수라 **매체 구성과 검색어 정의에 민감**하다. 한국 EPU는 특히 표본 매체가 제한적이다.
