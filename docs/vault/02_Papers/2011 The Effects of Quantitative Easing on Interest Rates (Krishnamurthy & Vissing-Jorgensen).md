# The Effects of QE on Interest Rates: Channels and Implications for Policy

## 1. 한 줄 명제

> **QE는 하나의 경로로 작동하지 않는다.** 여러 채널이 자산마다 다르게 작용하므로
> **국채금리만 정책목표로 삼는 것은 부적절**하고, **무엇을 사느냐가 효과를 결정한다.**

## 2~3. 연구 질문 · 문헌 공백

QE1(2008–09)·QE2(2010–11)의 금리 효과를 **이벤트 스터디**로 평가한다.
기존 논의는 대체로 **국채금리 하락폭 하나**로 QE를 평가했다.

## 4. 핵심 메커니즘

```
연준의 장기 자산 매입
   ├─ **시그널링 채널** — 정책금리를 오래 낮게 유지하겠다는 신호
   ├─ **안전자산 수요 채널** — 장기 안전자산에 대한 고유 수요를 흡수
   ├─ **인플레이션 채널** — 기대인플레 상승 → 실질금리 ↓
   ├─ **MBS 조기상환 채널** (QE1 한정)
   └─ **회사채 부도위험 채널** (QE1 한정)
        ↓
   채널마다 **다른 자산**에 다르게 작용
```

## 5. 충격 분류
**주 충격 = 통화충격.** 단 **자산별로 분해되는** 충격이다.

## 6. 전달경로

```
[[통화정책]] 자산매입 → (5개 채널 분기) → 국채·MBS·회사채·[[BEI (기대인플레이션)]]에 **차등** 작용
```

## 7~9. 주요 결과

**① 채널이 다섯 개고, QE1과 QE2가 다르다**

| 채널 | QE1 | QE2 |
|---|---|---|
| 시그널링 | ✓ | ✓ |
| 장기 안전자산 고유수요 | ✓ | ✓ |
| 인플레이션 | ✓ | ✓ |
| **MBS 조기상환** | ✓ | ✗ |
| **회사채 부도위험** | ✓ | ✗ |

**② 무엇을 사느냐가 결정적이다**
*"effects on particular assets depend **critically on which assets are purchased**."*
→ **QE1의 MBS 매입이 모기지 금리를 낮추는 데 결정적**이었다.
국채만 사면 모기지 금리는 덜 내려간다.

**③ 기대인플레가 크게 올랐다**
10년 시계에서 기대인플레 **+117bp (다른 사양 +146bp)**, 둘 다 **1% 수준에서 유의**.
→ 명목금리 하락분의 상당 부분이 **기대인플레 상승**을 통한 실질금리 하락이다.

**④ 정책 함의**: *"it is **inappropriate to focus only on Treasury rates as a policy target**"*

## 10. 레짐 의존성
**QE1은 위기 국면**(신용스프레드 확대, MBS 시장 붕괴), **QE2는 정상화 국면**이었다.
같은 도구가 **국면에 따라 다른 채널로** 작동했다 — 위기 특유 채널(MBS·부도위험)이 QE2에선 사라졌다.

## 11. 자산가격 함의
- **[논문 주장]** 매입 자산 종류가 어느 금리를 움직이는지를 정한다
- **[우리의 추론]** QE 규모(달러 금액)만으로 효과를 추론하면 틀린다. **구성**을 봐야 한다.
  이는 [[2013 When Credit Bites Back (Jorda, Schularick & Taylor)]]에서 배운
  "총액이 아니라 구성" 원칙의 통화정책 버전이다
- **[우리의 추론]** 재무부 발행 구성(bill vs coupon)과 **대칭적 논리**다 — 누가 어느 만기를 사고 파느냐

## 12. 반증 조건
- **확증**: 매입 자산군의 금리가 비매입 자산군보다 크게 하락
- **반증**: 자산군과 무관하게 동일한 금리 하락 (= 단일 채널)
- **감시**: 매입 구성 · [[BEI (기대인플레이션)]] · 모기지-국채 스프레드

## 13~14. 연결
**보완**: [[2013 Flow and Stock Effects of Large-Scale Treasury Purchases (D'Amico & King)]] —
KVJ는 **채널 분해**, DK는 **시간 구조(플로우 vs 스톡)**. 서로 다른 축이다
**보완**: [[2011 A Model of Unconventional Monetary Policy (Gertler & Karadi)]] — 같은 정책의 **모형** 쪽
**방법 유보**: [[고빈도 서프라이즈는 자산가격 연구에는 유효하고 거시 충격 도구변수로는 오염돼 있다]] —
이벤트 스터디이므로 **자산가격 반응 측정에는 적합**하나, 실물 효과 추정에는 별도 식별이 필요하다

## 15. 원문 대조에서 발견한 것
- **네 층 정합.** 초록의 두 결론(단일 목표 부적절 / 매입 자산이 결정적)이 본문과 일치
- **강점: 채널을 나열만 하지 않고 QE1/QE2에서 다르게 나타남을 보였다** —
  같은 도구의 국면 의존성을 실증한 셈
- ⚠ **이벤트 스터디**다. 발표일 창 밖의 효과·지속성은 이 방법으로 잡히지 않는다

## 17. 한 문장 · 확신도

> **QE를 "얼마 샀나"로 평가하면 틀린다. "무엇을 샀나"가 어느 금리를 움직였는지를 정한다.**

**확신도: 중상.** 채널 분해가 체계적이고 QE1/QE2 대비가 명확하다.
**유보**: ① WP 대조본 ② **이벤트 스터디의 창 밖 효과 미포착** ③ 채널 간 상호작용은 분리되지 않는다.
