# 변동성전이지수의 시간가변적 특성 (박종해·정대성, 2022)

**방법** : Diebold·Yilmaz(2012) **변동성전이지수**. 한국·미국 금융시장(주식·채권·환율).

## 핵심 결과

### ① 순전이자와 순수용자가 명확히 갈린다

| 구분 | 순전이 |
|---|---|
| **미국 주식 · 미국 채권** | **양(+) = 순전이자** |
| **한국 주식 · 한국 채권 · 환율** | **음(−) = 순수용자** |

수익률 전이와 **변동성 전이에서 유사한 결과**. → **미국이 한국을 주도한다.**

### ② 금융위기 이후 전이 수준이 올라갔다

**금융위기 이전보다 이후에 변동성전이지수의 수준이 증가**했다.

### ③ 양적완화기에는 전이가 줄고, 출구전략기에 늘어난다 — 이 논문의 고유 발견

- **양적완화 지속 기간** : 변동성전이지수 **지속 하락 추세**
- **양적완화 축소·출구전략 이후** : 변동성전이지수 **증가 추세**

→ 저자 해석: **통화량을 축소하는 시점에 미국발 변동성 전이가 더 높아질 수 있다.**

## 인과 사슬

미국 [[통화정책]] 긴축(테이퍼링·QT) → 미국 주식·채권 변동성 ↑
→ **변동성 전이지수 ↑** → [[KOSPI]] · 국내 채권 · [[원·달러 환율]] 변동성 ↑

**Comment**: **"미국이 한국을 주도한다"에 국면 조건을 붙인 것**이 기여다.
유동성을 푸는 국면에는 전이가 약해지고 거두는 국면에 강해진다.
→ [[매크로 분석 레이어 설계]]에서 내가 추정한 **미 주가 → 코스피 갭 β=0.59**도
**QT 국면에서는 더 클 수 있다**는 뜻이 된다(직접 검정하지는 않았다).

## Red Team

**② 전이지수는 예측오차 분산분해 기반이라 변수 순서·시차에 민감**하다. 강건성 보고 확인 필요.
