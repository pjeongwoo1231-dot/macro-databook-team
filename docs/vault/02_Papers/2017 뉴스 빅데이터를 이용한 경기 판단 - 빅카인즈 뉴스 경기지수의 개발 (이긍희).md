# 뉴스 기사 건수만으로 만든 경기지수가 경기선행지수·경제심리지수보다 침체국면을 더 잘 예측한다 (이긍희, 2017)

> 2017.2.20 접수 / 2017.4.1 수정 / 2017.4.26 채택. 한국방송통신대학교 2015년 4분기 학술연구비 지원.

## 왜 중요한가 — 우리 문제와 직결

[[한국 경제심리지수(ESI) 구축 (Moon 2011)]]은 BSI·CSI라는 **서베이 기반 지표**가 GDP보다 2~3개월 빠르다고 했다. 이 논문은 한 단계 더 나아가 묻는다 — "서베이보다도 빠른 게 있지 않은가?" 답은 **뉴스 기사 건수**다. 서베이는 표본을 설계하고 매월 조사해야 발표되지만, 뉴스 기사는 사건이 일어나는 즉시 쌓인다. 이 논문은 한국언론진흥재단의 빅카인즈(BIGKINDS) 시스템에서 "불황"·"경기침체" 같은 49개 키워드의 **월별 기사 건수**만으로 지수를 만들고, 이것이 실제로 경기선행지수·경제심리지수와 밀접하게 움직이며 **경기 수축국면 예측에서는 오히려 더 우수하다**는 것을 실증한다. [[2013 중국 경제 선행지표의 유효성에 관한 연구 (김동하)]]가 중국 CCI의 표본 대표성 문제를 지적한 것과 대비해서 읽으면, 이 논문의 "표본 없이 4천만 건 뉴스 전수"라는 접근은 대표성 문제 자체를 우회하는 방법론적 대안이다.

## 문제의식과 방법론

**빅카인즈**: 한국언론진흥재단이 1990년 이후 42개 언론사(중앙지+지방지+방송)의 뉴스 기사 약 4천만 건을 일별로 축적·자연어처리한 시스템(2016년 공개). 선행연구들(송치영 2005, 이완수 외 다수)은 소수 신문의 일부 기사만 다뤄 대표성·시계열 길이에 한계가 있었는데, 빅카인즈는 이를 극복한다.

**빅카인즈 뉴스 경기지수(BKI) 작성 4단계**:
1. 경기 관련 키워드 49개(호황군/불황군/일반경제용어)를 선정해 월별 기사건수 추출 — 언론사 그룹은 전국지·중앙지·주요지(1990년 이후 시계열 완비된 6개지: 경향·문화일보·서울신문·세계일보·한겨레·한국일보)로 구분
2. ESI 상관계수 절댓값>0.5 & 경기선행지수 상관계수 절댓값>0.4 기준으로 최종 4개 키워드 쌍(불황/호황: 불황·경기침체·경기불황·경제불황 ↔ 호황·경기회복·경기호황·경제호황) 확정, 6개 키워드 버전(디플레이션·인플레이션, 금리인하·금리인상 추가)도 병행 검토
3. X13-ARIMA-SEATS(X11필터)로 계절조정
4. BSI 방식으로 합성: `BKI = (호황지표−불황지표)/(호황지표+불황지표)×100+100` (0~200 사이, 100이 중립)

**유용성 검증**: Double HP필터(λ=13.93/133107.94, OECD 경기선행지수 작성과 동일 필터)로 순환변동치 추출 → 교차상관분석·전환점분석 → 로짓모형(설명변수=순환변동치, 종속변수=경기수축국면 더미)으로 예측력 비교.

## 핵심 결과

**① 키워드-경기지표 상관관계**: 4개 키워드 확정 근거가 된 상관계수(중앙지 기준, 〈표 3.3〉) — "불황" 키워드와 ESI −0.81, 경기선행지수 −0.46; "경기침체"와 ESI −0.72. 호황 관련어는 대체로 상관이 약함(예: "호황"과 ESI −0.04) — **뉴스는 호황보다 불황에 더 민감하게 반응**한다는 것이 이 단계에서부터 드러난다.

**② BKI와 경기지표 간 상관관계(〈표 3.6〉, 중앙지·4개키워드)**: 동행지수 순환변동치 0.48, **선행지수 순환변동치 0.68**, BSI 0.73, CSI 0.80, ESI 0.77, ESI 순환변동치 **0.83**. 개별 호황·불황지표보다 이를 합성한 BKI 쪽이 상관이 항상 더 높았다.

**③ 순환변동치 교차상관·시차(〈표 4.2〉)**: BKI 순환변동치는 경기선행지수 순환변동치에 **2개월, 상관계수 0.77**; 경제심리지수 순환변동치에 2개월, 0.80; 네이버 검색 경기지수 순환변동치(이긍희·황상필 2014)에 1개월, 0.81로 선행한다.

**④ 전환점 분석(〈표 4.3〉)**: BKI 순환변동치의 전환점 선행시차는 경기선행지수 순환변동치와 **평균은 같지만(6.5개월) 표준편차가 1.7개월 더 작다** — 즉 선행 폭은 비슷한데 그 폭이 훨씬 안정적(예측 가능)이다. 특히 경기 **정점**에서 표준편차가 1.8~2.6개월 더 작아 안정성 우위가 두드러진다.

**⑤ 로짓모형 경기 수축국면 예측력(〈표 4.5〉, 검증기간별 정확도)**: BKI 순환변동치를 쓴 로짓모형의 정확도는 시차 k=0/2/4, 검증기간①②③에서 **0.84~0.99**로, 경기선행지수(0.69~0.93)·경제심리지수(0.40~0.51)를 쓴 모형을 전 구간에서 압도한다. 특히 경제심리지수 기반 모형은 검증기간③(2011~2016)에서 정확도 0.40~0.51까지 떨어져 사실상 무용했다. 민감도(실제 침체를 침체로 맞춘 비율)에서도 BKI가 우월했으나, 특이도(실제 확장을 확장으로 맞춘 비율)에서는 경기선행지수가 근소하게 나은 구간도 있었다 — **뉴스 기반 지수는 침체 포착에 강하고 확장 국면 판별에는 상대적으로 약하다**는 저자의 해석과 일치.

## 저자가 밝힌 한계

- 빅카인즈 데이터베이스에 **판매부수 상위 3개 신문(조선·중앙·동아일보)이 빠져 있고**, 언론사별 축적 시작 시점이 제각각이라 완전한 대표성은 없다(다만 저자는 "동일 사건에 대한 보도 유사성"을 근거로 큰 문제는 아니라고 판단).
- 6개 키워드 확장판 중 "호황지표"는 M7 지표 기준 계절성이 식별되지 않았음에도 계절조정을 강행했다는 한계를 스스로 명시.
- 네이버 검색 경기지수는 2007년 이후 자료만 있어 로짓모형 예측력 비교에서 제외 — 검색 기반 지표와의 정면 비교는 이 논문에서 이뤄지지 않았다.
- 후속 과제로 ① 3대 신문 데이터 확충, ② 고용·물가 등 다른 분야 키워드군 개발, ③ 로짓모형 외 다양한 예측모형 적용, ④ 경제성장률·민간소비 등 실제 거시변수 예측에의 응용을 제시 — 즉 **이 논문 자체는 "경기 수축국면 유무"라는 이진 판별까지만 다루고, 성장률 수준 예측까지는 하지 않았다.**

## 우리 시스템에 적용

- **경기 침체 여부를 조기 판별하는 용도로는 서베이 기반 지표(ESI/CCI)보다 뉴스 텍스트 지수 쪽의 예측 안정성이 실증적으로 더 높다.** macro-databook이 국내 경기 국면(확장/수축) 판별에 참고지표를 늘릴 때, 서베이 심리지수 하나에 의존하지 말고 뉴스 볼륨 기반 지표를 함께 볼 근거가 된다.
- 다만 이 논문의 강점은 **"침체냐 아니냐"라는 이진판별**이지 성장률 수준 추정이 아니다 — [[K-SuperCast]]·[[2024 동적요인모형에 기반한 한국의 GDP 성장률 예측 (Lee&Lim)]] 같은 "수준 예측" 계열과는 상호보완적으로 취급할 것.
- 여기서 검증한 "불황 민감·호황 둔감" 비대칭성은 뉴스 기반 지표를 해석할 때마다 반복 적용할 원칙 — 뉴스 지수가 급등(악화)하면 신뢰하되, 완만한 개선 신호는 과신하지 말 것.
- 키워드-경기지표 상관계수를 이용해 지표를 선별하는 방법론(사전 스크리닝 → 주성분 분석으로 그룹화)은 [[대안데이터 파이프라인 구조]]·[[공식발표 통계지표의 적시성 확보를 위한 대안 데이터 파이프라인 구축제안]]이 제안하는 대안데이터 파이프라인에 바로 적용 가능한 구체적 사례다.
