## 연구 목적
- GDP 분기 성장률 예측에 딥러닝 시계열 모형(앙상블 + 적응적 학습)을 적용
- 코로나19처럼 급격한 경기변동 구간에서 딥러닝이 전통 머신러닝보다 우수한지 검증

---

## 해결하려는 과제

- GDP 성장률 관측치는 2000년 이후 약 80여 개뿐(극소표본) vs 후보 거시지표 145개 → 차원의 저주
- 지표별 발표시차 불일치(ragged-edge data)
- → MIDAS·DFM처럼 별도 보간모형을 두지 않고, 딥러닝이 직접 패턴을 학습하도록 설계

## 제안 모형

**앙상블 딥러닝 GDP 예측모형**
: 145개 경제지표(14개 부문)를 14개 그룹으로 나누고, 그룹별 GRU 기반 Encoder-Decoder(seq2seq)를 학습한 뒤 결과를 앙상블(총 25개 모형 평균)
- ragged-edge 처리: 보간·외삽 대신 미공표 시차 데이터를 제외하는 Shift 연산으로 재정렬
- 월초마다 전망치 재산출(분기당 3회: 첫째~셋째 달 초) → 매월 갱신되는 적시성 확보

```
145개 월별 거시지표 (14개 부문 그룹)
↓ (그룹별 GRU Encoder-Decoder, 12개월 입력)
그룹별 예측치 25개 모형
↓ (단순 평균 앙상블)
당분기 GDP 성장률 nowcast
```

---

## 핵심 실험 결과

**동적 최적화 + 그룹정보 지표선택의 효과**
: 2018.4Q 고정모형 대비, 매분기 재학습(동적 최적화)하고 부문 그룹별로 지표를 강제 분산선택하면 MAE 0.513 → 0.429로 개선
- 단순 상관 기반 지표선택은 특정 부문(산업활동)에 지표가 편중되고 5~7개 부문이 통째로 누락되는 문제 발생 → 그룹정보 반영이 안정성에 결정적
- 코로나19 이후 데이터 변동성이 커질수록 도메인 지식(그룹 정보) 활용의 효과가 더 커짐(누적오차 비교)

**코로나19 구간 머신러닝 대비 성능**
: 2020 Q1~Q2 급락 구간에서 머신러닝(RF/XGBoost/LGBM) MAE 약 0.9 내외 vs 딥러닝(그룹기반) MAE 0.4대
- 딥러닝이 경기 변곡점의 비선형성 포착에 상대적으로 유리함을 시사

## 한계 및 시사점

- 관측되지 않은(unseen) 경기 국면 예측 불가, 인과성 설명 불가 → 정책 활용 시 신뢰성 제약
- 단순 데이터 추가보다 최적 후보모형 선택·조합을 위한 메타 알고리즘(AI 운영화 기술) 필요성 강조
- 향후 저빈도 거시지표를 고빈도 빅데이터로 대체하면 적시성·예측력 추가 개선 기대 → [[공식발표 통계지표의 적시성 확보를 위한 대안 데이터 파이프라인 구축제안]]과 문제의식 연결
