# 애널리스트 투자의견과 목표주가의 투자가치

> KCMI 이슈보고서 26-05 (2026.2.12) — 김준석

## 연구 설계

- 데이터: 2000~2024년 국내 상장기업 애널리스트 보고서 약 70만 건 (투자의견 695,304건, 목표주가 604,182건)
- 방법: 캘린더-시점(calendar-time) 포트폴리오. 개별 정보 기준 + 컨센서스 기준(월별, 산업-중립 4분위). 벤치마크 3종(CAPM, DGTW 특성조정, Carhart 4요인)
- 표본 구분: 전체 / 2000~2012 / **2013~2024** — 2013년 = 시장질서 교란행위 규제 발표 + CJ E&M 미공개정보 유출사건

## 핵심 결과

1. **투자가치 존재 (전체 기간)**: 투자의견이 긍정적일수록 초과수익률 상승 — 매도 -0.92%/월, 매수 +0.33%, 적극매수 +0.56% (CAPM). 매수-매도 롱숏 +1.01%/월
2. **투자의견과 목표주가는 독립적 투자가치**: 결합 시 성과 상승 — 2012년 이전 매수+목표주가 상향 롱숏 +1.14%/월(연 14.6%). 컨센서스 결합(투자의견 LL & 예상수익률 LL)의 초과수익률 -1.46% — 둘 다 부정적일 때 신뢰성 높은 정보
3. **중소형주에서 유의**: 가치가중 시 유의성 하락 — 투자가치는 대형주보다 중형주 중심 (해외 연구와 일치)
4. **2013년 이후 투자가치 소멸**: 2013~2024년 표본에서는 어떤 포트폴리오·벤치마크에서도 유의한 초과수익률 없음. 5년 이동구간 분석에서 2013년 전후 t-통계량 급락

## 소멸의 원인 진단

- **정보우위 감소**: 2013.4 '주가조작 등 불공정거래 근절 종합대책'(시장질서 교란행위 규제 — 2차 이후 정보수령자도 처벌) + 2013.10 CJ E&M 사건(애널리스트가 미공개 실적정보를 펀드매니저에게 유출, 유죄 확정) → 기업-애널리스트 소통 위축, 정보력 약화. 규제 강화 이후 이익예측 오차 증가(조수지·양철원 2018), 보고서가 실적발표 직후에 집중(김준석 2026)
- **낙관적 편향 고착**: 매수의견 편중 심화 — 매수 포트폴리오 종목 수 380(2000)→563(2024), 보유는 402→134. 적극매도는 표본에 단 1건도 없음
- **변별력 약화**: 투자의견 컨센서스 상하위 격차 1.12→0.74, 예상수익률 컨센서스 격차 61%→39%
- 시장효율성 개선(정보기술 발전·거래비용 하락)도 배제할 수 없으나 미국 십진법 호가 같은 구조적 사건이 없어 간접 요인으로 평가

## 시사점

- 애널리스트의 경제적 역할(정보 생산·중개, 시장 감시)은 정보력·분석력·객관성·정확성이 전제 — 투자가치 소멸은 본질적 기능에 대한 우려
- 애널리스트: 대체정보 활용, 새 분석기법, 분석 영역 차별화 / 낙관 편향 축소(리서치 독립성, 객관성 기준 평가·보상)
- 정책: 공시정보 질 제고, 기업-애널리스트 공식 소통경로 강화(2024년 IR행사 미개최 상장사 73%), 비재무정보 공시 활성화 — 미공개정보 규제가 시장 전체 정보량 감소로 이어지지 않도록
