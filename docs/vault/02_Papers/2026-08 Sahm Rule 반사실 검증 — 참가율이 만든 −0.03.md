# Sahm Rule 반사실 검증 — 참가율이 만든 −0.03

> **학회 발표용.** 2026-08-09 주제 확정, 2026-08-13 계산 완료.

## 한 줄 결론

> **의심은 정당했고, 측정 결과 지표가 맞았다.**
> 참가율 −1.2%p가 실업률을 눌러 Sahm Rule을 −0.03으로 만든 것은 사실이다.
> 그런데 **이탈자 중 실제로 일자리를 원하는 사람의 비율(α)을 재보니 약 7%**로,
> Sahm이 발동하는 문턱 **50%에 한참 못 미친다.**
> → **현재 Sahm 판정은 유지된다. 참가율 하락은 숨은 실업이 아니라 진짜 이탈이다.**

**이 분석의 구조**: ① 지표를 의심한다 → ② 의심을 정량화한다(반사실) →
③ **의심의 크기를 측정한다**(α) → ④ 판정.
③이 없으면 "모른다"로 끝난다. ③을 했기 때문에 **결론을 낼 수 있다.**

---

## 1. 왜 이 질문인가

Sahm Rule은 **실업률 하나로만** 만들어진다:

```
Sahm = (최근 3개월 실업률 평균) − (직전 12개월 중 3개월평균 최저치)
임계 0.50%p 이상이면 침체 진입 신호
```

그런데 실업률 = 실업자 ÷ **경제활동인구**다. **분모가 줄면 실업률이 떨어진다** —
고용이 하나도 늘지 않아도. 지금이 정확히 그 상황인지를 묻는 것이 이 분석이다.

## 2. 재현 — 그리고 빈티지 문제

자체 계산과 FRED `SAHMREALTIME` 대조:

| 월 | 자체 계산 | FRED SAHMREALTIME | 차이 |
|---|---|---|---|
| 2026-02 | 0.267 | 0.27 | 0.00 |
| 2026-03 | 0.233 | 0.20 | **0.03** |
| 2026-04 | 0.200 | 0.13 | **0.07** |
| 2026-05 | 0.100 | 0.10 | 0.00 |
| 2026-06 | 0.067 | 0.07 | 0.00 |
| **2026-07** | **0.000** | **−0.03** | **0.03** |

**차이의 정체는 데이터 빈티지다.** `SAHMREALTIME`은 **발표 당시의 미수정 데이터**로 계산하고,
자체 계산은 **현재 수정된 UNRATE**를 쓴다. 두 값이 다르다는 사실 자체가
[[실시간으로 본 CCCI와 지금 보는 CCCI는 다른 숫자다]]의 미국판 사례다.

> ⚠ **발표 시 주의**: "Sahm Rule = −0.03"이라고 인용할 때 그것은 **실시간 버전**이다.
> 사후 수정 데이터로는 **0.00**이다. 어느 쪽을 쓰는지 밝혀야 한다.

> *"61.9 → 61.4, 5개 구간 연속, 누적 −0.5%p"* 로 서술했다.
> **5개월만 본 수치였다.** 15개월로 넓히면 **62.6 → 61.4 = −1.2%p**로 **2배 이상**이다.

## 4. 반사실 설계

**질문**: 참가율이 떨어지지 않았다면 실업률은 얼마였을까?

```
반사실 경제활동인구  CF_LF = 생산가능인구 × (12개월 전 참가율)
추가 유입            Δ = CF_LF − 실제 경제활동인구
그중 실업자 비율     α  (핵심 가정)

CF_실업자 = 실제 실업자 + α·Δ
CF_취업자 = 실제 취업자 + (1−α)·Δ
CF_실업률 = CF_실업자 ÷ (CF_취업자 + CF_실업자)
```

**α가 이 분석의 유일한 자유모수다.** α=1은 이탈자가 전부 구직 포기자(discouraged worker)라는
**상한 가정**이고, α=0은 전부 자발적 은퇴·비경제활동이라는 **하한**이다.
**롤링 기준선**(각 시점의 12개월 전 참가율)을 써서 한 시점의 임의 선택을 피했다.

## 6. 핵심 발견 — 임계점은 α ≈ 50%

**전부 아니면 전무의 주장이 아니다. 갈리는 지점이 정확히 나온다.**

```
α ≥ 50%  →  Sahm Rule 발동      (반사실 0.50~1.02)
α = 30%  →  미발동              (0.30)
```

즉 **"참가율 이탈자의 절반 이상이 실제로는 일자리를 원했던 사람"이면
Sahm Rule은 이미 침체를 가리키고 있다.**

그리고 α=100% 시나리오에서 반사실 Sahm은 **0.99~1.02** — **임계의 두 배**다.
상한 가정이긴 하나, 여유가 아슬아슬하지 않다는 뜻이다.

## 6-2. α를 측정한다 — 이 분석의 핵심

§6까지는 α를 **가정**했다. 이제 **잰다.**

**측정 도구**: `NILFWJN` — *Not in Labor Force, Want a Job Now*.
**노동시장 밖에 있으면서 "지금 일자리를 원한다"고 답한 사람** 수(천명). 정확히 α의 관측 대응물이다.
보조로 `U6RATE` — U-6는 **한계참가자·구직단념자를 포함**하므로, 이탈이 실질 실업이면 **U-6가 올라야 한다.**

### 2025-04 → 2026-07 (15개월)

| 지표 | 시작 | 끝 | 변화 |
|---|---|---|---|
| 경제활동참가율 | 62.6% | 61.4% | **−1.2%p** |
| U-3 (공식 실업률) | 4.2% | 4.1% | −0.1%p |
| **U-6 (광의 실업률)** | 7.8% | **7.9%** | **+0.1%p** |
| **취업 희망 비경활 (NILFWJN)** | 5,691천 | **5,920천** | **+229천** |

### 계산

```
참가율을 62.6%로 되돌릴 때 추가 유입 Δ        = 3,233천
같은 기간 "취업 희망" 비경활 순증             =   +229천
                                              ─────────
관측 기반 α ≈ 229 / 3,233                    =   **7.1%**
```

### 두 가지가 같은 방향을 가리킨다

**① α ≈ 7%** — 임계 50%의 **7분의 1**. §6 표에서 α=30%조차 미발동(0.30)이었으므로,
**7%는 발동 근처에도 못 간다.**

**② U-6가 거의 안 움직였다** — 이게 더 강한 증거다.
U-6는 **한계참가자와 구직단념자를 분자에 포함**한다. 320만 명이 구직을 포기해 이탈했다면
**U-6가 크게 올랐어야 한다.** 실제로는 **7.8% → 7.9%, +0.1%p**에 그쳤다.
같은 기간 U-3는 오히려 **−0.1%p**다. **두 지표의 격차가 벌어지지 않았다.**

> 만약 이탈이 숨은 실업이었다면 **U-6 − U-3 격차가 확대**됐어야 한다.
> 실제: 3.6%p → 3.8%p. **거의 변화 없음.**

### 결론

**참가율 하락은 숨은 실업이 아니다.** 인구구조·은퇴·비경제활동 선택 등
**구직 의사가 없는 이탈**이 지배적이다.
→ **Sahm Rule −0.03은 왜곡이 아니라 유효한 판정이다.**

⚠ **α 추정의 한계**: Δ = 3,233천은 참가율을 고정했을 때의 **가상 유입**이므로,
그중 일부는 이탈자가 아니라 **애초에 진입하지 않은 신규 인구**다.
따라서 NILFWJN 증가분과 분모가 완전히 대응하지 않는다.
**정밀한 α는 이보다 다소 클 수 있으나**, U-6 증거(②)가 같은 방향이므로
**50% 근처일 가능성은 매우 낮다.**

## 7. 이 분석이 증명하는 것과 아닌 것

**✅ 증명한다**
- 현재 Sahm Rule −0.03은 **분모(참가율) 축소의 영향을 받았다** — 참가율 −1.2%p는 사실이다
- 그 영향이 **판정을 뒤집을 만큼인지**는 α에 달렸고, **임계는 α = 50%**다
- **측정된 α는 약 7%**이며, **U-6가 거의 안 움직였다**는 독립 증거가 같은 방향이다
- → **Sahm 판정은 유지된다.** 참가율 하락은 **숨은 실업이 아니다**

**❌ 증명하지 않는다**
- 침체가 오지 않는다는 것 — Sahm Rule은 **하나의 지표**일 뿐이다
- 참가율 하락의 **원인**이 무엇인지 (고령화 vs 이민정책 vs 자산효과) — **"구직 의사 없음"까지만** 확인
- α의 **정확한 값** — §6-2의 분모 대응 문제로 **7%는 하한에 가깝다**

## 8. 발표 구성 제안

1. **훅** — "실업률이 4.2에서 4.1로 떨어졌습니다. 좋은 소식일까요?"
2. Sahm Rule 소개 + 현재 **−0.03** (침체 신호 없음)
3. **의심 제기** — 참가율 **62.6 → 61.4**. 분모가 줄면 실업률은 저절로 떨어진다
4. **의심의 정량화** — 반사실 설계. α = "떠난 사람 중 몇 명이 사실은 일하고 싶었나"
5. **임계 발견** — α ≥ 50%면 Sahm 발동 (α=100%에서 0.99)
6. **"그래서 α는 얼마인가?"** ← 여기가 전환점
7. **측정** — 취업 희망 비경활 **+229천 / 3,233천 = 7%**, 그리고 **U-6가 안 움직였다**
8. **판정** — 의심은 정당했으나 **지표가 맞았다**
9. 닫기 — **"지표를 의심하는 것과 지표가 틀렸다고 결론 내리는 것은 다르다.
   의심은 반드시 측정으로 닫아야 한다."**

> **이 구성의 강점**: "유명 지표가 고장났다"는 흔한 결론보다,
> **"고장을 의심하고 검증했더니 멀쩡했다"** 가 훨씬 어렵고 정직하다.
> 그리고 α라는 **검증 가능한 문턱**을 남기므로, 다음에 참가율이 더 떨어지면
> **같은 틀로 재판정**할 수 있다.
