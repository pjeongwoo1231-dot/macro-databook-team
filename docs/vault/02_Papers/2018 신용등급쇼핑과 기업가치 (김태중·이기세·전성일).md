# 2018 신용등급쇼핑과 기업가치 (김태중·이기세·전성일)

## 무엇을 했나

**등급쇼핑(Rating Shopping)** = 회사채 발행기업이 자신에게 유리한 등급을 주는 평가사만 골라
공시하는 행위. 발행자가 수수료를 내는 구조에서 불가피하게 발생한다.

문제는 **관측이 안 된다는 것**이다. 최종 등급과 최종 평가사만 공시되므로 어느 평가사에
비공식 타진했는지를 알 수 없다. 저자도 이를 명시한다(p5): *"명확하게 등급쇼핑기업을
선별할 수 없고 이러한 큰 한계점 때문에 등급쇼핑에 대한 정교한 실증분석이 쉽지 않다."*

그래서 **대리변수**를 썼다 — **"신용등급이 상승 + 평가기관이 변경(증가·감소·교체)"** = 등급쇼핑.

- 표본: 2001~2015 유가증권시장 회사채 발행기업, 금융업 제외, 12월 결산
- 1,275개 → **등급 상승 건만** 골라 최종 **340건** (등급쇼핑 51 / 비쇼핑 289, 쇼핑 비중 15.0%)
- 종속변수: 공시일 전후 7일(−3, +3) 누적초과수익률 **CAR1**(개별기업) · **CAR2**(시장조정)

## 인과 사슬

발행자지불(issuer-pay) 수수료 구조 → 평가사 독립성 훼손 → **등급쇼핑** →
등급 상승 공시 → 주식시장 반응 → 자금조달 비용 하락

**Comment**: 이 사슬의 마지막 고리(자본조달 비용)는 **검증되지 않았다.** 저자도 한계에서
*"최종적으로 기업의 자본조달 비용에 미치는 영향을 검토할 필요성이 있다"*고 남겼다.
논문이 실제로 잰 것은 **주가 반응까지**다. "자금조달이 원활해진다"는 서술은 전부 추론이다.

## 실제 결과 (표 대조 완료)

**차이분석 (표4-3)** — 등급쇼핑 51 vs 비쇼핑 289

| 변수 | 쇼핑 | 비쇼핑 | t |
|---|---|---|---|
| CAR1 | 0.055 | 0.013 | 2.64\*\*\* |
| CAR2 | 0.047 | 0.004 | 2.91\*\* |
| SIZE | 27.475 | 28.144 | −3.16\*\*\* |
| ROA | 0.034 | 0.053 | −1.76\* |
| CH-SCORE(등급 상승폭) | 0.784 | 0.573 | 4.00\*\*\* |

→ **작고 수익성 낮은 기업이 더 크게 등급이 오르고 주가도 더 올랐다.**

**주 회귀 (표4-4)**: DUMMY 계수 **+0.045 (t=2.78\*\*\*)** / CAR2 **+0.044 (t=2.94\*\*\*)**
수정 R² **0.061 / 0.064**

**추가분석 (표4-5)** — 평가기관 증감 분리. **여기가 이 논문의 핵심이다.**

| | CAR1 | CAR2 |
|---|---|---|
| DUMMY1 (평가기관 **증가**) | **+0.048** (t=2.36\*\*) | **+0.049** (t=2.59\*\*) |
| DUMMY2 (평가기관 **감소**) | **−0.051** (t=−2.25\*\*) | **−0.041** (t=−1.99\*\*) |

→ **부호가 정반대다.** 평가사가 늘면 신뢰도 상승으로 읽히고, 줄면 등급쇼핑으로 읽힌다.

## 원문 대조에서 발견한 것

### ① 초록 · 본문 · 결론이 세 방향을 가리킨다

| 층 | 주장 |
|---|---|
| **국문초록** | *"주식시장 이용자들은 등급쇼핑에 관한 정보를 **정확하게 인지하지 못하고** 신용등급 상승정보만을 긍정적으로 판단하여 반응"* |
| **본문 4.5 (p18)** | *"이해관계자들은 발행사의 등급쇼핑현상을 **제대로 인식하지 못하고**"* |
| **결론 (p21)** | *"주식시장의 참여자들은 이를 **적절하게 기업가치에 반영하고 있음**을 알 수 있다"* |

**초록·본문과 결론이 정반대다.** 결론은 추가분석(감소 시 −)만 보고 쓴 것이고,
초록·본문은 주 분석(전체 +)만 보고 쓴 것이다. **둘을 화해시키는 문장이 논문에 없다.**

→ 인용 시 **가장 좁은 층**에 맞춘다: "시장이 등급쇼핑을 인지한다"는 **평가기관이 감소한
경우에만** 성립한다. 전체로 일반화한 결론 문장은 인용 금지.

### ② 이벤트 효과가 공시일에 없다

추세분석(그림4-1) 등급쇼핑 집단 CAR1: D−3 **0.017** → D−1 0.009 → **D 0.016** →
D+1 0.012 → D+2 **0.025** → D+3 **0.055**

**공시일(D)에는 아무 일도 없고 D+2~D+3에 효과의 대부분이 몰렸다.** 정보효과라면
공시일에 나와야 한다. 지연 반응이거나, 윈도우 안의 **다른 사건**(실제 회사채 발행일 등)을
잡았을 가능성이 있다. 서론 각주1의 세아베스틸 사례가 *"등급이 오른 지 12일 후 회사채 발행"* 이다.

### ③ 표 내부 정합성 오류 2건

- **표4-1**: CAR1 중위수 **90.014** — 0.014의 오타. 평균 0.019·1% −0.282·99% 0.269와 비교하면 명백
- **표4-3**: CAR1 t=**2.64**에 `***`(1%), CAR2 t=**2.91**에 `**`(5%) — **t가 더 큰 쪽 유의도가 낮다.** 표기 역전
- 같은 표에서 LEV t=0.94 / z=−0.32, FOR t=−1.33 / z=+1.68\* — **t와 z의 부호가 반대**

### ④ 종속변수로 표본을 골랐다

**"신용등급이 상승한 집단만"** 대상으로 했다(p5, 각주4). 등급쇼핑의 정의 자체가
"등급 상승 + 평가사 변경"이므로 **하락·유지 케이스가 구조적으로 배제**된다.
저자도 한계에서 *"평가기관을 변경하여 신용등급을 유지 또는 하락의 폭을 좁히는 것도
등급쇼핑으로 정의될 수 있으나 이를 전부 포함시키지 못하였다"*고 인정한다.
→ [[종속변수로 표본을 고르면 결론은 이미 정해져 있다]]

### ⑤ 설명력이 매우 낮다

수정 R² **0.054~0.071**. F는 유의하나 CAR 변동의 **93~95%가 설명되지 않는다.**
통제변수 중 유의한 것은 ROA 하나뿐이고 SIZE·LEV·BETA·FOR 전부 비유의다.

## 제도 배경 (인용 가능한 사실)

- 한국 신용평가사 **3개** · 발행자지불 구조 · **복수평가의무제** 시행 중
- 2012 금융위 「신용평가시장 선진화 방안」: 독자신용등급 도입, **구두의뢰·예상등급 제시 금지**
- SRE 지표 기준 신용등급 신뢰도가 **5점 만점에 4점을 못 넘음**
- 뒷북평가 사례: 대한해운(회생신청 직전까지 BBB+ → 신청 후 D) · 진흥기업 · 부산저축은행
- 이론: 복수평가는 등급쇼핑을 **줄이지만 완전히 제거하지 못한다**(강경훈·이준서 2011)
