## 정의

**Nowcasting**
: 공식 통계(GDP 등)의 발표 시차를 보완하기 위해, 더 빠르게 관측되는 자료를 이용하여 현재 진행 중인 분기·기간의 경제지표를 실시간으로 추정하는 기법
- 어원: 기상학의 초단기 일기예보(nowcasting)에서 차용 (Giannone, Reichlin & Small, 2008)
- forecasting(장기전망)과 대비되는 개념: 아직 공식 발표되지 않은 '현재'의 값을 추정

---

## 왜 필요한가

- GDP 등 공식 통계는 집계에 시간이 걸려 발표 시차 발생
  - 한국 GDP: 속보치(분기 종료 후 약 28~30일) → 잠정치(약 2개월/70일) → 확정치(약 1~2년)
- 발표 시차 동안 정책결정자·시장참여자는 경기 상황을 정확히 파악하기 어려움
- 해결책: GDP와 상관관계가 높으면서 더 빨리 발표되는 대체 자료(월별·일별·실시간)를 계량모형에 결합

---

## 핵심 방법론적 문제 2가지

**혼합주기 문제(Mixed Frequency)**
: 종속변수(분기)와 설명변수(월·일)의 관측주기가 다른 문제
- 해결: 교량방정식(단순평균), MIDAS(가중평균 학습), 동적요인모형(DFM)의 상태공간모형(자연스러운 결측 처리)

**Ragged-edge 문제**
: 설명변수마다 발표시차·최종 수집시점이 달라, 특정 시점 기준으로 일부 변수만 최신값을 가지는 결측 형태의 문제
- 해결: 칼만필터링(K-SuperCast), 빈티지 데이터셋(vintage dataset) 구성, 가중회귀 결측치 대체

---

## 방법론 분류

- **결합모형(joint model)**: 종속변수·설명변수의 결합분포 P(X,Y) 추정 → 동적요인모형(DFM)이 대표적. 혼합주기·ragged-edge를 결측으로 자연스럽게 처리, 변수별 해석 용이. 단, 대용량 데이터에서 계산비용 큼
- **부분모형(partial model)**: 조건부 분포 P(Y|X) 추정 → 교량방정식, MIDAS-회귀가 대표적. 계산 효율적이라 빅데이터 확장에 유리하나, 결측 대체를 별도로 해야 함

---

## 흐름 예시 (K-SuperCast)

```
86~93개 거시변수(발표주기 상이) 실시간 수집
↓
PCA로 소수의 팩터 추출 (차원의 저주 완화)
↓
팩터-GDP 관계 회귀추정 (일치성 확보)
↓
칼만필터링으로 최신 자료 반영해 팩터 업데이트
↓
GDP 성장률 실시간 추정치(nowcast) 산출
```

## 최근 확장 동향

- 대안데이터(신용카드 소비, 뉴스텍스트, 검색량, 모빌리티, 전력사용량, 교통량 등) 결합
- 머신러닝·딥러닝(LSTM, GRU 앙상블, 커널분위수회귀, 랜덤포레스트 등) 적용으로 비선형·비대칭 경기변동 반영
- 클라우드 기반 실시간 데이터 파이프라인 구축으로 지속가능한 운영 체계화
