# 분쟁 전까지는 견조했다 — **에너지가 그림을 바꿨다** (OECD Interim, 2026-03)

> OECD 중간 전망 "Testing Resilience"(2026-03). **볼트 보유 PDF 전문 판독.**

## 진단 (그림 목차가 곧 논지다)

- **분쟁 이전 글로벌 성장은 견조**했다
- **AI 낙관으로 기술 관련 생산이 빠르게 증가**했다
- **여러 대형 신흥국의 추정 관세율이 뚜렷이 하락**했다
- **지정학 위험이 급등**했고 분쟁이 **에너지 시장을 크게 교란**했다. **에너지 가격 급등**
- 중동 수출 의존도가 높은 나라가 많고, **가계 소비에서 에너지가 차지하는 비중은 나라마다 다르다**
- **금융여건은 긴축됐지만 여전히 완만하게 완화적**이다
- **인플레는 안정적이나 기대인플레가 최근 상승**했다
- 분쟁이 **성장·물가 전망을 상당히 바꿨고**, 에너지 가격이 더 오르면 추가 충격이 온다
- **미국에서 AI 채택이 높은 부문의 생산성 증가가 더 빨랐다**
- **정책금리 경로가 국가별로 갈리고 있다**. 여러 나라에서 **군사비가 증가**한다

## 우리 시스템에 적용

1. **"AI 채택 높은 부문의 생산성이 더 빠르다"는 [[총요소생산성 (TFP)]]의 C(과제 재편) 쪽 증거 후보**다 —
   현재 볼트 판정은 A(자본심화)이므로 **대립 증거로 등록**하고, 부문별 자료로 검증할 과제로 남긴다
2. **가계 소비의 에너지 비중이 나라마다 다르다**는 점은 한국 CPI 해석에 직결된다 —
   볼트는 이미 *"한국 인플레는 석유류 단일 품목 현상"* 이라고 판정했다
3. **정책금리 경로의 국가별 분기**는 [[기준금리]] 판정에서 *"미국이 올렸으니 한은도"* 금지 규칙을 강화한다
4. **관세율 하락**(신흥국)은 [[무역분쟁·관세]]의 방향과 반대 신호 — 지역별로 갈라 읽어야 한다

## Red Team

1. **중간 전망**이라 본편보다 근거 서술이 짧다
2. 그림 제목 중심으로 읽으면 **인과를 과하게 읽기 쉽다** — 특히 AI·생산성 관계는 상관 서술이다
3. 2026-03 시점이며 이후 에너지·분쟁 전개가 전망을 바꿨을 수 있다
