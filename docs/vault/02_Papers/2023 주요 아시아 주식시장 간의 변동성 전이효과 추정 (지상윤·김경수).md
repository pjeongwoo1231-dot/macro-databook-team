# 아시아 주식시장 변동성 전이 (지상윤·김경수, 2023)

**방법** : Hamilton **2국면 1시차 Markov 국면전환모형(MS)** + VAR을
**Diebold·Yilmaz 변동성 전이지수**와 결합. 미국·영국 + **아시아 10개국** 일별 → 주별 변동성.

## 핵심 결과

### ① 위기 중 전이가 확산되고 위기 후에도 지속됐다

금융위기 동안 전반적 전이 확산으로 주가 급등이 발생했고 **불확실한 환경이 위기 이후에도 지속**됐다.

### ② 유입 민감도는 **시장 개방성**과 연계된다

개별 아시아 시장이 **유입 변동성 전이에 얼마나 민감한지가 개방성 정도와 연결**된다는 증거.

### ③ 아시아도 점점 발신자가 되고 있다

금융위기 이후 관찰된 **유출 변동성 전이의 증가** →
**아시아 증시가 금융충격의 더 유의한 요인이 되고 있다.**

### ④ 그래도 미국이 우위다

**표본이동회귀(rolling regressions)** 에서
**미국 주식시장이 한국·일본·중국보다 상대적으로 우위**라는 일반적 패턴을 발견.

## 인과 사슬

글로벌 위기 → 변동성 전이 확산 → **아시아 각국 유입 전이 ↑** (개방성이 클수록 민감)
위기 이후 → **아시아의 유출 전이도 증가** → 일방향성 완화

**Comment**: [[미국→한국 증시 전이 MOC]]의 네 논문 중 **유일하게 "한국이 받기만 한다"에 단서를 다는** 연구다.
[[2008 우리나라와 주요 선진주식시장간 변동성 전이 (EGARCH-M)]]은 2008년 표본에서
**역방향 전이가 전혀 없다**고 했는데, 이 논문은 **위기 이후 아시아의 유출이 늘었다**고 본다.
→ **역방향 부재는 영구적 구조가 아니라 시기 의존적일 수 있다.**

또 **개방성 ↔ 민감도** 연계는 [[매크로 분석 레이어 설계]] 0장에서 다룬
"외국인 비중이 높으면 지수를 주도하는가" 논쟁과 맞닿는다 —
**노출도가 크면 받는 충격도 크다**는 것은 확인되지만, 그것이 **주도**를 뜻하지는 않는다.

## Red Team

**① 표·수치를 대조하지 않았다** — `flag/partial-check`. 초록의 정성적 결론만 확인.
**② 2국면 MS 모형**은 국면 수를 **사전에 2개로 고정**한다. 3국면이면 결과가 달라질 수 있다.
**③ 일별 → 주별 변환** — 정보 손실. [[2008 우리나라와 주요 선진주식시장간 변동성 전이 (EGARCH-M)]]에 단 것과 같은 경고.
**④ "개방성"의 측정 방식**이 초록에 없다. 자본계정 개방도인지 외국인 지분율인지 확인 필요.
