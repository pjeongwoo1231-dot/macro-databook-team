# GDP 성장률

> `type: indicator` — 논문(02_Papers)과 데이터(04_DataBook)가 만나는 접점 노트.
> 데이터 계열은 Data Book(`indicators.yaml`)의 정의와 연결돼 있다 — 아래 `## 데이터` 참조.

## 데이터

- 출처 : FRED `GDPC1` (실질 GDP, 분기) · `GDPNOW` (애틀랜타 연은 나우캐스트)
- 갱신 : 분기 / 나우캐스트는 수시
- Data Book tier : 1
- 스냅샷 : `04_DataBook/` (최신) · `04_DataBook/snapshots/*.json`

> `GDPNOW`는 확정 통계가 아니라 **실시간 추정치**다. 분기 확정치(`GDPC1`)와 구분해서 읽을 것.

## 판정 규칙

**어느 GDP인지 먼저 밝힐 것 — 생산이냐 지출이냐로 변동성이 2배 이상 다르다**

[[2012 월별 GDP의 추정과 경기지표 활용 가능성 (김명기·백웅기)]] 〈표 13〉 월별 GDP 전기비 성장률:

| | 표준편차 | **변동계수** |
|---|---|---|
| 생산GDP | 0.83 | **2.48** |
| 지출GDP | 2.01 | **5.81** |
| 분기 GDP | 1.20 | 1.16 |

→ **지출GDP의 변동계수가 생산GDP의 2배 이상**이다. 경기판단에는 **생산GDP가 안정적**이다.

**예측할 때** — [[2002 월별 지표를 이용한 분기예측모형 (민경삼·박진호·박순옥, 통계청)]]
- **공급예측모형 > 수요예측모형.** 공급으로 전체 GDP를 먼저 예측한 뒤 그 값을 전제로 수요모형을 운용
- 공급 쪽 설명변수 RMSE는 대체로 **1% 내외**, 수요 쪽은 **2%대**
- **one-step ahead < post-sample 오차** → 새 데이터로 계수를 갱신하며 운용하는 편이 안정적

**금지** : 월별 GDP 추정치를 인용하면서 **생산/지출 구분을 밝히지 않는 것**

**교차 확인** : `GDPNOW`는 확정치가 아니라 실시간 추정이다 → [[산출갭]]·[[잠재성장률]]과 함께 볼 것

## 이 지표에 대해 vault가 아는 것

- 나우캐스팅에는 두 갈래가 있다 — **예측**([[K-SuperCast]]: 다변수→팩터→당분기 GDP)과 **분해**([[2012 월별 GDP의 추정과 경기지표 활용 가능성 (김명기·백웅기)]]: 분기GDP→월별). 대체재가 아니라 보완재
- [[2024 동적요인모형에 기반한 한국의 GDP 성장률 예측 (Lee&Lim)]] — DFM+penalty 회귀가 ARIMA를 이기지만 **코로나 이전 우위 17% → 이후 1.8%**로 급감
- [[2021 텍스트 마이닝을 활용한 실질 국내총생산의 실시간 예측 (임상수·최항석)]] — 표를 뜯어보면 **유의한 변수는 Lag(1) RGDP 하나뿐**, 텍스트마이닝 BSI·CSI 계수는 전부 비유의(p=0.30~0.52)
