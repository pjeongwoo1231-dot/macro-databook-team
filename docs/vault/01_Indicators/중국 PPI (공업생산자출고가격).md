# 중국 PPI (공업생산자출고가격)

> **이 노트가 중요한 이유**: 중국의 "디플레 수출" 여부를 재는 지표다.
> [[RegimeView_2026-08]] 장기 축 트리거 **T-E의 판정 기준**이 여기 걸려 있다.

## ⚠ 데이터 수급 주의

**FRED의 중국 PPI 계열(OECD MEI)은 폐지됐다**(`CHNPPIALLMINMEI` 등 404, 2026-08-25 확인).
`CHNCPIALLMINMEI`(CPI)도 2025-04에서 멈췄다. **NBS 월간 보도자료가 유일한 실시간 1차 출처다.**
발표: 매월 9~10일경, 중문/영문 동시. 커넥터 미구축 → 수동 갱신 중.

**기준시점 변경**: 2026년 1월부터 **2025년을 기준(base=2025)**으로 편제한다.
지수 레벨의 시계열 비교 시 주의. 전년동월비는 계속 계산된다.

## 타임라인 — 41개월 디플레의 종료

| 시점 | 값 | 비고 |
|---|---|---|
| 2022-10 ~ 2026-02 | **41개월 연속 마이너스** | 중국 디플레의 골격 |
| **2026-03** | **+0.5%** | **41개월 만에 플러스 전환.** 전월비 +1.0% |
| 2026-06 | +4.1% | 고점 |
| **2026-07** | **+3.5%** | **전월비 −0.7%** — 모멘텀 반전 |
| 2026 1~7월 평균 | +1.8% | |

> 볼트의 기존 수치 *"PPI 37개월 연속 하락 −2.7%"* 는 **2025-05 시점 기준으로는 맞았다.**
> 그 연속 하락은 **41개월에서 끝났다.** 오래된 스냅샷을 현재값으로 쓰지 말 것.

## 구성 — **헤드라인만 보면 정반대로 읽는다** (2026-07)

| 구분 | 전년동월비 | 전월비 |
|---|---|---|
| **생산재** | **+4.8%** | −0.9% |
| ├ 채굴 | **+16.4%** | −0.2% |
| ├ 원재료 | +6.1% | **−2.4%** |
| └ 가공 | +3.1% | −0.1% |
| **소비재** | **−0.8%** | −0.1% |
| ├ 식품 | −2.1% | 0.0% |
| ├ 의류 | −1.1% | −0.3% |
| ├ 일용품 | −1.0% | −0.2% |
| └ 내구재 | +0.4% | 0.0% |

**구입물가지수**(투입 측): 전년비 **+5.5%**, 전월비 −1.0% (1~7월 평균 +2.8%)
→ **투입(+5.5%)이 출고(+3.5%)보다 빠르게 오른다. 마진이 눌리고 있다.**

## 읽는 규칙

1. **헤드라인 PPI 플러스 = 디플레 수출 종료가 아니다.**
   상승분은 전부 상류(채굴 +16.4%)에서 왔고 **소비재 출고가는 여전히 마이너스(−0.8%)**다.
   세계로 나가는 공산품 가격은 아직 내려가고 있다.
2. **따라서 디플레 수출을 재려면 소비재 PPI를 본다.** 헤드라인은 글로벌 원자재 가격을
   수입한 결과라 중국 내부 수요를 반영하지 않는다.
3. **전월비를 같이 본다.** 7월 헤드라인은 +3.5%인데 전월비는 −0.7%,
   원재료는 −2.4%다. 전년비 플러스에 기저효과가 섞여 있다.
