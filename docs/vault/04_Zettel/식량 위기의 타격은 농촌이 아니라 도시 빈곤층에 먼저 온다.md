# 식량 위기의 타격은 농촌이 아니라 도시 빈곤층에 먼저 온다

## 1분 요약

흑해 지역은 **25년 전만 해도 순 식량 수입지역**이었다. 지금은 아니다.

| 품목 | 러시아+우크라이나의 세계 교역 비중 |
|---|---|
| **해바라기유** | **73%** |
| 밀 | **34%** |
| 보리 | 27% |
| 옥수수 | 17% |
| 세계 교역 **총 칼로리** | 약 **12%** |

비료도 마찬가지다 — 러시아가 **질소비료 세계 교역의 약 15%**,
러시아+벨라루스가 **칼륨(potash) 수출의 33%**.

그리고 러시아는 에너지 수출국이기도 하다. **에너지는 식량·비료의 생산과 수송에 들어가는 투입**이므로,
같은 충격이 **세 경로로 동시에** 들어온다.

## 반직관적 핵심 — 누가 먼저 다치나

> 식량 불안정의 **절대 수준**은 여전히 빈곤 가구가 많은 **농촌**이 높다.
> 그러나 이번 위기와 그에 따른 식량가격 급등으로 **가장 크게 고통받는 것은 도시 빈곤층**이다.

이유는 구조에 있다 — 농촌 가구는 **생산자이기도 하다**(자가소비·판매가 상승 수혜).
도시 빈곤층은 **순 구매자**이며 소득 대부분을 식량에 쓴다.

**"어디가 가난한가"와 "어디가 충격에 취약한가"는 다른 질문이다.**

## 인과 사슬

```
[[지정학적 리스크]] ↑ (흑해) ─┬→ 곡물·유지 수출 차질 → 국제 식량가 ↑
                            ├→ 비료(질소·칼륨) 수출 차질 → **다음 작기의 수확 ↓**
                            └→ 에너지 ↑ → 생산·수송·가공 원가 ↑ → 식량가 ↑
   → 수출국들의 **수출 제한 정책** → **상황 악화** (저자 명시)
   → 식량 수입 의존이 높은 MENA → 도시 순구매 빈곤층 타격
   → [[CPI (소비자물가지수)]] 중 식료품 비중이 큰 나라일수록 정치 리스크
```

**정책 대응이 충격을 키운다** — 수출 제한은 각국에 합리적이지만 총합으로는 가격을 더 밀어올린다.
전형적인 조율 실패다.

## 왜 이게 중요한가 — 판정 규칙

| 관측 | 흔한 오독 | 이 논문의 판정 |
|---|---|---|
| 곡물가 급등 | 생산 부족 | **교역 차질**일 수 있다. 생산량과 교역량을 갈라 볼 것 |
| 비료가 급등 | 부차적 문제 | **다음 작기 수확에 시차를 두고 반영.** 위기가 1년 뒤에도 온다 |
| 수출 제한 확산 | 자국 보호 | **총합으로는 가격 상승 요인.** 위기 증폭 장치 |
| "농촌이 더 가난하다" | 농촌이 더 위험 | **도시 순구매 빈곤층이 더 취약** |

**시차 구조가 핵심이다.** 곡물 충격은 즉시, **비료 충격은 다음 작기에** 온다.
식량 위기를 단년으로 판정하면 두 번째 파도를 놓친다.

## 한계

- **2023년 초 논문**이다. 흑해 곡물 협정(2022-07~2023-07)의 종료와 그 이후 국면은 담기지 않았다.
- **취약성 유형 분류 + 기술적(descriptive) 증거**다. 인과 추정이 아니다.
  25개 지표로 만든 유형론이며 **가중치 선택에 의존**한다.
- WFP의 "급성 기아 4,700만 명 증가" 전망은 **WFP 인용치**이지 저자 추정이 아니다.
- 사례가 **이집트·수단·예멘**이다. **한국에 직접 적용할 결론이 아니다** —
  한국은 식량 수입 의존이 높으나 소득 대비 식료품 비중이 낮아 취약성 구조가 다르다.
- 저자들이 위기 이전부터 식량·비료가가 오르고 있었다고 명시했다
  (2021년 중남미·동남아·유럽 수확 감소, 코로나 공급차질, 아시아 수요 증가).
  **전쟁만의 효과로 귀속하지 말 것.**
