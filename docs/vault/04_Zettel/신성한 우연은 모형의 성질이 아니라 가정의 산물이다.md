# 신성한 우연은 모형의 성질이 아니라 가정의 산물이다

## 1분 요약

표준 뉴케인지언 모형에서는 **물가를 안정시키면 산출갭도 저절로 안정된다.** 중앙은행이
고를 게 없다. 저자들이 **"신성한 우연(divine coincidence)"** 이라 이름 붙인 이 성질은
**모형의 일반적 귀결이 아니라 "비자명한 실질 불완전성이 없다"는 가정의 산물**이다.
**실질임금 경직성 하나만 넣으면 사라진다.**

## 인과 사슬

```
표준 NK: 가격 경직성만 존재
   → 자연산출 = 효율적 산출
   → 물가 안정 = 후생 산출갭 안정
   → **중앙은행에 상충 없음**

+ 실질임금 경직성
   → 자연산출 ≠ 효율적 산출  (둘 사이에 쐐기)
   → **물가를 잡으면 산출갭이 벌어지고, 산출갭을 닫으면 물가가 흔들린다**
```

**왜 중요한가 — "상충이 없다"는 결론이 어디서 왔는지 추적해야 한다.**
중앙은행은 늘 상충을 느끼는데 모형은 없다고 한다. 둘 중 하나가 틀린 게 아니라
**모형이 특수 가정 위에 서 있었다.**

**이 볼트가 이미 관측한 것에 이름을 준다.** [[RegimeView 1.0 (2026-08-09)]] ④는
현 연준을 **"인하도 인상도 못 하는 비대칭 마비"** 로 서술했다.
그 상태의 이론적 정체가 **신성한 우연이 깨진 국면**이다 —
물가 안정과 산출·고용 안정이 같은 방향을 가리키지 않는다.

**추가 함의: 상충이 있으면 반응함수가 예측 대상이 된다.**
상충이 없으면 중앙은행 행동은 자동이다(물가만 보면 된다). 상충이 있으면
**어느 쪽에 얼마의 가중치를 두는지**가 선택 변수가 되고, 그 가중치는 **시기·국면에 따라 변한다** →
[[한은 반응함수는 상수가 아니다 — 시기별로 물가와 성장의 비중이 반전된다]] ·
[[한은은 물가 하회 시엔 성장을 보고 상회 시엔 물가를 본다]]가 **이론적 근거를 얻는다.**
볼트가 실증으로 먼저 발견한 것을 이 논문이 모형으로 설명한다.

**부수 성과**: 실질임금 경직성 모형은 데이터의 **동태적 물가–실업 관계**에 자연스러운 해석을 준다.

**확신도: 중상.** 명제가 명확하고 반증 조건이 분명하다.
**유보**: ① NBER WP(2005) 대조본, JMCB 최종본(2007) 미확인
② **실질임금 경직성이 미시 기초 없이 가정으로 도입된다** — 왜 임금이 경직적인지는 설명하지 않는다
③ 상충의 **크기**는 경직성 파라미터에 조건부다.
