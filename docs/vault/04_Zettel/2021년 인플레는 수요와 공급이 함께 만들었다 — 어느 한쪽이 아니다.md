# 2021년 인플레는 수요와 공급이 함께 만들었다 — 어느 한쪽이 아니다

## 1분 요약

"이번 인플레는 공급 문제다" vs "수요 과잉이다"는 2021~22년 내내 갈렸다.
이 논문은 **다수의 물가·실물 지표를 쓰는 구조요인모형**으로 둘을 갈랐다 —
**요인 적재(factor loadings)에 이론적으로 정당화된 부호 제약**을 걸어 식별한다.

미국에 대한 결과:

> **2021년 중반 이후의 인플레 급등은
> **극도로 팽창적인 수요 조건**과 **타이트한 공급 조건**의 **조합**으로 나타났다.**

유로존도 비슷하되 —
> **타이트한 공급의 역할이 다소 더 크다.**
> 최근의 불리한 **글로벌 에너지 가격** 충격에 유로존이 더 노출돼 있다는 점과 정합적이다.

**즉 "수요냐 공급이냐"는 질문 자체가 잘못됐다. 둘 다였고, 비중이 지역마다 달랐다.**

## 왜 이게 중요한가 — 판정 규칙

### ① 원인 배분이 정책 처방을 정한다

| 지배 요인 | 금리로 대응 가능한가 |
|---|---|
| 수요 | **가능하다** |
| 공급 | **어렵다** — [[공급충격을 통과시키는 정책은 기대가 앵커된 경우에만 성립한다]] |
| **둘 다** | **부분적으로만.** 수요분만큼은 잡아야 한다 |

→ **"공급 충격이니 통과시킨다"도, "수요 과잉이니 강하게 올린다"도 둘 다 반쪽이다.**

### ② 지역별 비중 차이가 정책 발산을 설명한다

유로존에서 공급 비중이 더 컸다는 사실은 **ECB와 연준의 반응 차이**를
"판단의 차이"가 아니라 **직면한 충격 구성의 차이**로 설명한다.

→ **한국에도 같은 질문을 해야 한다.** 볼트에는 이미 답의 일부가 있다 —
[[RegimeView_2026-08]] v1.4의 한국 CPI 특수분류 실측:
**한국 인플레는 석유류 단일 품목 현상**이고 **근원은 애초에 안 움직였다**(2~7월 +2.2~2.6% 박스).
**한국은 공급 비중이 압도적인 쪽**이라는 뜻이다.

### ③ 방법의 한계도 함께 본다

**부호 제약 식별**은 이론적 부호를 **가정**한다.
가정이 틀리면 분해가 틀린다 — 그리고 **자료로는 검증되지 않는다.**
볼트의 「모형이 사실을 재현했다」 판정 규칙(① 타깃 모멘트인가 ② 파라미터가 독립 측정됐는가)이
여기서는 **①에 걸린다.**

## 인과 사슬

```
팬데믹 재정·통화 대응 → **수요 조건 극도로 팽창적**
공급망 교란 + 에너지 → **공급 조건 타이트**
   → 둘의 곱 → 2021년 중반~ 인플레 급등
   ↘ 유로존: 에너지 노출이 커 **공급 성분이 더 큼**
   ↘ 한국(볼트 실측): **석유류 단일 품목** — 공급 성분이 압도적
```

## 한계

- **BIS 워킹페이퍼**다. BIS 공식 견해가 아니다.
- **부호 제약 식별**이며, 제약 자체가 결과를 만든다(위 ③).
- **미국·유로존**이다. 한국 분해는 이 논문에 없다 —
  위의 한국 언급은 **볼트 자체 실측**이지 이 논문의 결과가 아니다.
- **성분의 크기(몇 %p씩)를 이 노트에 옮기지 않았다.** 방향과 상대 비중만 인용한다.
- 2022년 논문이다. **2026년의 에너지 충격 국면에 그대로 적용할 수 없다** —
  다만 **방법(수요·공급 분해를 먼저 하라)** 은 그대로 유효하다.
