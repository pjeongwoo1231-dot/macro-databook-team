# 채점 결과 — 독일 가스 공급은 지켜졌지만 가격으로 지불했다

## 예측 (2022-04-13 시점)

DIW Berlin이 러시아 침공 6주 뒤 내놓은 판정. 당시 독일은 천연가스의 **약 55%** 를 러시아에서 샀다.

> **"에너지 절약 잠재력을 최대로 활용하고 다른 공급국으로부터의 도입을 기술적으로 가능한
> 최대치까지 확대하면, 러시아 수입 없이도 2022년과 2022/23년 겨울 독일의 가스 공급은
> 안전하다."**

조건이 명시된 예측이다 —

- **공급 측**: 다른 수출국의 대체 + **파이프라인·저장 인프라를 더 효율적으로 사용**
- **수요 측**: 단기 절약 잠재력 **현 수요의 19~26%**
- 중기: 재생 열원 전환과 에너지 효율

독일 가스 소비는 2020년 기준 **868 TWh(≈86.8 bcm)**, 산업 255 TWh(29%)·가계 252 TWh(29%).

## 채점 — 물량은 맞았고, 가격은 논점 밖이었다

### ✅ 물리적 공급: 예측대로 지켜졌다

독일은 2022/23년 겨울에 **가스 배급(Notfallstufe, 비상 3단계)에 들어가지 않았다.**
2022년 6월 발동된 것은 **경보 2단계(Alarmstufe)** 까지였다.
저장 인프라의 효율적 사용 + LNG 도입 확대 + 수요 감소라는 **경로도 예측대로**였다.

### ⚠ 그러나 가격은 예측이 발표된 **뒤에** 최악으로 갔다

IMF 유럽 가스가(FRED `PNGASEUUSDM`, USD/MMBtu) 실측:

| 시점 | 가격 | 비고 |
|---|---|---|
| 2021-06 | **10.32** | 위기 이전 |
| 2022-03 | 41.73 | 침공 직후 |
| **2022-04** | **31.99** | ← **이 보고서 발표 시점** |
| **2022-08** | **69.98** | **표본 내 최고. 위기 전 대비 6.8배** |
| 2022-12 | 35.37 | 겨울 진입 |
| 2023-03 | 13.87 | 정상화 |
| 2025-12 | 9.46 | 위기 전 아래 |
| 2026-07 | 17.93 | 현재 |

**보고서 발표 후 4개월 동안 가격이 2.2배 더 올랐다.**

## 무엇을 배우나 — 판정 규칙

**"공급 안보"와 "가격 안정"은 다른 질문이고, 답도 다르다.**

이 예측은 **물량 기준으로 맞았다.** 그런데 같은 기간에 —

- 유럽 가스가는 **위기 전의 7배 가까이** 갔다
- 그 "절약 19~26%"의 상당 부분이 **자발적 효율 개선이 아니라 가격에 의한 수요 파괴**였다
  (산업 생산 축소·에너지집약 업종 이전)

→ **판정 규칙**: 에너지 공급안보 분석을 읽을 때 **결론이 물량인지 가격인지** 먼저 확인한다.
"공급은 확보된다"는 결론은 **"가격이 얼마든 상관없다면"** 이라는 암묵 조건을 달고 있다.
그리고 그 가격이 [[CPI (소비자물가지수)]]와 산업 경쟁력으로 넘어간다.

**절약 목표치가 정책의 성과인지 가격의 결과인지 구분하지 않으면,
같은 처방을 다음 위기에 잘못 적용한다.**

## 인과 사슬

```
러시아 공급 중단 → 물량 부족 우려 → (인프라 효율화 + LNG + 절약) → **물량 확보 성공**
                                  ↘ 그 절약의 상당 부분이 가격발 수요 파괴
                → [[천연가스]] 가격 6.8배 → 산업 원가 ↑ → [[CPI (소비자물가지수)]] ↑
                → 에너지집약 산업 축소 (물량 통계에는 "절약"으로 잡힌다)
```

## 한계

- **DIW focus는 정책 브리프**다. 심사 논문이 아니고 시나리오 계산이다.
- **가격 경로는 이 보고서의 주장이 아니다.** 물량 예측을 가격 예측으로 채점하는 것은 부당하다 —
  위에서 채점한 것은 **"물량은 맞았다"** 이고, 가격은 **논점이 빠져 있었다**는 지적이다.
- 위 가스가는 **IMF 유럽 가스 지수(USD/MMBtu, 월간)** 이지 독일 국내 소매가가 아니다.
  ⚠ **TTF 일별과도 다른 계열이다.** 최고치 시점(2022-08)은 월평균 기준이다.
- **"배급에 들어가지 않았다"는 서술은 이 세션에서 데이터로 재확인하지 않았다.**
  독일 연방경제부의 비상단계 발동 이력으로 별도 검증할 것.
- 2022/23년 겨울이 **평년보다 온난**했다는 요인이 이 채점에 반영돼 있지 않다.
  예측의 성공에 운이 얼마나 기여했는지는 분리되지 않았다.
