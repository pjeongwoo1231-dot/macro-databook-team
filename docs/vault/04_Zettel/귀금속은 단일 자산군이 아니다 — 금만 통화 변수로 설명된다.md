# 귀금속은 단일 자산군이 아니다 — 금만 통화 변수로 설명된다

## 1분 요약

**금·은·백금·팔라듐** 네 귀금속의 **월간 가격 변동성**을 모형화하고,
거시 결정요인 세 축(**경기순환 · 통화 환경 · 금융시장 심리**)으로 설명을 시도했다.

| 결과 | |
|---|---|
| **금 변동성** | **통화 변수로 설명된다** |
| **은 변동성** | **그렇지 않다** |
| 네 금속에 **같은 거시 요인이 공동으로** 영향 | **증거가 제한적** |
| 귀금속 **상호간 변동성 피드백** | **증거가 있다** |

> 저자들의 결론: 이 결과는 **귀금속이 단일 자산군으로 간주되거나
> 하나의 지수로 대표되기에는 너무 이질적**이라는 견해와 정합적이다.
> 이는 **포트폴리오 매니저와 투자자에게 중요한 발견**이다.

## 왜 이게 중요한가 — 볼트의 "금은 다르다"가 셋이 됐다

**서로 다른 세 방법이 같은 결론에 수렴한다.**

| 논문 | 방법 | 결론 |
|---|---|---|
| [[현재가치 모형은 소비되는 원자재에서만 작동한다]] (Pindyck 1993) | 현재가치 공적분 검정 | **금은 편의수익이 없어 모형이 안 맞는다** |
| [[저장이론은 검출되고 위험프리미엄은 잘 안 검출된다 — 같은 자료에서]] (Fama-French 1987) | 베이시스-금리 회귀 | **금이 저장이론에 가장 잘 맞는다**(계수 1.07, R²=83%) |
| **이 논문** (Batten 외 2010) | 변동성의 거시 결정요인 | **금만 통화 변수로 설명된다** |

**셋을 합치면**: **금은 소비되는 원자재가 아니라 통화적 자산에 가깝다.**
Fama-French에서 저장이론에 잘 맞는 이유(편의수익 ≈ 0)와
이 논문에서 통화 변수로 설명되는 이유가 **같은 사실의 두 얼굴**이다.

## 판정 규칙

| 관측 | 판정 |
|---|---|
| "귀금속 섹터가 올랐다" | **어느 금속인지 특정한다.** 동인이 다르다 |
| 귀금속 **지수·ETF**로 분석 | **대표성이 없다.** 이질적인 것을 평균했다 |
| 금 변동성 해석 | **통화 환경**(금리·통화량·달러)을 1순위로 |
| 은·백금·팔라듐 | **금의 논리를 옮기지 않는다.** 산업 수요 비중이 다르다 |
| 귀금속 간 동조 | **변동성 피드백**은 있다 — 수준의 공통 동인과 구분할 것 |

→ [[금 가격]] 노드에 **"통화적 자산"** 축을 세우고, **은·백금·팔라듐은 별도**로 다룬다.

## 한계

- **2010년 논문**, 표본이 그 이전이다. **금융화·ETF 확산 이후**의 구조는 부분적으로만 담긴다.
- **월간 변동성**을 대상으로 한다. 수준(가격)의 결정요인이 아니다 — **혼동 금지**.
- "제한적 증거"라는 표현은 **기각이 아니라 약한 지지**다. 공통 요인이 **없다**는 증명이 아니다.
- **계수·모형 사양을 이 노트에 옮기지 않았다.** 방향과 결론만 인용한다.
- **팔라듐·백금은 산업 수요(자동차 촉매)** 비중이 커서 애초에 금과 다른 자산이다 —
  이 결과가 놀랍지 않다는 반론도 가능하다.
