# 절사점 규칙이 다르면 정확도는 비교할 수 없다 — 한쪽의 100%는 결과가 아니라 제약이다

## 1분 요약

두 버전이 같은 데이터에 같은 기법을 쓰고도 절사점을 정하는 방식이 다르다.
한쪽은 "부도를 100% 잡도록" 절사점을 역산했고, 다른 쪽은 오분류 비용 비율을 넣어 계산했다.
**앞쪽의 100%는 모형이 달성한 성과가 아니라 처음부터 걸어둔 조건이다.**

## 인과 사슬

선행 버전 : "극단적인 위험회피형이라고 간주하고 부도기업의 분류정확도를
           **가능한 100%가 되도록** 최적 절사점을 도출"
           → 100%는 입력(제약조건)

2006 확장판 : "위험회피형이라고 간주하고 **오분류 비용을 각각 0.6과 0.03**으로 설정하여
           최적 절사점을 도출"(Paradi et al. 2004) → 비용비 약 20:1
           → 100%는 출력(결과)

→ 같은 표에 "부도 100%"가 적혀 있어도 의미가 다르다

**왜 중요한가**: 분류모형의 정확도는 **절사점을 어떻게 정했는지와 분리해서 읽을 수 없다.**
부도 정확도를 100%로 고정하면 건전 정확도가 남은 자유도를 전부 흡수한다 —
실제로 두 논문 모두 건전 정확도가 52~78%로 떨어진다.

인용 규칙: "이 모형은 부도를 100% 예측했다"가 아니라
**"부도 100%를 제약으로 걸었을 때 건전 정확도가 52~78%였다"** 로 써야 정확하다.
[[부도를 100% 잡으면 건전기업 절반을 오분류한다 — 절사점이 어려운 진짜 이유]]와 함께 볼 것.

**확신도: 상.** 두 버전의 절사점 설정 문장을 직접 대조한 결과다. '100%가 입력인가 출력인가'는 문서에서 판정된다
