# 카르텔은 점유율이 낮으면 가격을 올릴 수 없다 — 시장점유율 함정

## 1분 요약

Adelman이 1981~1992년 OPEC의 후퇴를 정리하며 뽑아낸 명제는 하나다.

> 카르텔의 임무는 **시장점유율을 팔아 더 높은 가격을 사는 것**이다.
> 그런데 **점유율이 너무 낮으면 가격 인상이 가져올 손실을 감당할 수 없다.**
> 점유율이 오르기 전까지 카르텔은 **함정에 갇힌다.**

산수는 단순하다. 점유율 s인 카르텔이 가격을 올리면 —
얻는 것은 **남은 판매량 × 가격 상승분**, 잃는 것은 **줄어든 판매량 × 마진**.
**s가 작을수록 감산 부담이 커져** 순효과가 음(−)으로 넘어간다.

1980년대 실제 경로가 그랬다 — OPEC 점유율이 **30% 아래**로 떨어졌고,
1982~85년 사우디가 손실을 거의 홀로 흡수하다 수출이 0에 가까워지자
**최후의 조절자이기를 그만두었다.** 가격은 $10 아래로 갔고,
시장분할 합의를 겨우 붙여 $18 근처로 돌아왔다.

## 왜 수요가 생각보다 탄력적이었나 — 파생수요의 산수

원유 수요는 **석유제품 수요에서 파생**된다. 그래서 —

```
원유 가격탄력성 = 제품 가격탄력성 × (원유가 / 제품가)
```

제품의 장기 가격탄력성은 대략 **1 근처**(Griffin 1979; Kouris 1983은 최빈값 0.85).
그런데 OECD에서 제품가 중 원유가 차지하는 비중이 작다(세금·정제마진이 크다).
→ **원유의 단기 탄력성은 작아 보이지만, 장기로 가면 제품 탄력성에 수렴한다.**

Adelman의 조정 속도 추정 — 소비 반응의 **반감기 약 9년**,
첫해 7.7%가 나타나고 이후 남은 것의 7.7%씩. **단, 저자 스스로 "확고한 근거가 없는 추측"이라고 명시했다.**

## 여유생산능력과 가격의 통설을 부정한다

한때 넘쳤던 여유생산능력이 줄었지만 —

> "in theory and in fact **this had little effect on the price**"

**여유용량 축소 = 가격 상승**이라는 통설을 이론과 자료 양쪽에서 부인한다.
여유용량은 가격 결정 변수가 아니라 **카르텔 내부 협상의 도구**로 다뤄진다.

## 인과 사슬

```
1970년대 가격 폭등 → (지연된 반응) → 비OPEC 생산 ↑ + 소비 ↓
   → OPEC 점유율 30% 미만 → **점유율 함정** → 가격 인상 불가
감산 부담 배분 → 회원국이 서로에게 떠넘김 → 응집력 ↓
시장 "상품화"(재판매자 다수) → 고정가 준수 **감시 불가** → 생산 제한에 의존
   → 회의·분쟁이 거의 상시화
```

## 왜 이게 중요한가 — 판정 규칙

**OPEC+ 감산 뉴스를 읽을 때 물어야 할 것.**

| 흔한 해석 | Adelman 프레임의 질문 |
|---|---|
| "감산 발표 = 가격 상승" | **점유율이 얼마인가.** 낮으면 감산 자체가 손해다 |
| "여유용량이 줄어 가격이 오른다" | **부정된다.** 여유용량은 협상 도구이지 가격 변수가 아니다 |
| "OPEC이 가격을 정한다" | 감시가 안 되면 고정가는 유지되지 않는다. **생산 제한만 남는다** |
| "수요가 비탄력적이라 괜찮다" | **단기만 그렇다.** 장기 탄력성은 제품 탄력성(≈1)에 수렴 |

특히 **비OPEC 공급 증가는 가격 인상이 없었어도 왔을 것**이라는 지적이 중요하다 —
카르텔이 스스로 만든 손실과 외생적 추세를 분리하지 않으면 정책 효과를 과대평가한다.

## 볼트에 붙는 자리

[[WTI (국제유가)]]의 「왜 올랐나를 먼저 밝힌다」 규칙에 **공급 측 정치경제**를 더한다.

**구조(카르텔의 존재)에서 결과(가격 지배)를 바로 추론하지 않는다.**

## 한계

- **1993년 MIT 워킹페이퍼**다. 셰일 혁명·OPEC+ 체제·중국 수요·전환 수요가 전부 표본 밖이다.
  **명제는 살아 있으나 수치는 낡았다.**
- **서술적·산업조직적 분석**이다. 구조 추정이나 계량 검정이 아니다.
- 반감기 9년은 저자가 **추측이라고 명시**했다. 인용 시 반드시 이 단서를 붙일 것.
- 저자의 관점이 명확히 **반(反)희소성·시장주의**다. 국영기업을
  *"bumbling state companies" · "flabby national dinosaurs"* 라 부른다.
  **논지의 타당성과 별개로 서술 톤을 감안할 것.**
- 274쪽 중 앞부분과 목차·요약을 대조했다. **본문 표(Table II·XIII)의 수치는 옮기지 않았다.**
