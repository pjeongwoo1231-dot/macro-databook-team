# 채점 결과 — GDP 발표 시차가 50일에서 23일로 줄어 논문의 문제의식이 절반 해소됐다

## 1분 요약

2002년 논문의 출발점은 "GDP 속보가 분기 종료 후 1개월 20여일 뒤에 나와서
경기판단이 1~2개월 지연된다"였다. 지금은 **약 23일**이다.
논문이 풀려던 문제 자체가 절반 이상 작아졌다.

## 인과 사슬

논문 전제 (2002) : GDP 속보 발표 = 분기 종료 후 **1개월 20여일** (≈50일)
                  → 목표: "분기 종료 후 **1개월 이내**" 예측

현재 (2026)      : 한국은행 실질GDP 속보치 = 분기 종료 후 **약 23일**
                  2026Q1 → 4월 23일 발표 · 2026Q2 → 7월 23일 발표

→ 논문의 목표(30일)와 실제 발표(23일)가 **역전됐다.**
  예측이 속보보다 늦다

**왜 중요한가**: 방법론의 유효성과 문제의 유효성은 별개다.
이 논문의 **부문별 회귀 구조와 공급·수요 비대칭 발견은 여전히 유효**하지만,
"속보보다 빨리 알아내자"는 목표는 이제 의미가 없다.

현재의 문제는 다시 정의돼야 한다 — **"분기 종료 후 30일"이 아니라 "분기 중 매주 갱신"**이다.
그게 진짜 나우캐스팅이고, 이 vault의 [[GDP 성장률]] 노드에 모인
K-SuperCast·DFM 계열이 겨냥하는 지점이다.

**교훈의 일반형**: 오래된 논문을 읽을 때 **결과보다 전제를 먼저 검증**한다.
데이터 인프라가 개선되면 방법론은 남고 동기는 사라진다.
이 논문에서 가져갈 것은 "빨리 예측하는 법"이 아니라
"공급 쪽 지표가 수요 쪽보다 정확하다"는 구조적 발견이다.

**확신도: 상.** ✔ 사후검증. 한국은행 발표 일정이라는 확인 가능한 사실로 논문의 전제가 무효화됨을 보였다. 방법론과 문제의식을 분리하는 판정에 해석 여지가 없다
