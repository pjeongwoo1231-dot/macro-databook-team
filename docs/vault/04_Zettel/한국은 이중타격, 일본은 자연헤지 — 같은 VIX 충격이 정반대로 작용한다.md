# 한국은 이중타격, 일본은 자연헤지 — 같은 VIX 충격이 정반대로 작용한다

## 1분 요약

글로벌 공포지수가 오르면 한국은 **주식이 빠지고 통화도 같이 빠진다.**
일본은 주식이 빠지는 대신 **통화가 오른다.** 외국인 투자자 입장에서 한국 자산은
두 손실이 곱해지고, 일본 자산은 상쇄된다. 위기 때 한국에서 자금이 더 빨리 빠지는 구조적 이유다.

## 인과 사슬

[[VIX]](-1) → 각 시장 (VAR(2), 일별 2004~2013)

  Japan 주식 : **−0.0767**\*\*\* (t=−18.82)
  Korea 주식 : **−0.0993**\*\*\* (t=−16.72)   ← 한국이 **29% 더 민감**
  JPY        : **−0.0061**\*\*\* (t=−2.91)    → 엔 **절상**
  **KRW**    : **+0.0212**\*\*\* (t=8.52)     → 원 **절하**, 엔의 **3.5배 민감**

한국 : 주식 ↓ **AND** 통화 ↓ → 이중타격
일본 : 주식 ↓ **BUT** 통화 ↑ → 부분 자연헤지

**왜 중요한가**: 외화표시 수익률로 보면 격차가 더 커진다.
한국 주식을 달러로 들고 있으면 주가 하락에 환손실이 더해지고, 일본은 환이익이 상쇄한다.
**"위기 때 한국이 더 빠진다"는 현상은 심리가 아니라 두 계수의 부호 조합이다.**

이 vault의 [[2012 외국인투자가 환율과 주가에 미치는 영향 (이한재)]]가 **외국인 순매수 → 환율**
경로를 확인했으므로 사슬이 완성된다:
**[[VIX]] ↑ → 외국인 이탈 → [[KOSPI]] ↓ → 원화 절하.** 논문 본문도 같은 기제를 서술한다.

기술통계도 정합적이다 — 원화 수익률의 첨도가 **52.5**(엔 7.6)로 극단적 꼬리를 갖는다.
평상시엔 조용하고 위기 때 크게 튀는 통화라는 뜻이다.

**확신도: 중상.** 계수·t값이 크고 부호 조합(한국 주식↓통화↓ / 일본 주식↓통화↑)이 명확하다. 단 표본이 일본·한국 2개국이고 2013년에 끝난다
