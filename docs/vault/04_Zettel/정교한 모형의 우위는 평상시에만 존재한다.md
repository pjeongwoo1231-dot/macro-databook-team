# 정교한 모형의 우위는 평상시에만 존재한다

## 1분 요약

G20 117개 거시변수를 동적요인모형으로 압축하고 릿지·라쏘까지 얹은 모형이, **작년 값 하나만 쓰는 AR(1)** 을 얼마나 이기는가. 평상시에는 17% 이긴다. 그런데 코로나 국면에서는 **1.8%로 줄어든다.** 사실상 무승부다. **모형을 정교하게 만들어 얻는 이득은 세상이 평소처럼 굴러갈 때만 존재한다.**

## 인과 사슬

```
DFM(G20 117변수) + Ridge/Lasso  vs  AR(1) (한국 GDP 성장률만 사용)
        ↓
RMSE 비교 (expanding window, 8개 분기씩)

코로나 이전(2018Q1~2019Q4)   AR 0.503 → LR(15팩터) **0.417**   개선 **약 17%**
코로나 이후(2021Q1~2022Q4)   AR 0.625 → RR(20팩터) **0.614**   개선 **약 1.8%**
        ↓
구조적 충격 국면에서 정교한 모형의 우위가 거의 소멸
```

**왜 그런가**: 팩터모형은 **과거의 공분산 구조**를 학습한다. 구조가 유지되는 동안은 117개 변수의 정보가 이득이 되지만, 구조가 깨지면 그 학습이 오히려 부담이 된다. 반면 AR(1)은 학습한 게 거의 없어서 잃을 것도 없다 — **단순함이 구조변화에 대한 방어**가 된다.

**같은 데이터가 보여주는 두 번째 교훈**: 팩터를 늘릴 때 정규화 없이 방치하면 예측력이 무너진다. OLS는 팩터 1→3개로 늘리자 코로나 이후 RMSE가 0.637 → **0.819**로 악화돼 AR(1)보다도 나빠졌다. 팩터 15개를 뽑았을 때 팩터 간 상관이 **−0.77~0.74**로 다중공선성이 심한 것이 원인이다.

**왜 중요한가**: 레짐 전환이 의심되는 국면일수록 **모형 예측치의 근거 가치가 낮아진다.** 정확히 판단이 어려운 때에 도구도 같이 무뎌지는 구조다. Data Book 코멘터리에 모형 예측치를 실을 때 **"현재가 평상시 국면인가"를 먼저 판정**하고, 아니라면 단순 벤치마크와 나란히 제시해야 한다.

**확신도: 중.** 17% → 1.8%는 원문 표에서 직접 계산한 값이며 **저자들은 이 격차 축소를 별도로 논의하지 않는다**(수치를 나란히 제시할 뿐). 각 구간이 **8개 분기뿐**이라 RMSE 차이의 통계적 유의성은 검정되지 않았다. 벤치마크도 단변량 AR(1)에 그쳐 SARIMA·VAR과는 비교되지 않았다.
