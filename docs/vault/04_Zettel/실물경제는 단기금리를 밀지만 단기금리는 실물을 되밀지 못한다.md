# 실물경제는 단기금리를 밀지만 단기금리는 실물을 되밀지 못한다

> ✅ **원문 대조 완료 (2026-08-13)** — 연세대 경제대학원 석사학위논문 원문 72p (`Attachments/macro_classics/김석진2024_DNS거시_기간구조.pdf`) pymupdf 전문 추출·대조.

## 1분 요약

금리와 경기는 서로 주고받는 사이처럼 보이지만, 이 논문의 검정에서는 **한쪽으로만 흐른다.**
실물경제 지표를 압축한 요인이 1년물 국채금리를 앞서 움직이는 반면, 1년물 금리는 실물요인을
전혀 예측하지 못했다. 물이 위에서 아래로만 흐르는 것과 같아서, 경기를 보고 금리를 읽을 수는 있어도
단기금리를 보고 경기를 읽으려는 시도는 이 표본에서는 근거가 약하다.

## 인과 사슬

실질요인(=[[산업생산]] 87.71% + 비농업고용 72.74% 설명) ↑
→ 1년물 국채금리 ↑ (F=7.6236, p=0.0060)
→ 3년물·5년물로도 유의한 선행성 확산

역방향: 1년물 금리 → 실질요인 (F=0.0005, **p=0.9996**) — 사실상 완전한 무관계

**왜 중요한가**: 단기금리를 경기 선행지표로 쓰는 관행에 제동을 건다.
이 vault는 이미 [[경기선행지수 (CLI)]]가 선행하지 못한다는 증거를 모아왔는데(양준모·최진석 2008),
여기서는 반대로 **실물이 금리를 선행한다**는 방향이 확인됐다. 즉 금리는 경기의 원인이 아니라
결과 쪽에 가깝다. p=0.9996은 통계적으로 "아무 관계 없음"에 가까운 극단값이라는 점도 눈여겨볼 것.

**확신도: 상.** 원문 <표 7>에서 양방향을 모두 확인했다 — RealFactor→govt12m F=7.6236(p=0.0060), 역방향 govt12m→RealFactor F=0.0005(**p=0.9996**). 표에 직접 실린 값이라 해석 여지가 없다. ⚠ 단 본문의 '실질요인이 36·60개월물에도 유의한 선행성'은 표에 해당 검정이 없다 — 12개월물 결과만 인용할 것.
