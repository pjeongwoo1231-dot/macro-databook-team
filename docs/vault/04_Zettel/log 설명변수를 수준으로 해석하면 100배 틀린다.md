# log 설명변수를 수준으로 해석하면 100배 틀린다

## 1분 요약

회귀식의 설명변수가 `log(VIX)`인데 결과를 "VIX가 1포인트 오르면"으로 읽은 논문이 있다.
계수 2.3802는 **VIX가 e배(172%) 오를 때의 효과**이지 1포인트일 때가 아니다.
같은 숫자를 잘못 읽으면 위기 시 스프레드가 **162%p 벌어진다**는 결론이 나온다.

## 인과 사슬

모형: `premium = α₀ + α₁·log(VIX) + ε`,  α₁ = 2.3802

```
올바른 해석 : VIX **1% 상승** → 프리미엄 **+0.0233%p**  (= α₁/100)
논문의 해석 : VIX **1포인트 상승** → 프리미엄 +2.3802%p
```

| 국면 | 논문 서술대로 | 올바른 해석 |
|---|---|---|
| VIX 12 → 80 (리먼·코로나) | **+162%p = 16,185bp** | **+4.42%p** |
| VIX 13 → 65 (2024 캐리청산) | +124%p | +3.75%p |

→ 미 회사채 스프레드가 162%p 벌어지는 일은 **존재하지 않는다.**
   반면 위기에 +4.4%p(440bp)는 실측과 잘 맞는다

**왜 중요한가**: 추정은 멀쩡한데 **해석만 틀린** 사례다. 재현해보니 계수가 2.3292로
논문 값(2.3802)과 거의 같았다 — 데이터도 방법도 문제없고, 문장 하나가 틀렸다.
그리고 그 문장이 **초록·서론·결과·결론에 4번 반복**된다.

점검 규칙: **설명변수가 log·비율·차분인지 먼저 확인하고 계수 단위를 재구성한다.**
"1단위 증가"라는 표현이 나오면 그 1단위가 원 변수의 1인지, 로그의 1인지, 표준편차 1인지 묻는다.

크기 감각으로 잡아내는 것도 가능하다 — 이 vault의 규칙 "부호와 크기를 적는다"의 역방향 활용이다.
**보고된 효과 크기를 실제 관측 범위에 대입해보면 대부분의 단위 오류가 드러난다.**

**확신도: 상.** 계수 재현(2.3292 vs 논문 2.3802)으로 데이터·방법이 확인됐고, 단위 오류는 산술적으로 판정되는 사실이다
