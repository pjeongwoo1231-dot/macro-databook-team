# 임금 기대와 물가 기대의 연결이 소비를 지킨다

## 1분 요약

같은 물가 상승을 겪어도 가계마다 소비 반응이 다르다. 갈리는 것은
**"물가가 오르면 내 임금도 오를 것"이라고 믿는가**다.

일본 가계 서베이 미시자료 결과 —

1. **임금상승 기대와 물가상승 기대의 연결이 최근 강해졌다**
2. 연결 정도의 **가계 간 이질성**은 다음과 유의하게 연관된다 —
   **노동시장 타이트니스 · 노동 이동성 · 소득 수준 · 노조 가입 여부**
3. 저자들의 해석: 고령화로 **추가 노동공급 여지가 줄어드는 구조 변화**가
   연결 강화에 기여했을 수 있다
4. **연결이 강한 가계는 물가 상승기에도 지출 태도를 상대적으로 유지한다.**
   기대 실질소득의 하락폭이 작기 때문이다

## 인과 사슬

```
고령화 → 추가 노동공급 여지 ↓ → 노동시장 타이트니스 ↑
   → 임금 협상력 ↑ → **물가 기대 → 임금 기대 연결 강화**
   → 물가 상승기의 **기대 실질소득 하락폭 축소** → 지출 태도 유지
   → 소비 방어 → 인플레의 수요 파괴 효과 약화
반대로 연결이 약한 가계(비노조·저소득·이동성 낮음)
   → 기대 실질소득 급락 → 지출 위축 → **같은 물가에 다른 소비 반응**
```

## 왜 이게 중요한가 — 판정 규칙

**"물가가 오르면 소비가 줄어든다"는 명제에 조건이 붙는다.**
줄어드는 정도가 **임금-물가 기대의 연결 강도**에 달려 있다.

| 관측 | 흔한 해석 | 이 논문의 판정 |
|---|---|---|
| 인플레인데 소비가 버팀 | 초과저축·자산효과 | **임금 기대가 따라 오르고 있을 수 있다** |
| 소비심리 악화 | 물가 그 자체 | **기대 실질소득**을 봐야 한다 — 명목임금 기대가 핵심 |
| 임금 상승 = 인플레 압력 | 2차 효과 우려 | **동시에 소비를 지탱**한다. 방향이 하나가 아니다 |

→ [[CSI (소비자심리지수)]]를 읽을 때 **물가 전망 문항과 소득 전망 문항을 함께** 볼 것.
둘의 **차이(기대 실질소득)** 가 지출 태도를 정한다. 물가 전망 단독으로는 부호를 못 읽는다.

## 한국에 옮길 때

**연결 강도의 결정요인이 한국에서는 다른 방향일 수 있다** —

- 노조 가입률: 한국은 **일본보다 낮다** → 연결이 약한 쪽
- 노동시장 이중구조: 대기업·정규직과 그 밖의 **연결 강도 격차가 클 것**
- 고령화 속도: 한국이 더 빠르다 → 타이트니스 경로는 같은 방향

→ **총량 소비심리로는 이 이질성이 보이지 않는다.** 계층별 분해가 필요하다(현재 파이프라인에 없음).

## 한계

- **BOJ 워킹페이퍼**다. 은행 공식 견해가 아니다.
- **서베이 기대**다. 실제 임금 상승이 아니라 **기대**이며, 실현과 다를 수 있다.
- 연결 강도와 지출 태도의 관계는 **상관**이다. 역인과(지출 여력이 있는 가계가
  임금 기대도 낙관적)를 배제하지 못한다.
- 일본은 **춘투(春闘)라는 집중 임금협상 제도**가 있다. 임금 기대 형성의 제도적 배경이 다르다.
- 계수·표본기간을 옮기지 않았다. **방향과 구조만 인용한다.**
