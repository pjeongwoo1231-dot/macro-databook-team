# 팩터 개수 전략은 목적이 정한다 — 해석이냐 예측이냐

## 1분 요약

수십~수백 개 변수를 몇 개의 공통요인으로 줄일 때, **몇 개로 줄일 것인가**에는 정답이 없다. 답은 무엇을 하려는지에 달려 있다. **"이 요인은 실물이고 저 요인은 물가다"라고 말하고 싶으면 적게** 뽑아야 하고, **그냥 잘 맞히기만 하면 되면 많이** 뽑은 뒤 정규화로 정리하는 편이 낫다. 두 목적은 정반대 방향을 가리킨다.

## 인과 사슬

```
목적 A — 해석 가능한 나우캐스팅
   변수 86~93개 → 팩터 **3개**
   "요인1 = 실물, 요인2 = 물가" 식의 서사가 가능
   대표: [[K-SuperCast]] 계열
        ↓
   대가: 예측 성능 자체는 최적이 아님

목적 B — 순수 예측 성능
   변수 117개 → 팩터 **15~20개** → Ridge/Lasso로 정리
   저자 결론: "적은 수의 factor보다 많은 수의 factor를 추출한 후
              변수선택 또는 변수축소 방법론을 사용하는 경우가 예측력이 더 우수"
        ↓
   대가: 팩터 하나하나의 경제적 의미를 말할 수 없음
```

**왜 많이 뽑으면 정규화가 필수인가**

```
팩터 15개 추출 → 팩터 간 상관 **−0.77 ~ 0.74** (다중공선성 심각)
        ↓
   ┌─ 정규화 없음(OLS): 팩터 1→3개로 늘리자 코로나 이후 RMSE 0.637 → **0.819**
   │                      (AR(1) 0.625보다도 나빠짐)
   └─ Ridge/Lasso: 팩터 15~20개에서 최저 RMSE 달성
```

**Ridge vs Lasso는 우열이 갈리지 않는다**: 코로나 이전엔 Lasso(0.417), 이후엔 Ridge(0.614)가 근소 우위. 실무 기준은 성능이 아니라 용도로 잡는 편이 낫다 — **변수선택·해석이 필요하면 Lasso, 안정성이 필요하면 Ridge.**

**왜 중요한가**: 자체 지표를 설계할 때 **"팩터 몇 개?"를 성능 문제로만 다루면 안 된다.** 산출물이 브리핑에 실려 사람이 읽을 것이라면 해석 가능성이 성능보다 중요하고, 백테스트 신호로만 쓸 것이라면 반대다. 두 용도를 하나의 지표로 겸하려 하면 양쪽 다 어중간해진다.

**확신도: 중.** 저자 본인이 결론에서 **"선택한 거시경제 변수와 factor 개수에 따라 예측 성능이 달라질 수 있으므로, 연구자가 실험을 통하여 이러한 것들을 결정해야 한다"**고 인정한다. 즉 팩터 개수가 **사전 이론이 아니라 사후 그리드서치**(1·3개 vs 15·20개 비교)로 정해졌고, 정보기준(AIC/BIC류)의 통계적 정당화는 제시되지 않았다.

## 핵심 지표 · 연결고리

- **관련 노드**: [[GDP 성장률]] · [[동행종합지수 (CCI·CCCI)]] · [[산업생산]] · [[경기침체]]
- **부수 발견**: 이 논문은 **해외 거시지표(G20 16개국+EU)로 한국 GDP를 예측**한다. 국내 지표만 쓰던 기존 접근이 답하지 않은 질문이다. 국가당 변수는 8종(GDP·소비·투자·CPI·PPI·산업생산·장기금리·실업률)뿐이라 재현 비용이 낮다.
- **같이 볼 것**: [[정교한 모형의 우위는 평상시에만 존재한다]] — 같은 논문의 더 중요한 결론. 팩터 전략을 아무리 잘 잡아도 구조변화 앞에서는 우위가 사라진다.
- **방법론 위치**: [[나우캐스팅에는 세 계보가 있다 — 예측·분해·합성]]의 ① 예측 계보 내부 분기.
