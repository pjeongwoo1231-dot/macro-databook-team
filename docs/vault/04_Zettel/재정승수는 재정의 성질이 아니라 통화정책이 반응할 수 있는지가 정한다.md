# 재정승수는 재정의 성질이 아니라 통화정책이 반응할 수 있는지가 정한다

## 1분 요약

"재정승수는 얼마인가"는 **레짐을 명시하지 않으면 성립하지 않는 질문**이다.
평상시엔 1보다 작고, **제로하한이 구속되면 1보다 훨씬 크다.** 차이를 만드는 것은
재정지출의 성질이 아니라 **중앙은행이 금리를 올려 상쇄할 수 있는가**다.

## 인과 사슬

```
[평상시]  정부지출 ↑ → 수요·물가 ↑ → **중앙은행 금리 인상** → 민간지출 구축
          → 승수 **< 1**

[제로하한] 정부지출 ↑ → 수요·기대인플레 ↑ → 명목금리 **0에 고정**
          → **실질금리 하락** → 민간 소비·투자도 **함께 증가**
          → 승수 **>> 1**
```

**기존 추정치 (저자들이 먼저 인정한 것)**
- 일부 실증 **약 0.8** · **Ramey(2008) 약 1.2**
- 표준 뉴케인지언 모형: *"the multiplier is typically **less than one**"*

**추가 명제 두 개**

**① 타이밍이 규모만큼 중요하다**
*"The larger is the fraction of government spending that occurs **while the nominal interest
rate is zero**, the larger is the value of the multiplier."*
→ 하한을 벗어난 뒤 집행되는 지출은 승수가 작다. **같은 금액도 언제 쓰느냐로 효과가 갈린다.**

**② 자본축적은 비선형으로 작용한다**
주어진 충격에 대해 **하한 진입 가능성은 낮추고**, 하한이 걸린 뒤에는 **승수를 키운다.**

**왜 중요한가 — 이 볼트가 반복 확인한 원리의 재정 버전이다.**
[[거시에서 관계는 구간별로만 안정적이다|확립 명제 6]]. 승수를 단일 숫자로 보고하는 실증 문헌은
**레짐을 평균낸 값**을 준다. 그 평균은 어느 국면에도 해당하지 않는다.

**현 국면 적용 (2026)**: 미 정책금리 **3.75%**로 하한에서 멀다 → **평상시 승수, 즉 1 미만**이 적용된다.
[[RegimeView 1.0 (2026-08-09)]]의 재정 감축(정부고용 −53K) 해석에 이 단서가 붙는다 —
**하한이 아닌 국면의 재정 축소는 승수가 작아 실물 파급이 제한적**이다.
반대로 2020~21 팬데믹 재정은 **하한 구간에 집행**됐으므로 승수가 컸을 것이고,
이는 [[상품시장 충격은 크지만 일시적이고 노동시장 충격은 작지만 지속적이다]]의
"재정이 수요를 밀었다"는 배경과 정합적이다.

**확신도: 중.** 메커니즘이 명확하고 저자들이 자기 결과에 불리한 기존 추정치를 먼저 제시했다.
**유보**: ① **모형 기반(DSGE 시뮬레이션)** 이지 실증 추정이 아니다 — 결론이 모형 사양에 조건부
② NBER WP(2010.12) 대조본, JPE 최종본(2011) 미확인
③ 하한 **지속기간·충격 크기** 가정에 민감하다.
