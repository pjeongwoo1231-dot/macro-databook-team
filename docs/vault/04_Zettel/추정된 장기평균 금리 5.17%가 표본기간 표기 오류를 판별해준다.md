# 추정된 장기평균 금리 5.17%가 표본기간 표기 오류를 판별해준다

> ✅ **원문 대조 완료 (2026-08-13)** — 연세대 경제대학원 석사학위논문 원문 72p (`Attachments/macro_classics/김석진2024_DNS거시_기간구조.pdf`) pymupdf 전문 추출·대조.

## 1분 요약

논문은 표본기간을 두 군데서 다르게 적었다 — p.352는 1982년 1월부터, p.553은 2000년 1월부터다.
어느 쪽으로 추정했는지 본문만으로는 알 수 없다. 그런데 **추정 결과가 답을 알려준다.**
레벨 요인의 장기평균 추정치가 5.17%인데, 2000년 이후 표본에서는 나올 수 없는 값이다.

## 인과 사슬

DNS 추정 결과 : mu₁ = 5.1660 (t=4.85, p<0.001) = 레벨 요인의 장기평균
  ≈ 장기금리의 무조건 평균 수준

1982~2023 표본 : 1980년대 두 자릿수 금리 구간 포함 → 평균 5%대가 자연스럽다
2000~2023 표본 : 이 기간 미 10년물 평균은 3%대 → **5.17%가 나올 수 없다**

→ 실제 추정은 **1982년 1월부터**로 판단. p.553의 "2000년 1월"은 오기이거나
   ACM 데이터 가용성 서술이 혼입된 것으로 보인다

**왜 중요한가**: 표본기간이 1982년부터라면 **mu₁ = 5.17%는 현재에 그대로 대입할 수 없다.**
1980년대 볼커 디스인플레이션 국면이 장기평균을 크게 끌어올리기 때문이다.
VECM의 오차수정항은 이 평균을 향해 예측치를 되돌리므로, **장기 예측에 상방 편향**이 생긴다.

실제로 세 모형 전부 2024년 10월 금리를 과대예측했다(+1.7bp ~ +81.7bp).
채점 결과의 공통 상방 편향은 이 표본 구성에서 나온 것일 가능성이 있다 —
[[채점 결과 — DNS-거시 결합 모형의 2024년 10월 예측이 맞았다]]와 함께 볼 것.

**확신도: 상.** 원문에서 세 가지를 모두 확인했다 — ① mu₁ 추정치 **5.166**이 <표 2>에 존재, ② 표본기간 표기 불일치가 실재(1982년 1월 기준 서술 5곳: 3장 데이터 절·<그림 1>·<그림 2> 캡션·4.4.3절 / 2000년 1월 기준 서술 2곳: 2장 ACM 소개·4.1절), ③ **<그림 2>(DNS 3요인 추정치 시계열) 캡션이 '1982년 1월 ~ 2023년 3월'** 이므로 요인 추정이 1982년부터임이 확정된다. 추론이었던 판정이 그림 캡션으로 직접 확인됐다.
