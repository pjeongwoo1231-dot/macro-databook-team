# 표본 내 1등이 표본 외에서도 1등이었다 — 단 방향은 셋 다 틀렸다

> ✅ **원문 대조 완료 (2026-08-13)** — 연세대 경제대학원 석사학위논문 원문 72p (`Attachments/macro_classics/김석진2024_DNS거시_기간구조.pdf`) pymupdf 전문 추출·대조.

## 1분 요약

"과거에 잘 맞는 모형이 미래를 잘 맞히는 건 아니다"는 통설을 이 논문으로 검증했더니
**절반만 맞았다.** 표본 내 1등이던 결합모형은 실제 사후 채점에서도 1등이었다(레벨 정확도).
그러나 세 모형 모두 금리를 과대예측했다는 점에서, 순위는 유지됐지만 방향 편향은 공통이었다.

## 인과 사슬

표본 내 (Govt12M) : 결합 R²=0.9954 > 거시Only 0.9947 > DNS Only 0.9945
무작위 30시점 RMSE : 결합 0.1534 < 거시Only 0.1742 < DNS Only 0.1796
2024-10 사후 채점  : 결합 0.037 < DNS Only 0.387 < 거시Only 0.403
→ **세 기준에서 결합모형이 일관되게 1위**

단, 논문의 12개월 경로 예측(2023.4~2024.3)에서는 결합=하락 / 나머지=상승으로 방향이 갈렸고
저자 본인도 "어느 한 모형의 우수성을 단정하기 어렵다"고 결론

**왜 중요한가**: 표본 외 성적을 따로 확인해야 한다는 원칙은 유효하지만,
**"표본 내 우위는 무의미하다"까지 가면 과잉 일반화**다. 여기서는 이어졌다.

이 vault의 반대 사례와 나란히 볼 것 — [[GDP 성장률]] 노드의 Lee&Lim(코로나 이후 우위 17%→1.8% 붕괴),
임상수·최항석(실제로 일한 변수는 Lag(1) 하나뿐). 그쪽은 표본 내 우위가 표본 외로 안 이어진 사례다.
**차이는 구조변화 유무**로 보인다: 2023~24년은 레짐이 바뀌지 않은 구간이었고,
코로나는 바뀐 구간이었다. 즉 표본 내 우위는 **레짐이 유지되는 동안만** 이어진다.

**확신도: 중상.** 원문에서 표본 내 수치를 확인했다 — <표 9> R² 0.9954/0.9945/0.9947, 무작위 30시점 RMSE 0.1534/0.1796/0.1742. ⚠ 그러나 제목의 '표본 외'는 **논문의 표본외 절이 아니라 이 볼트의 2024-10 사후 채점**을 가리킨다. 논문 자신의 표본외 평가(4.4.5, <그림 9>)에는 **정량 지표가 전혀 없고** 예측 방향 비교뿐이다. 따라서 '표본 내 1등이 표본 외에서도 1등'은 논문이 보인 것이 아니라 **볼트가 채점해서 얻은 것**이다.
