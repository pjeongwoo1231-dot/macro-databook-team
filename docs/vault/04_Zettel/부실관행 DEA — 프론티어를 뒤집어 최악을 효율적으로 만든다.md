# 부실관행 DEA — 프론티어를 뒤집어 최악을 효율적으로 만든다

## 1분 요약

보통 효율성 분석은 "가장 잘하는 기업"을 기준선(프론티어)에 세우고 나머지를 그와 비교한다.
부실관행 DEA는 그 기준선을 반대편에 세운다. **가장 나쁜 기업을 "효율적"이라고 부른다.**
빚을 늘리는 데 가장 능률적인 기업, 즉 망하는 일을 가장 잘 해내는 기업을 찾아내는 장치다.

## 인과 사슬

정상 DEA  : 투입 = 작을수록 좋은 것(총자산·총부채·금융비용)
            산출 = 클수록 좋은 것(EBITDA·이익잉여금·현금흐름)
            → 효율적 프론티어 = **우수** 기업

부실관행 DEA : 투입·산출의 **위치를 반전**
            투입 = 운전자본·EBITDA·이익잉여금·현금흐름
            산출 = 금융비용(IN)
            → 효율적 프론티어 = **최악** 기업 = [[기업 부도]] 후보

**왜 중요한가**: 금융기관이 실제로 필요한 건 "우수 기업 순위"가 아니라 **걸러낼 대상**이다.
정상 DEA로 우수 기업을 찾고 그 반대편을 위험하다고 추론하는 것보다,
애초에 위험 쪽을 직접 모형화하는 편이 정확하다.

저자는 부실관행 DEA가 정상 DEA보다 **절사점 변화에 강건하다**고 보고한다 —
프론티어 근처에 부도기업이 밀집해 있어 경계선을 조금 움직여도 판정이 덜 흔들린다는 뜻이다.
[[신용사이클]]의 국면 판단에도 같은 논리를 적용할 수 있다: 좋은 신호의 부재보다
나쁜 신호의 밀집을 직접 재는 편이 낫다.

**확신도: 상.** 모형 정의(투입·산출 반전)는 방법론 서술 사실이다. 다만 '절사점에 강건하다'는 저자 주장 부분은 별도 검증 대상

## 핵심 지표 · 연결고리

- **관련 노드**: [[기업 부도]] · [[신용사이클]] · [[신용스프레드]]
- **리서치 관점**: 문제를 뒤집어 정의하는 발상 — "잘하는 쪽을 재서 못하는 쪽을 추론"하지 않고 못하는 쪽을 직접 잰다.
