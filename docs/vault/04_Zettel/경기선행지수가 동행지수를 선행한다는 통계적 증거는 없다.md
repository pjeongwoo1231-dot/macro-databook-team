# 경기선행지수가 동행지수를 선행한다는 통계적 증거는 없다

## 1분 요약

통계청 경기선행지수는 이름부터 "선행"이다. 존재 이유가 경기를 미리 알려주는 것이다. 그런데 그 선행성을 **정면으로 검정한 연구가 거의 없었다.** 실제로 재보니 **"3~6개월 선행"이라는 통설을 뒷받침할 통계적 근거가 나오지 않는다.** 어떤 국면에서는 오히려 동행지수보다 **늦게** 돈다.

## 인과 사슬

**검정 3종 전부 통설을 지지하지 않는다**

```
① Diebold-Mariano 예측오차 검정 (핵심)
   시차 1~6개월 선행 예측 vs 시차 0(무시차) 예측
   → S1 통계량으로 6개 비교 중 **유의하게 기각한 사례 0건**
   → S2'(sign test)로는 오히려 **무시차(D01)가 더 낫다**

② 그랜저 인과관계 (4개월 시차)
   → **동행지수 → 선행지수** 방향으로 나옴 (이름과 정반대)

③ 교차상관
   시차0 = 0.71, 3개월 선행 시 최대 0.82
   그런데 **선행지수가 18개월 후행하는 방향에서도 상관 절댓값이 큼**
   → 저자 본인이 "교차상관계수만으로 판단하기가 매우 힘들다"고 명시
```

**국면별 선행폭이 뒤집힌다** (BK필터 순환변동치, 표 2-1)

| 국면 | 선행폭 |
|---|---|
| 1970년대 | 평균 약 6개월 |
| 1981.7(상승) · 1997.5(상승) | **0개월** (동시전환) |
| 1993.5(하락) | **−1개월** (후행) |
| 1996.9(하락) | **−2개월** (후행) |

→ 외환위기 이전엔 대체로 선행성이 있었으나 **1990년대 이후 불안정해지고 방향까지 뒤집힌다.**

**왜 중요한가**: [[경기선행지수 (CLI)]]를 경기전환점 트리거로 쓰는 설계는 이 논문 앞에서 근거를 잃는다. "몇 개월 선행"이라는 통설을 그대로 인용하면 안 되고, **선행폭 자체가 국면 의존적으로 6개월~−2개월까지 요동친다**는 캐비어트가 반드시 붙어야 한다.

**추가로 드러난 것**: 주성분분석에서 동행·선행 두 지수의 **제1주성분이 변동의 85.6%를 설명**하고 둘 다 같은 부호의 loading을 갖는다. 저자는 "경기적 특성이 유사한 좋은 지수 쌍"으로 해석하지만, 뒤집으면 **두 지수가 하나의 공통요인에 강하게 동조돼 서로 구분되는 정보량이 크지 않다**는 뜻이다.

**확신도: 중상.** 검정 3종이 같은 방향을 가리킨다. 다만 표본이 **2006년 12월에서 끝나** 이후 통계청 경기종합지수 개편분이 반영되지 않았고, BK필터(18~96개월 주기만 잔존) 선택 자체가 "무엇이 경기변동인가"의 정의를 이미 포함한다.
