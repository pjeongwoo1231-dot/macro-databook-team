# 원자재 ETF의 성과를 정하는 건 가격 방향이 아니라 롤 캐리다

## 1분 요약

USO는 WTI 근월물을 그대로 추종하는 무레버리지 ETF다. 그런데 2006년 상장 이후 **−72%**인데
같은 기간 **WTI 현물은 +43%**다. 방향을 맞혀도 죽는다. **차이는 전부 롤 비용이다.**

선물은 만기가 있어 ETF는 매달 근월물을 팔고 차월물을 산다.
**콘탱고**면 비싸게 다시 사고(= 매달 이자를 낸다), **백워데이션**이면 싸게 다시 산다(= 캐리를 받는다).
같은 자산이 **레짐에 따라 이자를 내는 자산과 받는 자산으로 뒤집힌다.**

## 인과 사슬

```
선물 만기 → 롤오버 강제
        ├─ 콘탱고 (차월물 > 근월물) → 비싸게 재매수 → **매수자가 매도자에게 캐리 지급**
        └─ 백워데이션 (근월물 > 차월물) → 싸게 재매수 → **매수자가 캐리 수취**
                ↓  누적된다 — 한 번이 아니라 매달
        수개월~수년 뒤 가격 방향과 무관한 성과 격차
```

**규모가 작지 않다.** 2008~2020-04 평균 프런트 스프레드는 월 **+0.5달러**, 연환산 약 **9%**를
**12년간 매달** 냈다. 리먼 국면(2008-09~2009-06)은 월 +1.68(연 34%), 셰일 충격기
(2014-07~2016-12)는 월 +0.63(연 14%). 반대로 2020-07 이후는 월평균 **−0.66**로 뒤집혔다.

그래서 **명목 가격은 함정이다.** *"깊은 백워데이션에서 100불에 사는 것"* 이
*"깊은 콘탱고에서 60~70불에 사는 것"* 보다 낫다. 2022-05 고점(120불)에 산 USO 투자자도
현재 유가가 그보다 10% 낮은데 **+77%** 다.

## 왜 중요한가

> **판정 규칙**: 원자재 포지션을 잡기 전 **"커브가 나에게 비용을 청구하는가, 캐리를 지급하는가"**
> 를 먼저 묻는다. 가격 전망은 그다음이다. 커브를 보지 않은 원자재 뷰는 절반이 비어 있다.

**실행 분기**: 강한 콘탱고 → 원유 **기업**(업스트림. 롤 비용 없이 현금흐름·배당·자사주 누적).
강한 백워데이션 → **ETF 직접**(캐리 수취). 평탄 → 개별 기업 분석(밸류에이션·원가·부채).

**"원자재는 롤 비용 때문에 언인베스터블"은 레짐 하나를 자산의 본질로 착각한 것이다.**
2010년대 원유 펀드의 실패는 원유의 속성이 아니라 **그 시대 커브의 결과**다.
