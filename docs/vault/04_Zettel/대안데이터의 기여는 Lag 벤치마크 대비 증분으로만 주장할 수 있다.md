# 대안데이터의 기여는 Lag 벤치마크 대비 증분으로만 주장할 수 있다

## 1분 요약

뉴스 449개 키워드를 딥러닝에 넣어 BSI·CSI를 실시간 추정하고, 그걸로 GDP를 예측했다. **Adj. R²가 0.966이 나왔다.** 성공처럼 보인다. 그런데 표를 뜯어보면 **유의한 변수는 작년 GDP 하나뿐**(계수 0.95, p<0.0001)이고, 애써 만든 딥러닝 BSI·CSI는 **전부 비유의**(p=0.30~0.52)다. R² 0.966은 새 지표의 성적이 아니라 **GDP가 원래 자기 자신을 잘 설명한다는 사실**의 성적이다.

## 인과 사슬

```
RGDP는 자기지속성이 매우 강한 시계열
        ↓
Lag(1) 항 하나만 넣어도 Adj. R² ≈ 0.966 확보 (계수 0.95)
        ↓
여기에 새 변수를 얹으면 R²는 거의 안 움직인다
        ↓
그래도 "R² 0.966" 이라고 보고하면 성공처럼 읽힌다
        ↓
**증분 설명력(marginal R²)을 따로 보고하지 않으면 기여를 알 수 없다**
```

**표가 실제로 말하는 것** (표3, 시차회귀모형)

| 변수 | 계수 | p값 |
|---|---|---|
| **Lag1 RGDP** | **0.95** | **<0.0001** |
| BSI(딥러닝 추정) | 299.41 / 96.64 / 73.49 | 0.300 / 0.515 / 0.482 |
| CSI(딥러닝 추정) | 208.91 / 137.36 / 95.78 | 0.441 / 0.346 / 0.334 |

**비교 자체가 불공정했다** — 저자가 언급하지 않은 지점

```
Model 1 (LR)      : Lag1 **포함** + BSI·CSI   → 검정 RMSE 13,709  (승)
Model 3 (AR-MIDAS): Lag1 **포함** + BSI·CSI   → 26,682
Model 2 (AR-DFM)  : Lag1 **없음**, Factor1 단독 → 51,735, Adj. R² **−0.04**
```

AR-DFM의 Adj. R²가 **음수**라는 것은 단순 평균보다도 못 맞췄다는 뜻이다. Factor1 계수는 −29.80에 **p=0.981**. 즉 "시차회귀모형이 동적요소모형을 이겼다"는 결론의 실체는 방법론의 우열이 아니라 **"Lag1을 넣었는지 여부"** 일 가능성이 크다.

**왜 중요한가**: 대안데이터를 볼트에 편입할 때 두 가지를 **분리해서** 검증해야 한다.

1. **지표 자체의 완성도** — 이 논문의 딥러닝 BSI·CSI는 훈련 RMSE 2.25/2.45 → 검정 5.76/7.95로 **2.5~3.2배 열화**했다(검정기간에 코로나 급락이 포함).
2. **최종 타깃 예측에의 기여** — 이건 별개 질문이고, 이 논문은 확인하지 않았거나 확인하고도 보고하지 않았다.

**확신도: 상.** 계수와 p값이 원문 표에 그대로 있다. 저자 본인은 이를 논의하지 않고 "설명력과 예측력 모두 시차회귀모형이 우월"이라고만 결론낸다.

## 어떻게 제대로 하는가

1. **벤치마크를 Lag만 포함한 모형으로 잡는다.** 새 변수의 성적은 그 벤치마크 대비 증분으로만 보고한다.
2. 경쟁 모형끼리 **동일한 Lag 구조**를 갖게 맞춘다. 한쪽만 Lag가 빠지면 비교가 성립하지 않는다.
3. R²가 아니라 **out-of-sample 개선폭**과 **새 변수 계수의 유의성**을 함께 싣는다.
4. 지표의 out-of-sample 열화를 **평상시/위기 국면으로 쪼개** 보고한다.
