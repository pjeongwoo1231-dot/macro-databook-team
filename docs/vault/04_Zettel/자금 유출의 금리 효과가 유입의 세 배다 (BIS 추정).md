# 자금 유출의 금리 효과가 유입의 세 배다 (BIS 추정)

## 1분 요약

스테이블코인으로 돈이 들어올 때와 나갈 때 금리가 받는 충격의 크기가 다르다.
**나갈 때가 세 배 가까이 크다.** 준비자산을 급히 팔아야 하니 매도 압력이 집중되기 때문이다.
평온한 확장기의 완만한 효과와 위기 국면의 급격한 효과를 같은 계수로 보면 안 된다.

## 인과 사슬

BIS 추정 (미 3개월물 금리, 10일 이내)

  자금 **유입** (준비자산 확대) → **−2~2.5bp**
  자금 **유출** (준비자산 축소) → **+6~8bp**

→ 절대값 기준 유출 효과가 약 **2.4~4배**
→ 비대칭의 원인: 상환 요청 시 **즉시 현금화 의무** (보수적 운용 강제)

**왜 중요한가**: 이 비대칭이 스테이블코인을 **위기 증폭 장치**로 만든다.
De-pegging 우려나 위험자산 회피가 발생하면 환매 → 준비자산 매도 → 단기금리 급등 →
조달비용 상승 → 추가 환매 압력. 확장기에는 완만하게 금리를 누르지만
수축기에는 급격하게 밀어올린다.

이 vault의 비대칭 사례들과 함께 볼 것 — [[산출갭]]의 한은 반응함수 비대칭
(물가 하회 시 성장에, 상회 시 물가에 반응), [[실물 충격은 균형금리 자체를 영구히 옮긴다 — 공적분이 말하는 것]]의
지속성 비대칭. **거시에서 대칭을 가정하는 것이 예외**라는 패턴이 반복된다.

⚠ 출처가 "BIS는 …언급한다"로만 적혀 있어 어느 보고서인지 특정되지 않는다. 인용 전 확인 필요.

**확신도: 중하.** 비대칭의 방향과 크기가 구체적이나 출처가 'BIS는 …언급한다'로만 적혀 어느 보고서인지 특정되지 않는다. 노트 본인이 인용 전 확인 필요를 명시
