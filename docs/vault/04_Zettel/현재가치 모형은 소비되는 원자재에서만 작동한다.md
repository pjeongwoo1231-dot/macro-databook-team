# 현재가치 모형은 소비되는 원자재에서만 작동한다

## 1분 요약

주식 가격이 배당의 현재가치이듯, 저장 가능한 원자재 가격은 **편의수익(convenience yield)의
현재가치**여야 한다. 편의수익은 현물·선물 가격에서 **직접 측정**되므로,
이 모형은 두 가격의 결합 동학에 **검정 가능한 제약**을 건다(Campbell-Shiller 방법).

네 품목에 걸어본 결과 — **결과가 갈렸다.**

| 품목 | 현재가치 모형 | 초과수익의 계열상관 |
|---|---|---|
| **난방유** | **잘 맞는다** | **없다** (모든 자기상관이 표준편차 1 이내, Q통계 p>0.9) |
| 구리 | 엇갈림 | 일부 있음 |
| 목재 | 엇갈림 | 일부 있음 |
| **금** | **특히 안 맞는다** | **상당히 크다** |

**두 결과가 나란히 간다** — 모형 부합도와 계열상관 부재가 같은 순서다.

## 왜 갈리나 — 편의수익의 크기가 답이다

- **난방유·구리·목재**: 기업이 재고 유지를 위해 이자·보관비 외에
  **월 5~10%의 기대 손실**까지 감수한 시기가 있다. 편의수익이 그만큼 크다
- **금**: 월간 순편의수익이 **항상 가격의 1% 미만, 대개 0.2% 미만**이고
  가격과의 공행도 거의 없다(1981년 짧은 급등 제외)

→ 금의 급등(1980, 1982~83)은 **가격이 계속 갈 것이라는 기대**로 해석된다.
저자의 표현대로 **투기적 버블**이거나, 미래 편의수익 상승 기대에 근거한 것이다.

## 인과 사슬

```
생산 투입으로 **소비되는** 원자재 → 재고 부족의 실물 비용 큼 → 편의수익 ↑
   → 가격 = 편의수익의 현재가치 (모형 성립) → 초과수익에 계열상관 없음 (효율적)
가치저장 수단(금) → 편의수익 ≈ 0 → 현재가치가 가격을 묶지 못함
   → 가격이 펀더멘털에서 **일시적으로 이탈**("fads") → 초과수익에 계열상관
```

## 왜 이게 중요한가 — 판정 규칙

**"원자재"를 한 덩어리로 다루면 안 된다. 편의수익의 크기가 분류 기준이다.**

| 유형 | 판정 |
|---|---|
| **소비형**(에너지·산업금속·목재) | 곡선·재고 논리가 작동. [[선물 곡선 (Futures Curve)]]·[[원자재 재고]] 규칙 유효 |
| **가치저장형**(금) | 곡선 논리가 **가격을 설명하지 못한다.** 심리·실질금리·통화 쪽으로 갈 것 |

→ [[금 가격]]을 [[구리 가격]]과 같은 문장에 넣지 않는다.
볼트가 이미 [[구리 가격]] 노드에 *"석유와 같은 문장에 넣지 않는다"* 규칙을 갖고 있는데,
**금은 그보다 더 멀다** — 아예 다른 모형이 필요하다.

## 데이터가 적게 든다는 점

저자가 강조한 실무 이점 — 이 검정은 **현물·선물 가격만** 있으면 된다.
재고·생산비·수급 변수가 필요 없다. **우리 파이프라인으로 재현 가능한 검정**이다
(→ 검증 큐 후보).

## 한계

- 표본이 **1975~1990년 3월**이다. 원자재 금융화(2004~2008 지수투자 유입) 이전이다.
  **금의 계열상관 추정치는 표본에 크게 의존한다** — 저자 스스로 Cutler-Poterba-Summers의
  1914~1988 표본에서는 ρ 추정치가 **0.020**에 불과했다고 대조했다
- **네 품목**만이다. 일반화 금지.
- "fads"는 **해석**이지 식별된 메커니즘이 아니다. 저자도 대안(미래 편의수익 상승 기대)을 병기했다.
- 편의수익 측정이 **차익거래 관계에 의존**한다. 시장이 얇거나 인도 제약이 있으면 측정 자체가 흔들린다.

## 같이 볼 것

- [[저장모형은 원자재 급등은 설명하지만 지속성은 설명하지 못한다]] — 재고 쪽 접근의 한계.
- [[원자재의 평균회귀는 두 종류다 — 어느 측도에서 회귀하는지가 함의를 가른다]] —
  **금은 물리 측도 회귀만** 갖는다는 결과와 정합적이다. 편의수익이 없기 때문이다.
- [[원자재 ETF의 성과를 정하는 건 가격 방향이 아니라 롤 캐리다]] — 편의수익의 실무 발현.
