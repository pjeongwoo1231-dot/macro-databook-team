# 자동식별자 — 앞단 층에 한 종류만 남는다는 사실 자체가 판별력이다

## 1분 요약

층을 벗겨낼 때 앞쪽 층에 **한 종류의 기업만** 나타나면, 그 층은 그것만으로 판정 근거가 된다.
정상 DEA의 앞단 층에는 건전기업만, 부실관행 DEA의 1~2층에는 부도기업만 나온다.
사전 정보 없이도 "확실한 건전"과 "확실한 부도"를 자동으로 골라낼 수 있다는 뜻이다.

## 인과 사슬

정상 DEA + 층화 → 앞단 여러 층에 **건전기업만** 효율적
  (2002년 층별 11·14·16·10·20개 전부 건전, 10층까지 계속 건전만)
  → 건전 자동식별자 (non-bankruptcy self-identifier)

부실관행 DEA + 층화 → 1~2층에 **부도기업만** 효율적
  → 부도 자동식별자 (bankruptcy self-identifier)

결합 : 정상 DEA로 '확실한 건전' 선제외 → 남은 기업에 부실관행 DEA 적용

**왜 중요한가**: 지도학습 없이 극단값을 확정할 수 있다는 점이 실무적으로 크다.
심사 인력을 "확실한 건전"과 "확실한 부도"에 쓰지 않고 **회색지대에만 배분**할 수 있다.

⚠ 다만 결합의 실제 이득은 저자 서술보다 작다. 표 6에서 정상 DEA 1+2층을 선제외해도
건전 정확도는 층별로 99→99, 95→96, 90→91 — **0~1%p 개선**이다.
초록의 "향상시킬 수 있었다"는 방향은 맞지만 크기는 미미하다.

**확신도: 중상.** 층별 구성은 표에서 직접 확인되는 사실이다. 단 노트 본인이 결합의 실제 이득을 0~1%p로 축소 보고했다 — 자동식별 자체는 성립하되 실익은 작다
