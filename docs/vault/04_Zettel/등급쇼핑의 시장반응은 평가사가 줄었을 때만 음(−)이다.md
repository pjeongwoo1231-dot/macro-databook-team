# 등급쇼핑의 시장반응은 평가사가 줄었을 때만 음(−)이다

## 1분 요약

"시장이 등급쇼핑을 알아보는가"의 답은 **예/아니오가 아니라 방향에 달렸다.**
등급이 오르면서 평가사가 **늘면** 주가가 오르고, **줄면** 내린다. 같은 "평가기관 변경"인데
부호가 뒤집힌다. 투자자는 평가사 수의 **증감을 신호로 읽는다** — 늘어난 건 검증이 늘었다는 뜻,
줄어든 건 불리한 등급을 뺐다는 뜻이다.

## 인과 사슬

```
등급 상승 공시
   ├─ 평가사 **증가** → "검증 주체가 늘었다" → 신뢰성 ↑ → CAR ↑
   │     DUMMY1 = **+0.048** (t=2.36**) / CAR2 **+0.049** (t=2.59**)
   └─ 평가사 **감소** → "불리한 등급을 뺐다" → 등급쇼핑 인지 → CAR ↓
         DUMMY2 = **−0.051** (t=−2.25**) / CAR2 **−0.041** (t=−1.99**)
```

**전체를 한 덩어리로 묶으면 이 비대칭이 사라진다.** 주 회귀(표4-4)에서 변경 여부만 보면
DUMMY = **+0.045 (t=2.78\*\*\*)** 로 양(+)이다. 증가 케이스가 감소 케이스를 압도해
평균이 양으로 나온 것이고, 이 값만 보면 "시장이 등급쇼핑을 못 알아본다"는 정반대 결론이 나온다.

**왜 중요한가**: **더미를 쪼개기 전과 후의 결론이 반대다.** 방향 정보를 잃은 이진 더미는
비대칭을 평균으로 지운다. [[매크로 해석 프레임]]의 "비대칭을 기본으로 가정한다"가
회귀 설계 단계에서 적용돼야 하는 사례 — 사후 해석이 아니라 **변수 정의 시점**의 문제다.

**확신도: 중하.** 아래가 결론을 잠식한다.
- 등급쇼핑이 **관측되지 않아 대리변수**를 썼다. "등급 상승 + 평가사 변경"이 등급쇼핑이라는
  보장이 없다 — 정상적인 평가사 교체·신규 계약도 같은 값을 갖는다
- 증가·감소 각각의 **표본 수가 보고되지 않았다** (변경 전체가 51건). 감소 케이스가 몇 건인지
  모르는 채로 t=−2.25를 읽고 있다
- 수정 R² **0.054~0.071**. CAR 변동의 93% 이상이 설명되지 않는다
- 효과가 공시일이 아니라 D+2~D+3에 몰렸다 → [[이벤트 효과가 공시일이 아니라 이틀 뒤에 몰렸다]]
