# 호르무즈 충격의 부담은 1차 노출과 다른 곳에 쌓인다

> 🔴 **2026-08-31 개정 — 이것은 더 이상 가정이 아니다.**
> BIS AER 2026(2026-06)이 **2026년 3월 초 호르무즈 해협의 실제 봉쇄**를 기록했다.
> 원유 흐름이 **일 1,000만 배럴 이상(정상 공급의 13%)** 끊겼다 — 1970년대 위기(약 8%)보다 크다.
> → [[호르무즈는 실제로 닫혔다 — 공급 손실은 1970년대보다 컸다]]
>
> **따라서 아래는 스트레스 테스트가 아니라 채점 가능한 사전 예측이다.** 채점은 아직 안 했다(미착수).
> 채점할 때 확인할 것 — ① 화학·금속·전자·기계의 하류 비용이 실제로 올랐나
> ② 재고가 실제로 전달량을 줄였나 ③ 1차 노출 순위와 실현 부담 순위가 정말 달랐나

## 1분 요약

호르무즈 봉쇄를 **다지역 투입산출(MRIO) 스트레스 테스트**로 돌렸다
(OECD ICIO 2025 판, 2022년 기준). 충격을 원유·가스 채굴, 정제, 전력, 운송,
운송지원 부문에 걸고 **7차 전파**까지 재고 완충을 넣어 밀어봤다.

**핵심 결과 — 1차 노출과 누적 부담이 일치하지 않는다.**

처음 맞는 곳은 에너지 부문이지만, 나중에 비용을 짊어지는 곳은
**에너지 집약 소재 · 항공 서비스 · 화학 · 광물 · 금속 · 전자 · 기계**다.
물자와 물류를 사들이는 경로로 하류에 쌓인다.

## 재고가 얼마나 막아주나 — 임계값이 이동한다

하류 제조업의 추가비용이 **10%**에 도달하는 데 필요한 **상류 에너지 충격 크기**:

| 재고 흡수율 | 필요 상류 충격 |
|---|---|
| 0% | **73.6%** |
| 30% | **85.3%** |
| 50% | **92.2%** |

같은 기준선(상류 20% 충격)에서 하류 제조업 평균 추가비용은 **2.72% → 2.34%** 로 낮아진다.

**재고는 전달량을 줄이지만 전달 경로를 바꾸지는 못한다** — 저자들의 명시적 결론이다.

## 인과 사슬

```
[[지정학적 리스크]] ↑ (호르무즈) → 원유·LNG 가용량 ↓ + 우회·운임·보험·항만·창고 비용 ↑
   → 채굴·정제·전력·운송에 1차 충격
   → (재고 완충) → 물자·물류 구매 경로로 7차까지 전파
   → **화학·금속·전자·기계에 하류 비용** → [[산업생산]] 비용 ↑
   → 최종수요 시장으로 귀착 (1차 노출 순위와 **다른 순위**)
```

## 무엇을 먼저 봐야 하나 — 링크 목록

저자들이 꼽은 최대 전달 링크(금액 기준):

| 링크 | 규모 |
|---|---|
| ROW 에너지채굴 → **중국 정제** | 46.1억 달러 |
| ROW 에너지채굴 → **인도 정제** | 28.7억 달러 |
| 캐나다 에너지채굴 → **미국 정제** | 22.3억 달러 |
| ROW 에너지채굴 → 중국 전력 | 21.4억 달러 |
| 중국 해운 → **싱가포르 해운** | 17.8억 달러 |

**지리적 근접성이 아니라 절대 거래 규모가 압력의 지속을 설명한다.**
연쇄 압력과의 상관은 **내향 연결중심성 0.69**(스피어만)로 가장 높고,
고유벡터 0.51, 매개·PageRank는 0.31 수준이다.
→ **상류 의존의 폭과 공급망 중심성**이 전파를 만든다.

## 왜 이게 중요한가 — 판정 규칙

**호르무즈 국면에서 유가만 보면 충격의 절반을 놓친다.**

1. **1차 노출 순위로 피해를 예단하지 않는다.** 하류 누적 부담 순위가 다르다
2. **재고는 크기를 줄이지 경로를 바꾸지 않는다** — 완충을 이유로 안심하면 안 된다
3. **한국은 정제·화학·전자·기계가 모두 하류 부담 부문**이다. 정유주 손익만이 아니라
   **소재·전자 원가**로 번지는 경로를 함께 볼 것
4. 운임·보험·항만 비용이 충격의 **일부**다 — 유가에 안 잡히는 성분

## 한계

- ~~**스트레스 테스트다. 확률 예측이 아니다.**~~ → **2026-03에 실제로 일어났다.**
  이제는 사후 채점의 대상이다(위 개정 주석 참조).
- **정태 투입산출**의 한계 — 가격 반응에 따른 **대체(substitution)** 가 없다.
  현실에서는 우회·연료 전환이 일어나므로 **상한 추정**으로 읽어야 한다.
- 2022년 ICIO 표 기준이다. 러시아 재편 이후의 물류 구조가 부분적으로만 반영된다.
- 재고 흡수율 30%·50%는 **가정값**이다. 실제 산업별 재고일수와 대조하지 않았다.
- MDPI 저널이다. 심사 강도에 대한 논란이 있는 출판사이므로 **결론의 방향을 쓰되
  수치는 재현 가능성을 전제로 인용**할 것.

## 같이 볼 것

- [[유가 상승이 주가에 미치는 부호는 유가가 왜 올랐는지가 정한다]] —
  호르무즈는 **예비적 수요**를 자극하는 전형적 사건이다. 그 경우 주가 반응은 유의한 음(−).
- [[호르무즈는 실제로 닫혔다 — 공급 손실은 1970년대보다 컸다]] — **실제 사건 기록.**
  ⚠ 거기서 드러난 이 모형의 사각지대: **헬륨처럼 금액 비중이 작은 투입재**는
  금액 기준 링크 분석에 잡히지 않는데, 실제 병목은 거기서 생겼다.
- [[원자재 부문의 충격은 투입산출 경로로는 거의 안 퍼진다]] —
  ⚠ **정면으로 긴장한다.** 그 논문은 투입산출 경로의 전파가 작다고 봤다.
  차이는 이 논문이 **에너지 가용량 + 물류비용을 함께** 충격으로 걸었다는 데 있다.
  가격 충격만 걸면 작고, 물류·가용량을 함께 걸면 커진다 — **무엇을 충격으로 정의했는지 확인할 것.**
