# 고빈도 통화 서프라이즈는 충격의 자격을 갖추지 못했다 — 자기상관되고 예측 가능하다

## 1분 요약

FOMC 발표 직후 30분 금리 변화 — 이른바 고빈도 서프라이즈는 "정의상 예상 밖"이라 깨끗한
충격으로 널리 쓰인다. **아니다.** 이 계열은 자기상관돼 있고, 과거 정보로 예측되며,
중앙은행 전망과 상관된다. **충격이라면 셋 다 성립하면 안 된다.**

## 인과 사슬

**진짜 충격이 만족해야 할 세 조건과 실제 관측**

| 조건 | 고빈도 서프라이즈 실제 |
|---|---|
| 자기상관이 없어야 한다 | ✗ **자기상관됨** |
| 과거 정보로 예측 불가해야 한다 | ✗ **예측 가능** |
| 중앙은행 전망과 무관해야 한다 | ✗ **상관됨** |
| (추가) 예고된 정책변화가 없어야 한다 | ✗ **포워드 가이던스가 섞여 있다** |

```
자기상관의 정체 = **기대의 느린 조정**(정보경직성)
   → 서베이 데이터가 여러 경제주체에서 같은 패턴을 보인다
전망과의 상관 = 중앙은행의 **사적 정보**가 발표에 실려 나감
```

→ **처방**: 서프라이즈를 (i) **자기 시차**와 (ii) **Greenbook 예측·예측 수정치**
(실질성장·물가·실업률)에 회귀시켜 **잔차만** 도구변수로 쓴다.

**왜 중요한가 — "정의상 외생"은 근거가 아니다.**
고빈도 식별의 설득력은 "발표 직후 30분 창(window) 안에서는 다른 게 안 움직인다"는
**타이밍 논증**에 있다. 그런데 타이밍이 좁다고 계열이 충격이 되는 것은 아니다.
**시간창의 협소함과 통계적 외생성은 다른 문제다.**

**일반화 — 외부도구변수 논문을 읽을 때 점검 3종**
1. 도구변수 자체의 **자기상관**을 보고했는가
2. 도구변수가 **과거 거시변수로 예측되는지** 검정했는가
3. 도구변수가 **정책당국 전망과 상관**되는지 봤는가

셋 다 없으면 "외생적이다"는 저자의 **주장**이지 결과가 아니다.
이 볼트가 [[벤치마크가 변수 하나짜리 회귀면 R²는 성과가 아니다]] ·
[[랜덤워크 벤치마크가 없다 — 금리 예측에서 가장 이기기 어려운 상대를 빼놓았다]]에서
"벤치마크를 확인하라"고 배운 것의 **식별 버전**이다.

**MAR의 강점**: 저자들이 **자기 도구변수의 타당성을 스스로 테스트 가능한 함의로 만들어 검정**했다.
대부분의 외부도구변수 논문이 생략하는 절차다 —
[[한계 절이 없는 논문 — 한계라는 단어가 25페이지에 0회 등장한다]]의 정반대.

**확신도: 중상.** 진단 자체는 명확하고 Ramey(2016)·Coibion(2012)이 독립적으로 지지한다.
**유보**: ① 2017 원고 대조본 ② 처방(Greenbook 통제)의 타당성은 Greenbook이 중앙은행
정보집합을 대리한다는 **검증 불가한 가정**에 의존한다 ③ 한국은 Greenbook 대응물
(한은 경제전망보고서)의 공개 시차·빈도가 달라 **그대로 이식되지 않는다.**
