# 사후 확정된 지표로 계산한 RMSE는 실시간 성과가 아니다

## 1분 요약

이 논문에서 도소매·음식숙박업의 최우수 설명변수는 **경기동행지수**였다(RMSE 0.2%).
그런데 동행지수는 나중에 크게 수정되는 지표다. **수정이 끝난 값으로 과거를 맞히면
당연히 잘 맞는다.** 실시간으로 그 정확도가 나올 리 없다.

## 인과 사슬

논문 결과: 도소매·음식숙박업 GDP ← [[동행종합지수 (CCI·CCCI)]], **RMSE 0.2%**

그런데 [[2012 월별 GDP의 추정과 경기지표 활용 가능성 (김명기·백웅기)]]의 실증
→ 2008년 동행종합지수(CCCI)가 3년간 **월평균 2.2p 상향조정**

→ 예측 시점에 볼 수 있는 값 ≠ 논문이 회귀에 쓴 값
→ **실시간 데이터 문제(real-time data problem)**. 논문은 이를 다루지 않는다

**왜 중요한가**: 나우캐스팅·예측모형 논문을 읽을 때 반드시 확인할 항목이다.
"vintage 데이터를 썼는가, 확정 데이터를 썼는가." 확정 데이터로 백테스트한 성과는
**실전에서 재현되지 않는다.**

이 vault의 모형 논문 전반에 적용할 점검 항목이다 — [[표본 내 1등이 표본 외에서도 1등이었다 — 단 방향은 셋 다 틀렸다]]가
표본 내/외 구분이라면, 이것은 **같은 표본 내에서도 데이터 시점(vintage) 구분**이 필요하다는 이야기다.
둘은 다른 문제이고 둘 다 확인해야 한다.

**확신도: 상.** '예측 시점에 볼 수 있는 값 ≠ 회귀에 쓴 값'은 논리적 필연이고, 동행지수 월평균 2.2p 상향이라는 실측 근거가 붙는다

## 핵심 지표 · 연결고리

- **관련 노드**: [[동행종합지수 (CCI·CCCI)]] · [[GDP 성장률]] · [[경기선행지수 (CLI)]]
- **리서치 관점**: 백테스트 성과를 볼 때 "그 시점에 그 값을 볼 수 있었는가"를 먼저 묻는다.
