# 등급쇼핑 논문의 초록과 결론이 정반대다 — 시장이 인지하는가에 대해

## 1분 요약

같은 논문이 **핵심 질문에 두 번 답하는데 답이 반대다.** 초록과 본문은 "시장이 등급쇼핑을
알아보지 못한다"고 쓰고, 결론은 "적절하게 반영하고 있다"고 쓴다. 두 문장을 화해시키는
설명이 논문 어디에도 없다. 초록만 읽고 인용하면 저자의 최종 결론과 반대되는 말을 하게 된다.

## 인과 사슬

```
주 분석 (표4-4) — 평가사 변경 전체
   DUMMY = +0.045 (t=2.78***)  → 등급쇼핑기업이 오히려 CAR 높음
        ↓
   **초록**: "주식시장 이용자들은 등급쇼핑에 관한 정보를 정확하게 인지하지 못하고
             신용등급 상승정보만을 긍정적으로 판단하여 반응"
   **본문 4.5(p18)**: "이해관계자들은 발행사의 등급쇼핑현상을 제대로 인식하지 못하고"

추가분석 (표4-5) — 증가/감소 분리
   DUMMY2(감소) = −0.051 (t=−2.25**)  → 감소 시에는 음(−)
        ↓
   **결론(p21)**: "주식시장의 참여자들은 이를 **적절하게 기업가치에 반영**하고 있음"
```

**두 절이 서로 다른 표를 보고 각자 결론을 냈다.** 논문은 어느 쪽이 최종 답인지 밝히지 않는다.

**왜 중요한가**: [[매크로 해석 프레임]] 3단계의 **네 층 대조(제목·초록·본문·표)** 가
국내 회계학 논문에서도 그대로 걸린다는 증거다. 이 볼트는 같은 패턴을
[[연결성 문헌은 초록과 본문이 어긋나는 사례가 반복된다]](크립토 3편) ·
[[저자는 정책금리가 전 만기에 영향이라 썼지만 표에는 1년물만 유의하다]](김석진 2024)에서
이미 확인했다. **문헌군을 가리지 않는 현상이다.**

**인용 규칙**: 가장 좁은 층에 맞춘다.
> ✅ **"평가사가 감소한 경우에 한해** 시장이 등급쇼핑을 부정적으로 반영한다" (표4-5 근거)
> ❌ "시장이 등급쇼핑을 적절히 반영한다" (결론 문장 — 전체로 일반화, 표가 뒷받침 안 함)
> ❌ "시장이 등급쇼핑을 인지하지 못한다" (초록 문장 — 추가분석이 반박)

**같은 논문에서 함께 발견된 표 오류** (표 내부 정합성 검사에 걸림)
- 표4-1: CAR1 중위수 **90.014** — 0.014의 오타 (평균 0.019, 99% 0.269와 대조하면 명백)
- 표4-3: CAR1 t=**2.64**에 `***`(1%), CAR2 t=**2.91**에 `**`(5%) — **t가 큰 쪽 유의도가 낮다**
- 표4-3: LEV t=0.94 / z=−0.32, FOR t=−1.33 / z=+1.68\* — **t와 z의 부호가 반대**

**확신도: 상.** 초록·본문과 결론이 반대라는 것은 문서 대조로 확정되며, 표 내부 오류 3건도 표에서 직접 확인된다
