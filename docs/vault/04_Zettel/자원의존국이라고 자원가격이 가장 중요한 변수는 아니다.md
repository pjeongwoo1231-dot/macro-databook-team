# 자원의존국이라고 자원가격이 가장 중요한 변수는 아니다

## 1분 요약

몽골은 구리·석탄 수출로 먹고사는 나라다. 그러니 구리 값이 성장률을 좌우할 것 같다. 그런데 21년치를 회귀해 보면 **가장 강한 변수는 구리가 아니라 환율**이다. 구리는 10% 수준에서 겨우 걸리고(p=0.057), **투그릭 절하는 1% 수준에서 성장률을 확실히 끌어내린다.** 저자의 첫 번째 정책 제언이 "자원산업 육성"이 아니라 **"환율 안정"** 인 이유다.

## 인과 사슬

```
회귀 결과 (몽골 실질 GDP 성장률, 2005~2025 연간 21개 관측치, R²=0.504)

**ln 환율(USD/MNT)**   −8.288***   p=0.0022   ← 가장 강함
ln 구리가격             9.638*      p=0.0567   ← 한계적
ln 석탄가격             1.532       p=0.5721   ← 비유의
중국 실질 GDP 성장률    0.133       p=0.8095   ← 사실상 0
```

**환율 경로가 자원가격 경로보다 강한 이유**

```
투그릭 절하
   ├─ 수입비용 ↑ (자본재·소비재 대부분 수입)
   ├─ **외채 부담 ↑** (외화표시 부채)
   └─ 물가 ↑ → 실질구매력 ↓
        ↓
   성장률 ↓  (환율 1% 절하 시 약 −0.083%p)

구리가격 ↑
   └─ 수출수익·외환유입 ↑ → 성장률 ↑  *(단 p=0.057, 한계적)*
```

**왜 중요한가**: **원자재 가격을 자원국 전망의 주된 근거로 쓰는 서술**을 만나면 이 결과를 대조할 것. "구리가 오르니 자원국이 좋아진다"는 통념이 21년 표본에서 **10% 수준에서만 겨우 잡힌다.** 자원국 리스크를 볼 때 상품 가격보다 **통화·외채 구조**를 먼저 봐야 한다는 실무 순서를 준다.

**확신도: 하.** 결론 방향은 그럴듯하나 **계량 설계에 심각한 문제가 있다.**
- **표본이 연간 21개** — 설명변수 4개+상수로 자유도 16. 이 크기에서 p=0.0567을 "관련성 있음"으로 읽는 것은 관대하고, 반대로 비유의 결과를 "영향 없음"으로 읽는 것도 위험하다(검정력 부족).
- **I(1) 변수를 수준으로 OLS 회귀했다.** 몽골 성장률·구리·석탄·환율이 모두 I(1)로 판정됐고 **공적분 벡터 2개**를 확인해 놓고도 VECM/FMOLS/DOLS가 아닌 **일반 OLS 결과만** 제시한다. → **표준오차를 신뢰할 수 없고 t=−3.737조차 액면대로 받기 어렵다.**
- **환율의 내생성** — 자원가격 상승 → 외화 유입 → 통화 절상은 논문 스스로 서술한 경로다. 그렇다면 환율은 구리가격의 **결과**이기도 한데 IV도 시차도 없다.
- **제목과 모형의 괴리** — "에너지 전환"을 전면에 내세우지만 **모형에 에너지 전환을 측정하는 변수가 없다.** 저자도 구리가격이 직접 측정 지표가 아니라고 인정한다.
- 게재지가 계량경제 저널이 아니라 지역학 저널(《중국학논총》)이다.

**석탄 비유의에 대한 저자 해석은 과하다**: "에너지 전환으로 화석연료의 상대적 중요성이 약화"됐다고 읽는데, **21개 관측치의 비유의 결과 하나로 구조 변화를 주장하는 것은 무리다.** 석탄은 여전히 몽골 수출의 핵심 품목이다.
