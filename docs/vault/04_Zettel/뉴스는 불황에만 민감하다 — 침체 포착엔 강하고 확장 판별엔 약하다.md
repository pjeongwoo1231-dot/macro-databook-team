# 뉴스는 불황에만 민감하다 — 침체 포착엔 강하고 확장 판별엔 약하다

## 1분 요약

"불황"·"경기침체" 같은 단어가 **기사에 몇 번 나왔는지 세기만 해도** 경기지수가 된다. 서베이처럼 표본을 설계하고 조사할 필요가 없고, 사건이 터지는 즉시 쌓인다. 그런데 이 지수에는 뚜렷한 편향이 있다 — **나쁜 소식은 잘 잡고 좋은 소식은 잘 못 잡는다.** 언론이 원래 그렇게 생겼기 때문이다.

## 인과 사슬

```
경기 악화 사건 발생
        ↓
언론 보도 급증 ("불황"·"경기침체" 기사 건수 ↑)
        ↓
BKI(빅카인즈 뉴스 경기지수) 하락
        ↓
[[경기침체]] 수축국면을 조기 포착

  ※ 반대 방향은 약하다
경기 개선 → 보도 증가폭 작음 → 신호 약함
```

**비대칭이 데이터 단계에서 이미 보인다** (키워드-ESI 상관, 표 3.3)

| 키워드 | ESI와의 상관 |
|---|---|
| "불황" | **−0.81** |
| "경기침체" | **−0.72** |
| "호황" | **−0.04** (사실상 무관) |

**성능 — 침체 예측에서 기존 지표를 압도**

| 로짓모형 설명변수 | 수축국면 예측 정확도 |
|---|---|
| **BKI 순환변동치** | **0.84 ~ 0.99** |
| [[경기선행지수 (CLI)]] 순환변동치 | 0.69 ~ 0.93 |
| 경제심리지수(ESI) 순환변동치 | **0.40 ~ 0.51** |

ESI 기반 모형은 2011~2016 검증구간에서 정확도 0.40~0.51로 **사실상 무용**했다. 다만 특이도(실제 확장을 확장으로 맞춘 비율)에서는 CLI가 근소하게 나은 구간이 있다 — **비대칭의 실측 증거**다.

**선행폭이 더 안정적이다**: 전환점 선행시차의 평균은 CLI와 같은 6.5개월인데 **표준편차가 1.7개월 더 작다.** 특히 경기 **정점**에서 1.8~2.6개월 더 작다. → 선행 폭이 비슷해도 **예측 가능성이 다르다.** [[경기선행지수가 동행지수를 선행한다는 통계적 증거는 없다]]의 "선행폭이 국면마다 요동친다"는 문제를 뉴스지수가 완화한다.

**왜 중요한가**: 운용 규칙이 갈린다.
- 뉴스지수 **급락(악화)** → 신뢰한다. 침체 신호로 채택.
- 뉴스지수 **완만한 개선** → 과신하지 않는다. 확장 국면 판별은 다른 지표로 확인한다.

**확신도: 중.** 저자가 한계를 명시한다 — 빅카인즈에 **판매부수 상위 3개 신문(조선·중앙·동아)이 빠져 있고**, 언론사별 축적 시작 시점이 제각각이다. 또한 이 논문이 다룬 것은 **"침체냐 아니냐"의 이진 판별까지**이며 성장률 수준 예측은 하지 않았다.

## 핵심 지표 · 연결고리

- **관련 노드**: [[경기침체]] · [[경기선행지수 (CLI)]] · [[BSI (기업경기실사지수)]] · [[CSI (소비자심리지수)]] · [[소비자신뢰지수 (CCI)]]
- **일반화**: **미디어·검색·소셜 기반 대안데이터는 대부분 이 비대칭을 갖는다.** 부정적 사건이 주목을 끌기 때문이다. 대안데이터 지표를 만들 때 **상승 신호와 하락 신호에 다른 임계값**을 두는 것이 기본 설계가 되어야 한다.
- **표본 대표성 우회**: 서베이 지표의 고질적 문제(표본 설계·응답률·대표성)를 **전수 텍스트**로 우회한 사례다. 다만 매체 구성 편향이라는 다른 형태의 대표성 문제로 갈아탄 것이기도 하다.
- **역할 분담**: 이 지수의 강점은 **이진 판별**이지 수준 추정이 아니다 → [[나우캐스팅에는 세 계보가 있다 — 예측·분해·합성]]의 수준 예측 계열과 보완 관계.
