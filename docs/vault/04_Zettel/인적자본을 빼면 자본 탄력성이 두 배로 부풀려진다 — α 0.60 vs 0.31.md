# 인적자본을 빼면 자본 탄력성이 두 배로 부풀려진다 — α 0.60 vs 0.31

## 1분 요약

교과서 Solow 모형으로 국가 간 소득을 회귀하면 **자본의 산출탄력성 α가 0.60**으로 나온다.
그런데 이론이 말하는 α는 자본소득분배율, 즉 **대략 1/3**이다. 두 배 가까이 어긋난다.
MRW는 이걸 모형의 실패가 아니라 **빠뜨린 변수 탓**이라고 본다. 교육 투자를 회귀식에 넣자
같은 데이터에서 α가 **0.31로 내려앉았다.** 교육을 안 넣으면 "자본이 한 일"에 "사람이 한 일"이
섞여 들어간다 — 부유한 나라는 기계도 많고 학교도 많아서, 둘을 안 나누면 기계가 공을 다 가져간다.

## 인과 사슬

```
인적자본(교육)을 회귀식에서 누락
        ↓  교육투자와 물적투자는 국가 간 양(+) 상관
물적자본 계수가 인적자본의 기여까지 흡수 (누락변수편의)
        ↓
[[총요소생산성 (TFP)]] 해석 왜곡 · 자본축적의 기여 과대평가
        ↓
"Solow 모형은 α가 비현실적이라 틀렸다"는 오진
```

**원문 수치**(비산유 98개국, 1960–85, g+δ=0.05 가정):

| | 제약회귀 implied α | R² |
|---|---|---|
| 교과서 Solow (Table I) | **0.60** (s.e. 0.02) | 0.59 |
| 확장 Solow (Table II) | **0.31** (s.e. 0.04) | 0.78 |

확장 모형의 implied β(인적자본)는 **0.28** (s.e. 0.03)이다. α+β ≈ 0.59로 1보다 확실히 작다 —
**수확체감이 유지된다**는 뜻이고, 이것이 내생성장(α+β=1)과 갈리는 지점이다.

## 왜 중요한가

**"계수가 이론값과 안 맞는다"는 관측은 모형 기각의 근거가 되기 전에 설정 오류부터 의심해야 한다.**
MRW는 같은 데이터·같은 모형에서 변수 하나를 추가해 α를 0.60 → 0.31로 옮겼다.
[[벤치마크가 변수 하나짜리 회귀면 R²는 성과가 아니다]]와 짝을 이루는 교훈이다 —
**설명력이 아니라 계수의 크기가 설정을 심판한다.**

  Lucas는 같은 인적자본을 **외부효과**로 놓고, MRW는 **사적 생산요소**로 놓는다. 이 차이가 결론을 가른다.
