# 저장할 수 없는 재화의 선도가격은 수요 분포의 왜도가 정한다

## 1분 요약

전력은 **경제적으로 저장할 수 없다.** 그래서 재고를 통한 차익거래가 성립하지 않고,
선물가격을 현물+보관비용으로 묶는 익숙한 방법이 통하지 않는다.

균형모형이 내놓는 결론은 **선도 프리미엄의 부호가 수요 상태에 따라 뒤집힌다**는 것이다.

- **기대 수요가 낮고 수요 위험이 보통**이면 → 선도가격이 미래 현물의
  **하향 편의 예측치**(즉 음의 프리미엄)
- **기대 수요나 수요 분산이 높으면** → 프리미엄이 **커진다**.
  현물가 분포에 **양의 왜도**가 생기기 때문이다

예비적 증거로 **여름철에 선도 프리미엄이 가장 크다**고 보고한다.

## 인과 사슬

```
저장 불가 → 재고 완충 없음 → 수요 급증이 현물가에 **비대칭적으로** 전가
        → 현물가 분포에 양의 왜도 → 생산자·소비자의 헤지 수요가 비대칭
        → 선도 프리미엄 ↑ (수요·분산이 높을 때)
```

## 왜 이게 중요한가

**"선물가격은 미래 현물가의 불편 예측치"라는 기본 가정이 저장 불가 재화에서는 깨진다.**
전력이 극단적 사례지만, 저장이 **비싸거나 제약된** 재화라면 정도의 차이일 뿐 같은 힘이 작동한다 —
천연가스(저장 용량 제약)·전력·일부 농산물.

[[원자재 재고]] 판정 규칙이 **"가격↑ + 재고↓ = 펀더멘털"** 인데,
**재고가 존재하지 않는 재화에는 그 규칙을 쓸 수 없다.** 대신 봐야 하는 것은
**수요 분포의 모양**(기대 수준과 분산)이다.

## 볼트에 붙는 자리

[[선물 곡선 (Futures Curve)]] 노드에 **저장 불가 사례**를 더한다.
편의수익 개념 자체가 재고를 전제하므로, 이 축이 없으면 전력·가스를 곡선 논리로
잘못 읽는다.

[[에너지 전환]]과도 걸린다 — 재생에너지 비중이 오르면 **공급의 변동성**이 커지고,
그것이 수요 분산과 같은 방향으로 왜도를 키운다. 이 모형대로면
**선도 프리미엄이 구조적으로 확대**되는 쪽이다(원 논문이 검증한 명제는 아니다).

## 한계

- 실증은 **예비적(preliminary)**이라고 저자들이 명시했다. 계절 패턴 하나다.
- 미국 도매전력 시장(1990년대 말~2000년대 초) 대상이다.
  **한국 전력시장은 규제 구조가 달라 그대로 옮길 수 없다.**
- 전력에서 도출한 명제를 가스·농산물로 확장하는 것은 **이 노트의 추론**이며
  원 논문의 주장이 아니다.
