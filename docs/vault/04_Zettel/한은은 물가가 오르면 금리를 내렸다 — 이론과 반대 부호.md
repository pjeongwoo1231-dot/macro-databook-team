# 한은은 물가가 오르면 금리를 내렸다 — 이론과 반대 부호

## 1분 요약

물가안정목표제를 쓰는 중앙은행이라면 물가가 오를 때 금리를 올려야 한다.
그런데 2000~2011년 데이터로 추정하면 **[[CPI (소비자물가지수)]]가 오를 때
금리 인하 확률이 높아진다.** 저자도 "논리적으로 받아들이기 힘든 결과"라고 인정한다.

## 인과 사슬

다항로짓 (MPC, 동결 대비, 표본 2000.1~2011.9)

  [[CPI (소비자물가지수)]] ↑ → **인하** 확률 ↑ (계수 **1.693\***, 10% 유의)  ← 이론과 반대
  [[장단기 금리차]] ↑ → 인하 확률 ↓ (5% 유의)  ← 이론 부합
  [[산업생산]] ↑ → 인하 확률 ↓ (5% 유의)  ← 이론 부합

→ 다른 변수는 정상인데 **물가만 뒤집혀 있다**

**왜 중요한가**: 이 vault에서 **두 번째로 같은 이상이 확인됐다.**
[[2024 부문별 인플레이션을 이용한 테일러 준칙 추정 (주현도)]]는 테일러 준칙 회귀로 **초기(~2006) 물가계수가 음수**라고 보고한다.
방법론이 전혀 다른데(테일러 준칙 회귀 vs 다항로짓) 표본기간이 겹치고 **같은 방향**을 가리킨다.

독립적인 두 증거가 모였으므로 "한국 통화정책의 물가 반응이 2000년대에는 정상 작동하지 않았다"는
명제는 이 vault에서 **교차검증된 것으로 취급할 수 있다.**

⚠ 단 10% 유의수준이다. 주장의 강도를 낮춰 인용할 것.

**확신도: 중.** 계수 1.693이 10% 유의에 그치고 노트 본인이 강도를 낮추라고 명시한다. 다만 주현도(2024)가 다른 방법론으로 같은 방향을 보고해 교차검증은 성립한다
