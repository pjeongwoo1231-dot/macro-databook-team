# 대리변수와 그 동인을 함께 넣으면 동인이 죽는다

## 1분 요약

몽골은 수출의 대부분을 중국에 보낸다. 논문 스스로 "중국 경기 변동에 크게 영향받는다"고 쓴다. 그런데 회귀에 중국 GDP를 넣으면 **t=0.245, p=0.8095로 사실상 0**이 나온다. 영향이 없어서가 아니다. **중국 수요가 이미 구리가격 안에 들어가 있어서** 따로 넣을 때 남는 몫이 없는 것이다.

## 인과 사슬

```
중국은 세계 최대 구리 소비국
        ↓
중국 수요 변동 → **구리가격에 이미 반영됨**
        ↓
회귀에 [구리가격]과 [중국 GDP]를 **함께** 투입
        ↓
두 변수가 강하게 공선(collinear)
        ↓
중국 GDP의 고유 설명력 ≈ 0  →  p=0.81
        ↓
   ⚠ 이를 "중국은 몽골 성장에 영향이 없다"로 읽으면 **정반대 결론**
```

**논문의 처리**: 저자는 이를 "특정 국가의 경제 상황만으로 설명하기 어렵다"고 넘긴다. 그러나 **VIF나 상관행렬 등 공선성 진단을 전혀 제시하지 않아** 독자가 판별할 수 없다.

**왜 중요한가**: 비유의 계수를 "영향 없음"으로 읽는 것은 흔한 오독이다. 세 가지가 구분되지 않는다.

| 관측 | 가능한 원인 |
|---|---|
| p값이 크다 | ① 정말 영향이 없다 |
| | ② **다른 변수에 이미 흡수됐다** (공선성) |
| | ③ 표본이 작아 검정력이 없다 |

몽골 사례는 ②와 ③이 겹친 경우다(관측치 21개).

**이 vault에 직접 적용되는 지점**: [[구리 가격]] 노트의 경고 — *"구리 가격에는 중국 수요가 섞인다"* — 를 이 결과가 **뒤집는 게 아니라 강화한다.** 중국 수요가 가격에 이미 들어가 있어서 따로 넣으면 아무것도 안 남는다는 뜻이다.

**확신도: 중상.** 계수·p값은 원문 확인됐다. "공선성 때문"이라는 진단은 **VIF가 제시되지 않아 직접 확인할 수 없는** 추론이지만, 중국-구리의 이론적 연동과 논문 자체의 서술을 감안하면 가장 자연스러운 해석이다.

## 어떻게 피하는가

1. **대리변수와 그 동인을 같은 회귀에 넣지 않는다.** 넣어야 한다면 무엇을 식별하려는지 먼저 정한다.
2. 넣었다면 **VIF·상관행렬을 반드시 보고**한다.
3. 비유의 계수를 해석할 때 **셋 중 어느 경우인지 밝힌다** — 영향 없음 / 흡수됨 / 검정력 부족.
4. 동인의 효과를 보고 싶으면 **대리변수를 빼고 다시 추정**해 계수 변화를 함께 싣는다.
