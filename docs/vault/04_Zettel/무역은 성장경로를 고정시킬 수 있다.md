# 무역은 성장경로를 고정시킬 수 있다

## 1분 요약

"무역은 언제나 성장에 좋다"는 명제는 루카스 모형 안에서 **조건부**다.

재화마다 **배우는 속도**가 다르다면 — 반도체를 만들며 쌓이는 숙련과 원면을 재배하며 쌓이는 숙련의 축적률이 다르다면 — 비교우위에 따른 특화는 **느리게 배우는 재화에 나라를 가둘 수 있다.**

악기 연습에 비유하면, 처음에 리코더가 조금 더 쉬웠다는 이유로 리코더만 30년 연습한 사람과 피아노를 택한 사람의 격차 같은 것이다. 매 순간의 선택은 합리적이었다. 그런데 **경로가 갈렸다.**

## 인과 사슬

```
재화별 학습률이 다름:  δ₁ > δ₂  (재화 1 = 고기술재, 재화 2 = 저기술재)
학습은 **생산하며** 일어남:  ḣᵢ = hᵢ · δᵢ · uᵢ
        ↓
초기에 재화 2에 비교우위 → 노동을 u₂ 에 배분
        ↓
h₂ 만 자라고 h₁ 은 정체
        ↓
상대가격 q = h₁/h₂ 가 특화를 **더 강화**
        ↓
**저학습 경로에 고착 — 매 시점 최적인 선택의 누적 결과**
```

핵심은 **학습이 생산에 붙어 있다**는 점이다. 원문 §4의 학교교육 모형에서는 생산에서 **빠져나와야**(1−u) 인적자본이 쌓이는데, §5에서는 반대로 **생산할수록**(uᵢ) 쌓인다. 이 차이가 무역의 성격을 바꾼다 — 무엇을 만드느냐가 무엇을 배우느냐를 결정한다.

**저자가 이 절에서 밝힌 모형화 의도** (중요한 단서):
> "(30)에 담긴 수확체감 문제를 그대로 넣으면 인적자본은 성장 엔진의 지위를 잃는다. 내가 (30)이 '대변하기를' 바라는 것은, **새로운 재화가 계속 도입되고, 각각에 대해서는 학습에 수확체감이 있으며, 옛 재화에 특화된 인적자본이 새 재화에 어떤 식으로든 '상속'되는** 환경이다."

→ 즉 δᵢ는 개별 품목의 학습률이 아니라 **"재화 가족(families of goods)"의 학습 잠재력**을 나타내는 축약이다.

## 왜 중요한가

**"무역 개방 = 성장"이라는 등식에 조건을 붙인다.** 정태적 효율(비교우위에 따른 자원배분)과 동태적 효과(무엇을 배우게 되는가)가 **다른 방향일 수 있다.**

실무 함의 둘:

1. **관세·무역제한의 비용 평가를 분리한다.** 후생비용(정태적, 계산 가능, 대개 작음 → [[비효율 제거는 성장률이 아니라 수준을 옮긴다]])과 학습경로 효과(동태적, 계산 어려움, 잠재적으로 큼)는 다른 항목이다. 둘을 합산하지 말고 따로 적는다.
2. **산업정책 논쟁의 이론적 출발점 중 하나**다. 다만 이 모형은 정책 처방을 주지 않는다 — 어떤 재화가 δ가 높은지를 사전에 알 방법이 모형에 없다.

[[글로벌 공급망]] 재편·[[무역분쟁·관세]] 국면에서 "어느 공정을 국내에 두는가"를 논할 때, 부가가치가 아니라 **학습률**을 축으로 보는 관점을 제공한다.

**확신도: 중.** 원문 §5를 직접 읽었으나 이 절 자체의 뒷받침이 §4보다 약하다.

- **캘리브레이션이 없다.** §4는 미국 데이터로 파라미터를 역산하지만, §5는 **정성적 동학(식 34)만 제시**한다. 숫자가 하나도 없다.
- 학습률 δ₁ > δ₂ 를 **가정으로 넣는다.** 어떤 재화가 고학습인지 판별하는 기준이 모형 안에 없다.
- 정식화 자체가 Krugman(1985)에서 가져온 것이라고 각주에 밝힌다.
- 저자 본인이 §4의 모형을 "중심(central)"이라 부르고 §5는 "또 하나의 다른 예시(another, quite different, example)"로 위치를 낮춘다.

→ **이 제텔은 "무역이 해롭다"의 근거로 쓸 수 없다.** "무역의 성장 효과가 자동이 아니다"까지가 원문이 지지하는 범위다.

- **같이 볼 것**: [[비효율 제거는 성장률이 아니라 수준을 옮긴다]] — 무역장벽의 **정태적** 비용은 작다는 같은 논문의 결론. 이 제텔은 **동태적** 채널을 연다. 두 개를 함께 읽어야 무역정책 평가가 완성된다.
- **반대편**: [[성장의 규모변수는 인구가 아니라 숙련인력이다]] — Romer(1990)는 시장통합이 **무조건** 성장률을 올린다고 본다. 두 논문이 무역에 대해 반대 방향이다.
- **리서치 관점**: 공급망 재편·리쇼어링 논의에서 "무엇을 만드느냐가 무엇을 배우느냐를 정한다"는 프레임.
