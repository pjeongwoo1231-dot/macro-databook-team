# 같은 연구가 두 번 출판됐다 — 표본 숫자가 6개 셀 전부 다르다

## 1분 요약

같은 저자가 같은 데이터로 같은 기법을 쓴 논문이 두 편 있다. 서론과 모형식은 문장 단위로 같다.
그런데 **표본 크기가 6개 칸 전부 다르다.** 표본을 설명하는 문장은 똑같은데 숫자만 줄었고,
왜 줄었는지는 어느 논문에도 적혀 있지 않다.

## 인과 사슬

동일한 표본 기술: "2002~2004년 부도 발생 기업의 도산 직전년도 재무제표,
자산 10~100억원 외감 제조업체"

| | 선행 버전 | 2006 확장판 | 차이 |
|---|---|---|---|
| 2002 부도 / 건전 | 17 / 337 | 16 / 334 | −1 / −3 |
| 2003 부도 / 건전 | 25 / 411 | 22 / 407 | −3 / −4 |
| 2004 부도 / 건전 | **23** / 239 | **16** / 235 | **−7** / −4 |

→ 2004년 부도기업이 **30% 감소**. 데이터 정제로 보이지만 언급이 없다

**왜 중요한가**: 두 논문을 독립적인 두 증거로 세면 안 된다. 검증된 사례가 두 건인 것처럼
보이지만 실은 한 연구의 두 버전이다. 이 vault가 문헌을 축적할 때 **중복 계상**을 피해야 하는 이유다.

더 실질적인 문제: 부도 표본이 16~25개인데 그중 7개가 사라졌다면
"부도 분류정확도 100%"라는 결과가 표본 정제에 얼마나 민감한지 알 수 없다.
어느 기업을 왜 뺐는지가 곧 결과를 좌우한다. **표본 선택이 결과의 일부**인데 그 과정이 비공개다.

선후 판별 근거: 선행 버전의 최신 인용은 2003년이고 Paradi et al.(2004)를 1회만 언급한다.
확장판은 2004년 인용에 Paradi를 10회 쓴다 — 층화·절사점 논의의 축이 Paradi다.

**확신도: 상.** 같은 표본 기술 문장에 6개 셀의 숫자가 모두 다르다는 문서 사실이다. 중복 계상 방지라는 실무 함의도 직접 따라 나온다
