# 같은 논문이 표에 따라 자본 탄력성을 0.31로도 0.48로도 보고한다

## 1분 요약

MRW에서 "자본의 산출탄력성 α는 0.31"이라는 인용을 자주 본다. 그런데 **같은 논문 안에
0.48이라는 값도 있다.** 오타가 아니라 **다른 회귀에서 나온 다른 추정치**다.
소득 **수준**을 회귀하면 0.31이고, 소득 **증가분**(수렴 회귀)을 회귀하면 0.48이다.
어느 쪽을 인용하느냐로 "자본소득분배율 1/3과 부합한다"는 결론이 성립하기도 하고 깨지기도 한다.

## 인과 사슬

```
Table II — 수준회귀: 1985년 소득을 s_k, s_h, (n+g+δ)에 회귀
   전제: 1985년에 각국이 이미 정상상태에 있다 (또는 이탈이 무작위)
        → implied α = 0.31 (0.04) · β = 0.28 (0.03)   ← "1/3과 부합" 서사
        ↕
Table VI — 수렴회귀(제약): 1960→85 소득 증가분을 ln(Y60)과 함께 회귀
   전제 완화: 정상상태 밖 이행동학을 명시적으로 허용
        → implied α = 0.48 (0.07) · β = 0.23 (0.05)   ← 1/3에서 이탈
```

**차이를 만드는 것은 데이터가 아니라 "정상상태에 있다고 볼 것인가"라는 가정이다.**
MRW 자신이 Table I·II의 회귀는 *"valid only if countries are in their steady states or if
deviations from steady state are random"* 이라고 명시했고, 식 (16) 계열은 그 제약을 푼 것이라고 썼다.

## 왜 중요한가

**하나의 논문에서 나온 하나의 숫자를 인용할 때도 "어느 설정에서"가 붙어야 한다.**
α=0.31은 정상상태 가정 위에서만 성립하는 값이고, 그 가정을 풀면 0.48로 올라가
이론값 1/3과의 거리가 다시 벌어진다.

> **판정 규칙**: "MRW가 α≈1/3을 확인했다"고만 쓴 문헌은 Table VI을 안 본 것으로 간주한다.
> α를 인용하려면 **수준회귀인지 수렴회귀인지**를 함께 밝힌다.

[[MRW의 수렴속도 2퍼센트는 추정치가 아니라 이론 예측치다]]와 같은 뿌리다 —
**MRW는 값이 하나가 아닌 논문인데 2차 문헌이 하나로 압축해 유통시킨다.**
