# 저자는 "정책금리가 전 만기에 영향"이라 썼지만 표에는 1년물만 유의하다

## 1분 요약

논문 본문과 결과표가 어긋나는 사례다. 저자는 연방기금금리가 모든 만기의 국채금리를
예측한다고 서술했는데, 정작 같은 페이지의 표를 보면 **1년물 하나만 통계적으로 유의**하다.
나머지 세 만기는 10% 기준으로도 전부 기각되지 않는다. 초록만 읽고 인용하면 틀린 문장을 옮기게 된다.

## 인과 사슬

[[기준금리]](FFER) → 1년물 : F=5.4596, **p=0.0197** (유의)
[[기준금리]] → 3년물  : F=0.8960, p=0.3700 (비유의)
[[기준금리]] → 5년물  : F=0.0320, **p=0.9750** (비유의)
[[기준금리]] → 10년물 : F=0.7680, p=0.4420 (비유의)

→ 정책금리의 그랜저 인과는 **커브의 짧은 끝에서 멈춘다**

**왜 중요한가**: "연준이 장기금리를 통제한다"는 전제를 이 표는 지지하지 않는다.
정책금리는 단기를 잡고, 장기는 앞 제텔대로 물가 요인이 민다. 다만 충격반응함수에서는
FFER 충격이 레벨·기울기·곡률 전반에 유의한 반응을 냈다고 보고돼 있어 **그랜저 검정과 IRF의 결론이
서로 다르다** — 어느 쪽을 인용하느냐로 결론이 뒤집히므로 반드시 검정 종류를 명시할 것.

**확신도: 상.** 네 만기의 F·p값이 표에 있고 1년물만 유의하다는 것은 직접 확인된다. 단 같은 논문의 IRF는 다른 결론을 내므로 검정 종류를 반드시 명시할 것
