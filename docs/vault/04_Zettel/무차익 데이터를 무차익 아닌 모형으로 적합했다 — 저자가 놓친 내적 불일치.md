# 무차익 데이터를 무차익 아닌 모형으로 적합했다 — 저자가 놓친 내적 불일치

## 1분 요약

논문은 스스로의 한계로 "무차익 조건 미반영"을 든다. 그런데 입력 데이터로 쓴
ACM Fitted Yield는 **이미 무차익 조건을 부과해 추정된 곡선**이다.
무차익 가정으로 만든 데이터를 무차익 가정 없는 모형으로 다시 적합한 셈이다.

## 인과 사슬

ACM Fitted Yield (Adrian·Crump·Moench, NY Fed)
  = 국채 가격에 **무차익 조건**을 부과해 추정한 무이표 수익률 + 기간프리미엄 분해
↓ 입력
DNS 모형 = 무차익 조건을 **부과하지 않는** 축약형 3요인 모형
↓
저자의 한계 서술: "무차익 조건을 반영한 이론 정합적 모형의 도입"을 향후 과제로 제시

→ 데이터에는 이미 들어 있고 모형에는 없다. 그 간극이 어디로 갔는지 논문은 다루지 않는다

**왜 중요한가**: 두 가지 실무적 함의가 있다.
① 추정된 DNS 요인은 순수한 시장 관측치가 아니라 **ACM 모형의 산출물을 재분해한 것**이다.
따라서 요인의 해석에 ACM의 가정(기간프리미엄 모형 설정)이 섞여 들어간다.
② 그래도 실용적으로는 정당화된다 — 관측 국채는 만기가 불규칙하고 이표가 붙어 있어
매끄러운 무이표 곡선을 얻으려면 어떤 형태로든 적합이 필요하다.

**인용 시 "미 국채 금리"가 아니라 "ACM 적합 무이표 수익률"이라고 써야 정확하다.**
이 구분은 이 vault가 [[장단기 금리차]]를 인용할 때도 그대로 적용된다 —
par yield 커브와 zero curve의 기울기는 같지 않다.

**확신도: 상.** ACM Fitted Yield가 무차익 조건을 부과해 추정된 곡선이라는 것은 데이터 정의상의 사실이다. 내적 불일치는 그로부터 직접 따라 나온다
