# 시장이 인식하는 반응함수는 정책이 실제로 바뀐 뒤에야 갱신된다

## 1분 요약

일본 시장참가자 서베이로 **"시장이 믿고 있는 정책 반응함수"** 를 추정했다.
중앙은행이 실제로 따르는 규칙이 아니라, **참가자들이 그렇게 될 것이라 생각하는 규칙**이다.

세 가지 결과 —

1. **실효하한(ELB)에 묶여 있을 때 인플레이션 계수는 거의 0이다.**
   다른 나라 선행연구와 같다. 하한에서 "물가가 올라도 금리는 안 오른다"고 믿는 것이 합리적이었다
2. **금리 인상기에 접어들면 계수가 올라간다** — 즉 참가자는 **실제 정책 변화에 반응해
   인식을 갱신한다.** 말이 아니라 행동을 보고 바꾼다
3. **장기 기대인플레가 목표 아래로 이탈한 그룹에서는, 최근 인상기에도 계수가 낮게 남았다.**
   이 하위집단은 **저금리가 오래 갈 것**으로 본다

그리고 결정적 대응관계 —

> **정책이 인플레에 강하게 반응한다고 가정하는 참가자일수록, 장기 기대인플레가 2% 근처에서 안정적이다.**

## 인과 사슬

```
실효하한 → 인식된 반응함수의 물가 계수 ≈ 0 → "물가가 올라도 금리는 안 움직인다"
   → 기대 앵커링 약화 → 장기 기대가 목표 아래로 표류
실제 인상 단행 → 인식 갱신 → 계수 ↑ → 앵커링 회복
⚠ 단 목표 아래로 이탈한 그룹은 **인상을 봐도 갱신이 느리다** → 앵커링 이질성이 남는다
```

## 왜 이게 중요한가 — 판정 규칙

**"중앙은행이 무엇을 말했나"와 "시장이 무엇을 믿나"는 다른 변수이고, 후자가 자산가격을 움직인다.**

| 관측 | 잘못된 추론 | 이 논문의 판정 |
|---|---|---|
| 총재 발언이 매파적 | 시장 기대가 즉시 이동 | **실제 인상 전까지 인식은 잘 안 바뀐다** |
| 인상 후에도 장기금리가 안 오름 | 시장이 정책을 불신 | **하위집단의 인식 갱신이 느린 것**일 수 있다 |
| 기대인플레가 목표에 못 미침 | 물가 자체의 문제 | **인식된 반응함수가 약한 것**이 원인일 수 있다 |

→ **상태의존적이다.** 같은 발언·같은 지표가 하한 국면과 인상 국면에서 **다른 크기로** 전달된다.
"통화정책의 효과"를 하나의 계수로 말할 수 없다.

## 볼트에 붙는 자리

[[한은 반응함수는 상수가 아니다 — 시기별로 물가와 성장의 비중이 반전된다]]와 **짝**이다.
그 노트는 **실제** 반응함수가 시기별로 변한다고 했고,
이 논문은 **인식된** 반응함수도 시기별로 변한다고 한다.

**둘을 겹치면 볼트에 새 구분이 생긴다** —

| | 실제 반응함수 | 인식된 반응함수 |
|---|---|---|
| 무엇을 재나 | 중앙은행 행동 | 시장 믿음 |
| 우리 자료 | 금통위 결정 + 거시변수 | **서베이(전문가 전망) 필요** |
| 자산가격에 직접 작용 | 간접 | **직접** |

→ 한국판 재현에는 **한은 서베이·전문가 전망 미시자료**가 필요하다. 현재 파이프라인에 없다(미해결).

[[일본 국채 (JGB)]]에도 직접 걸린다 — 목표 아래 이탈 그룹의 낮은 계수는
**JGB 장기 금리가 인상에도 잘 안 오르는 이유**의 한 후보다.

## 한계

- **BOJ 워킹페이퍼**다. 심사 논문이 아니며 은행 공식 견해가 아니라고 명시돼 있다.
- **일본 시장참가자 서베이**다. 한국·미국으로의 이식은 검증되지 않았다.
- **인식은 서베이로 잰다** — 응답자 구성 변화가 계수 변화로 나타날 수 있다
  (같은 사람이 생각을 바꾼 것인지, 다른 사람이 답한 것인지).
- **계수의 구체적 값을 이 노트에 옮기지 않았다.** 본문 표를 대조하지 않았으므로 방향만 인용한다.
- 상관관계다 — "강한 반응을 가정하는 참가자일수록 기대가 안정적"이 **인과라는 증거는 없다.**
