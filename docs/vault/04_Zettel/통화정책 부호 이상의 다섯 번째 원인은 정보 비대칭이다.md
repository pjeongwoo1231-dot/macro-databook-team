# 통화정책 부호 이상의 다섯 번째 원인은 정보 비대칭이다

## 1분 요약

"긴축했는데 물가가 올랐다"(물가퍼즐)는 50년 된 거시 실증의 골칫거리다. 원인은 경제가
이상해서가 아니다. **중앙은행이 인플레를 예견하고 올린 것인데, 그 예견을 통제하지 않으면
인상이 물가를 올린 것처럼 보인다.** 정보 비대칭을 걷어내면 **퍼즐이 사라진다.**

## 인과 사슬

```
중앙은행과 민간의 정보집합이 **서로 포함관계가 아니다** (non-nested)
        ↓
정책 발표가 두 개를 동시에 전달
   ① 진짜 정책 충격
   ② 중앙은행의 **경제 전망에 관한 사적 정보** ← 정보효과
        ↓
②를 안 걷으면: "긴축 → 물가 ↑" 로 관측
        ↓
**물가퍼즐**
        ↓
[해결] 서프라이즈를 (i) 자기 시차 (ii) **Greenbook 예측·수정치**에 회귀 → 잔차만 사용
        ↓
**긴축은 명백히 수축적. 물가퍼즐·산출퍼즐 모두 소멸**
```

**왜 중요한가 — [[매크로 해석 프레임]] 3단계의 빈 칸이 채워진다**

3단계 "부호가 이상할 때" 진단표는 네 원인을 둔다:
누락변수 · **역인과·동시성** · 표본 특수성 · 자유도 부족.
그런데 **역인과·동시성 칸은 "이 볼트에서 확인된 사례 없음"으로 비어 있었다.**

**이 논문이 그 사례다.** 그리고 동시성의 **구체적 형태**를 특정한다 — 단순한 역인과가 아니라
**정책당국이 가진 예측 정보**다. 진단 방법도 다르다:

| 원인 | 진단 |
|---|---|
| 누락변수 | 변수를 추가하면 부호 정상화 |
| **정보 비대칭** ← 신규 | **정책당국의 전망(예측·수정치)을 통제하면 부호 정상화** |
| 표본 특수성 | 표본을 늘리면 정상화 |
| 자유도 부족 | 무엇을 해도 안 죽는데 무조건부 관계가 없다 |

**한국 사례에 직접 걸린다.** 볼트는 [[한은은 물가가 오르면 금리를 내렸다 — 이론과 반대 부호]]를
[[한은의 물가 부호 이상은 표본 특수성이었다 — 표본을 늘리면 정상화된다]]로 진단했다.
MAR은 **경쟁 가설**을 제시한다 — 한은도 전망에 반응하므로,
**한은 경제전망보고서를 통제하지 않은 반응함수 추정은 부호가 뒤집힐 수 있다.**

→ 표본 특수성 진단이 **기각된 것은 아니다.** 다만 **경쟁 가설이 하나 늘었고, 아직 안 갈랐다.**
자체 재추정 v4에서 **한은 전망치를 통제변수로 넣은 사양**을 돌려야 판별된다.

**확신도: 중상.** 진단이 테스트 가능한 형태로 제시되고 실증됐다.
**유보**: ① 2017 원고 대조본(AEJ 최종본 미확인) ② Greenbook이 중앙은행 정보집합을
완전히 대리한다는 가정은 검증 불가 ③ 한국 적용은 **아직 확인되지 않은 추론**이다.
