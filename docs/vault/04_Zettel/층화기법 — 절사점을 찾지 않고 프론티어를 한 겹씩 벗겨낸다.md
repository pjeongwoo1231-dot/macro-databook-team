# 층화기법 — 절사점을 찾지 않고 프론티어를 한 겹씩 벗겨낸다

## 1분 요약

최적 절사점을 못 찾는다면 아예 쓰지 않는 방법이 있다. 프론티어에 올라온 기업을
제거하고 다시 DEA를 돌리면 새로운 프론티어가 드러난다. 이걸 반복해 **양파 껍질처럼 층을 쌓는다.**
은행은 자기 위험회피 수준에 맞춰 "몇 층까지 볼지"만 정하면 된다.

## 인과 사슬

1층 = 부실관행 DEA 효율적 프론티어(가장 위험) → 제거
2층 = 남은 표본으로 재실행한 프론티어 → 제거
…반복

2002년 부실관행 모형2 층별 구성 (부도/건전)
1층 4/2 · 2층 4/14 · 3층 1/18 · 4층 2/28 · 5층 2/25 · 6층 1/40 · 7층 2/36

→ **부도기업이 앞단 층에 밀집**한다. 층 번호가 곧 위험 순위다
→ 절사점이라는 단일 경계선 대신 **연속적인 서열**을 얻는다

**왜 중요한가**: 절사점은 "예/아니오"를 강제하지만 층화는 **등급**을 만든다.
신용등급 체계와 자연스럽게 대응하고, 은행의 위험선호가 바뀌면 모형을 다시 추정하지 않고
층수만 조정하면 된다. 이것이 이 논문이 말하는 실무적 유용성의 핵심이다.

주의: 층을 벗길 때마다 표본이 줄어 뒤쪽 층의 프론티어는 점점 적은 관측치로 추정된다.
2002년 부도 16개가 7개 층에 흩어지므로 **뒤쪽 층의 추정은 매우 불안정**하다.

**확신도: 중상.** 층별 구성표는 직접 확인되는 사실이고 등급 산출이라는 실무 함의도 명확하다. 단 노트 본인이 뒤쪽 층의 추정 불안정(부도 16개가 7개 층에 분산)을 지적한다
