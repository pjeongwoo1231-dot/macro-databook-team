# 부산물 금속은 자기 수요가 아니라 모금속 생산이 공급을 정한다

## 1분 요약

인듐·갈륨·게르마늄·텔루륨·셀레늄·카드뮴에는 **자기 광산이 없다.**
아연·구리·은·주석 광산의 **부산물**로만 나온다.

그래서 보통의 공급곡선 논리가 깨진다 —

> **인듐 가격이 올라도 인듐 생산은 늘지 않는다.**
> 늘어나려면 **아연을 더 캐야** 하고, 아연을 더 캐는 결정은 아연 가격이 정한다.

이것이 **부산물 금속(secondary dependent metal)** 의 공급 비탄력성이다.
저자들의 지적 — 기존 연구들이 인듐을 다루면서도 **이 성질의 함의를 제대로 반영하지 않았다.**

## 인과 사슬

```
아연·구리 가격 ↑ → 모금속 채굴 ↑ → **인듐 부산물 공급 ↑** (인듐 가격과 무관)
인듐 수요 ↑ (CIGS 태양광) → 인듐 가격 ↑ → **공급은 거의 반응하지 않음**
   → 가격이 배급 기능만 수행 → 하류 기술(태양광) 확산 속도가 제약됨
재활용률 ↑ → **유일하게 인듐 자체에 반응하는 공급원** → 병목 완화
```

**부산물 금속에서 재활용은 환경 의제가 아니라 유일한 탄력적 공급원이다.**

## 이 논문이 제시한 수치

| 항목 | 값 |
|---|---|
| 모금속에 존재하는 인듐 | 약 **550,000 t** |
| BAU에서 실제 추출 가능 | 약 **310,000~312,000 t** |
| 현재 인듐 재활용률 | **15~25%** (대부분 추정) |
| 재활용 개선 목표 | 50~60% |
| 2022년 수요 구성 | 평판 디스플레이·터치스크린 **65%** |
| CIGS 태양광 효율 | 22~25% (2023년 시장 점유 12%) |
| 세계 태양전지 인듐 수요 충족률 | **25%** |
| 모형상 인듐 생산 정점 | **2025~2030** |

## 왜 이게 중요한가 — 판정 규칙

**전환금속을 논할 때 "자기 광산이 있는가"를 먼저 묻는다.**

| 유형 | 공급 반응 | 판정 |
|---|---|---|
| **주광종**(구리·니켈·리튬) | 가격에 반응(리드타임 있음) | 통상 공급곡선 논리 적용 |
| **부산물**(In·Ga·Ge·Te·Se·Cd, 일부 Co) | **자기 가격에 거의 무반응** | 모금속 생산과 **재활용**만 본다 |

→ [[전환금속 수요 배수를 정하는 것은 전기차 대수가 아니라 배터리 화학이다]]와 겹쳐 읽으면,
**수요 시나리오(화학 조성) × 공급 유형(주광종/부산물)** 의 2×2가 실제 병목 지도다.

→ [[제련수수료 (TC-RC)]] 논의에도 걸린다. 부산물 회수는 **제련 단계**에서 결정되므로,
정광이 어느 제련소로 가느냐가 부산물 공급을 좌우한다. **채굴량만 봐서는 안 된다.**

## ⚠ 모형 자체에 대한 유보 — 크게 잡을 것

`flag/needs-review` 를 달았다. **WORLD7은 『성장의 한계』(Meadows 1972) 계보의
시스템 다이내믹스 모형**이고, 저자들도 그 계보를 명시적으로 인용한다.

- **2200년까지의 투영**은 검증 가능한 시계가 아니다. **"2090년 태양광 정점, 설치용량 1200 GW"
  같은 수치를 시황에 인용하지 말 것.**
- 저자들이 보고한 검증은 **과거 재현**(추출량·가격 패턴)이다.
  과거를 재현한 모형이 미래를 맞힌다는 보장은 없다 —
  볼트의 「모형이 사실을 재현했다」 판정 규칙을 그대로 적용한다:
  **① 타깃 모멘트인가 ② 파라미터가 독립 측정됐는가.**
- 저자들 스스로 인듐 함량 정보가 **"매우 근사적"** 이고 세계 수준 자료가 거의 없다고 적었다.
  **추정의 입력 자체가 약하다.**
- 이 논문군(EU "Imaginaries" 프레임)은 **정책 규범적 목적**을 명시한다.

**살아남는 것은 수치가 아니라 메커니즘이다** — 부산물 금속의 공급 비탄력성.
