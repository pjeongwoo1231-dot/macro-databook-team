# 미국 양적완화가 유럽 은행의 자본비율을 통해 대출을 줄인다

## 1분 요약

미국 대규모 자산매입(LSAP)의 국제 파급을 **은행 대차대조표를 따라가며** 추적했다.
유로존 **은행 단위 감독 자료** + **고빈도 식별 정책 서프라이즈**를 결합했다.

저자들이 **"비전통 통화정책의 국제 은행자본 채널(international bank capital channel)"** 이라
이름 붙인 경로 —

> **미 국채 수익률곡선을 가파르게(steepening) 만드는 LSAP 충격에 대해,
> 유로존 은행의 국채 포지션이 줄고, 자본비율이 악화되며,
> 자본이 덜 충실한 은행이 더 충실한 은행보다 대출을 더 많이 줄인다.**

**즉 미국 정책이 유럽 실물 신용에 도달하는 경로가 금리가 아니라 자본이다.**

## 인과 사슬

```
미 LSAP 충격 → **미 국채 커브 스티프닝** → 장기 국채 가격 ↓
   → 유로존 은행이 보유한 **미 국채 포지션 평가손** → 포지션 축소
   → **자본비율 악화**
   → **자본이 얇은 은행**이 대출을 상대적으로 더 줄인다 (횡단면 차이)
   → 유로존 기업·가계 신용 ↓
⚠ 금리 경로와 별개다 — **자본이 매개**한다
```

## 왜 이게 중요한가 — 한국에 그대로 적용 가능하다

**한국 금융기관도 미 국채를 대규모로 보유한다**(은행·보험·연기금).
따라서 같은 채널이 작동할 조건을 갖추고 있다.

| 물어야 할 것 | 왜 |
|---|---|
| 한국 금융기관의 **미 국채·해외채권 보유 규모와 듀레이션** | 평가손의 크기를 정한다 |
| **자본비율이 얇은 기관**이 어디인가 | 대출 축소가 거기서 먼저 나온다 |
| 회계 처리 — **만기보유 vs 매도가능** | 평가손이 자본에 반영되는지가 채널의 존재 여부를 가른다 |

⚠ **마지막 항목이 결정적이다.** 만기보유증권으로 분류하면 평가손이 자본에 안 잡히고,
그러면 이 채널이 **회계적으로 차단**된다. **논문이 이 구분을 어떻게 다뤘는지 확인하지 않았다.**

→ [[포트폴리오 중복이 전염 경로다 — 채권펀드와 지역은행이 같은 것을 들고 있다]]와
**같은 자산, 다른 경로**다. 그쪽은 **매도 압력(파이어세일)**, 이쪽은 **자본비율 제약**이다.

## 볼트에 붙는 자리

[[한국은 통화정책 자율성을 잃고 해외 채널만 남았다]]에 **채널을 하나 더** 더한다.
지금까지 정리된 채널 —

| 채널 | 근거 노트 |
|---|---|
| 금리·환율 | 기존 |
| **r\* 자체가 밀림** | [[한국의 중립금리는 하나가 아니다 — 경기순환용과 금융순환용이 갈린다]] |
| **뉴스 → 위험 인식** | [[미국 뉴스가 신흥국에 오는 경로는 통화정책만이 아니다 — 고용지표가 가장 세다]] |
| **국제 은행자본** | **이 노트** |

**정책 채널을 막아도 남는 경로가 계속 늘어난다.**

## 한계

- **Fed FEDS 워킹페이퍼**다. 연준 공식 견해가 아니다.
- **유로존 은행 자료**다. 한국 적용은 **이 노트의 추론**이며 검증되지 않았다.
- **계수·크기를 옮기지 않았다.** 방향과 채널만 인용한다.
- **회계 분류(만기보유/매도가능)의 처리를 확인하지 않았다** — 위 ⚠ 참조.
  이 채널의 크기는 회계 규정에 크게 의존한다.
- 고빈도 식별은 **정책 서프라이즈 창(window)** 안의 다른 뉴스에 오염될 수 있다.
- **스티프닝을 일으키는 LSAP 충격**이라는 특정 조건이 붙는다.
  모든 LSAP이 커브를 세우는 것은 아니다.
