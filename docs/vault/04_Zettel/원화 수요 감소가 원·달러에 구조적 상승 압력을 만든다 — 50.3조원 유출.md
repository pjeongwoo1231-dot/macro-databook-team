# 원화 수요 감소가 원/달러에 구조적 상승 압력을 만든다 — 50.3조원 유출

## 1분 요약

국내 자금이 스테이블코인으로 옮겨가면 원화를 덜 쓰게 된다. 원화 수요가 줄면
환율에는 **일시적 충격이 아니라 구조적 상승 압력**이 걸린다. 달러가 약해지는 국면에서도
원화가 다른 통화만큼 강해지지 못하는 현상이 이미 관측된다는 것이 이 보고서의 주장이다.

## 인과 사슬

24.12~25.4월 국내 거래소 → 국외 유출 추정 **약 50.3조원**

[[스테이블코인]] 확산 → 원화 수요 ↓ → [[원·달러 환율]] 구조적 상승 압력
→ 내국인 해외투자 감소 같은 **하락 요인이 있어도 원/달러 하락은 제한적**

관측: 24.12월 이후 금융계정 감소 · 달러화 하락
     그런데 **원화는 타국 통화에 비해 제한적으로만 하락**

병행 경로: 여유자금 → 코인 → 은행 예금 기반 축소
        → 대출 여력 ↓ → **신용중개 기능 약화** → [[신용사이클]]

**왜 중요한가**: 환율 전망에 새 변수가 추가된다. 무역수지·금리차·해외투자로 설명되던
원/달러에 **코인을 통한 상시 원화 매도 흐름**이 붙는다. 이건 계절성도 없고 되돌림도 약하다.

⚠ 50.3조원 추정은 검증이 필요하다. 추정 주체와 방법이 요약본에 없고,
**[[김치프리미엄]] 차익거래분과 순수 자본유출을 구분했는지 불명**이다.
김치프리미엄이 존재하는 구간에서는 유출·유입이 동시에 일어나므로 총액만으로는
순유출을 알 수 없다. [[김치프리미엄]] 노드의 이자율평가 논문과 교차검증할 대상.

**확신도: 하.** media 요약본 기반이고 50.3조원의 추정 주체·방법이 불명이다. 김치프리미엄 차익거래분과 순유출이 구분됐는지도 확인되지 않는다

## 핵심 지표 · 연결고리

- **관련 노드**: [[원·달러 환율]] · [[스테이블코인]] · [[김치프리미엄]] · [[신용사이클]] · [[글로벌 유동성]]
- **리서치 관점**: 환율 결정요인 목록의 갱신 — 자본계정에 잡히지 않는 상시 원화 매도 채널.
