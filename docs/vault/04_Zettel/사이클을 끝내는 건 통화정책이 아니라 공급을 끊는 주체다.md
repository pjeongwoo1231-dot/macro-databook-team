# 사이클을 끝내는 건 통화정책이 아니라 공급을 끊는 주체다

> ⚠ **사용자 가설**(`reliability: opinion`). 반증 조건은 원 노트 §6 참조.

## 1분 요약

1970년대 인플레를 끝낸 것은 통화정책이 아니라 **중동 산유국의 금수 조치**였다.
돈을 찍어 전쟁을 벌이던 미국에 산유국이 공급으로 답한 것이다.
**같은 구조가 지금 반복되는데, 마지막 조각이 아직 비어 있다** — 미국에 공급으로 답할 주체다.

중동 산유국은 그 역할을 할 수 없다. 이란과 적대적이고 이스라엘과 이해가 겹친다.
**남는 것은 중국이다.** 광물·부품·완성품 밸류체인을 사실상 독점하고 기술에서 미국을 추격한다.
**중국은 과거의 소련이자 과거의 중동이다** — 기술 경쟁자이면서 공급 차단 능력을 동시에 쥐었다.

## 인과 사슬

```
화폐 확장 + 재정 확장  →  인플레 압력 누적 (필요조건)
        ↓   ← 이것만으로는 사이클이 끝나지 않는다
       공급을 끊는 주체의 등장 (충분조건)
        ↓
   1973: OPEC 금수  →  오일쇼크
   현재: 중국?  →  가설상 첫 포문은 **대만 봉쇄**
        ├─ 서방 반도체 밸류체인 중단
        └─ 봉쇄 반대국은 중국 제조업 공급망에서 퇴출
        ↓
[[글로벌 공급망]] 불안 → 공급발 인플레 → 정책 선택 강요
```

**타이밍 주의**: 통킹만(1964)에서 1차 오일쇼크(1973)까지 약 9년이 걸렸다.
**주체가 등장해도 폭발까지 시차가 있다.** 트리거 관측 = 즉시 반영이 아니다.

## 왜 중요한가

> **판정 규칙**: 레짐 전환 시점을 예측할 때 **연준 관찰만으로 선행 포착이 가능하다고 가정하지 않는다.**
> 방아쇠가 정책 변수 밖(지정학 주체)에 있으면, 반응함수 모형은 사후적으로만 맞는다.

이것이 [[제텔 소환 인덱스]] §1이 경고하는 실패 모드와 맞물리는 지점이다 —
**절차(금리·물가 관찰)만 돌리면 방아쇠를 쥔 주체를 아예 시야에서 놓친다.**
