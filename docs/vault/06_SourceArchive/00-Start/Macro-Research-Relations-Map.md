# 거시경제 연구 관계 지도

이 노트는 ‘경제 현상끼리 어떻게 연결되는가’가 아니라, **연구들이 서로의 해석을 어떻게 바꾸는가**를 기록한다. 한 연구는 거시 문제를 정의하고, 다른 연구는 그 문제를 충격·집단·제도로 분해하며, 또 다른 연구는 적용 범위나 정책 실행 가능성을 제한한다. 따라서 이 지도는 논문들의 **연구상 영향과 역할 관계**를 보여 준다.

> [!important] 직접 인용 그래프와 구분
> 이 지도는 참고문헌을 전수 대조한 **서지적 인용 그래프가 아니다.** ‘A → B’는 A가 B를 직접 인용했다는 뜻이 아니라, 이 라이브러리에서 B를 읽을 때 A가 **질문·측정·기제·해석 경계·정책조건**을 제공한다는 뜻이다. 실제 인용 여부는 각 공식 원문의 참고문헌에서 별도로 확인해야 한다.

## 관계 언어

| 관계 | 연구상 효과 | 독해할 때 바뀌는 것 |
|---|---|---|
| **문제정의 → 분해** | 플래그십·사건 진단이 넓은 현상을 제시하고, 후속 연구가 충격·집단·채널을 분해한다 | ‘무엇이 문제인가’에서 ‘어떤 경로가 작동했는가’로 이동한다. |
| **기제 → 식별** | 개념·구조모형이 측정할 변수와 이질성을 제시하고, 실증 연구가 그 기제의 적용 범위를 제한한다 | 기제를 설명으로만 쓰지 않고 표본·식별가정과 대조한다. |
| **평균 → 분포** | 성장·물가·부채의 집계 진단이 노동·소득·부의 분포 연구로 보완된다 | 평균 개선이 모든 집단의 개선을 뜻하지 않는지 확인한다. |
| **정책목표 → 실행조건** | 정책 수단의 거시 논의가 제도·신뢰·수용성 연구로 제약된다 | ‘효율적인가’에서 ‘시행 가능한가’로 질문이 확장된다. |
| **시나리오 → 적용 경계** | 조건부 모형·전망이 재정여력·금융취약성·국가 이질성으로 제한된다 | 수치를 예측이나 보편 처방으로 오용하지 않는다. |
| **사례 → 감시체계** | 과거 사건과 미시 사례가 현재의 금융·재정 위험지표를 읽는 기준을 제공한다 | 과거 사례를 반복 예측이 아니라 취약성 점검 목록으로 쓴다. |

| 디지털 공공화폐 | [[BIS-AER-2021-CBDC-Monetary-System]]은 설계·공공성·데이터 거버넌스를, [[IMF-External-Sector-Report-2024-Imbalances]]는 대외부문 조건을, [[World-Bank-WDR-2017-Governance-Law]]는 실행 역량·제도 조건을 제공한다 | CBDC 연구를 기술 기능의 비교에서 법·ID·데이터·외환규제·국가역량의 복합 질문으로 넓힌다 | 이는 특정 국가의 도입 권고·비용편익 판단이 아니며, 각국의 설계·법·금융구조를 별도 검토해야 한다.[14] [17] [28] |

## 한 연구가 다른 연구를 ‘제약’하는 실제 방식

### 1. 플래그십 보고서는 질문의 바깥 경계를 만든다

WEO·GEP·GFSR·Fiscal Monitor 같은 플래그십 보고서는 많은 국가와 부문을 포괄하는 **진단·전망·위험의 지도**를 제공한다. 그러나 그 넓은 범위 때문에 특정 충격의 인과적 크기, 특정 집단의 손실, 특정 제도의 집행효과를 단독으로 식별하지 않는 경우가 많다. 따라서 [[IMF-WEO-2020-Great-Lockdown]]과 [[NBER-W27141-Cost-of-Covid-Crisis]], 또는 [[IMF-WEO-2024-Policy-Pivot-Rising-Threats]]와 [[NBER-W32859-Drivers-of-Post-Pandemic-Inflation]]의 관계는 ‘큰 진단을 작은 식별 질문으로 바꾸는 관계’다.

### 2. Working Paper는 기제를 더 구체적으로 만들지만 일반성을 줄인다

[[BIS-WP-395-Financial-Cycle-Macroeconomics]], [[BIS_WP_870]], [[BIS_WP_874]], [[BIS_WP_875]], [[BIS_WP_876]], [[BIS_WP_890]] 같은 심층 연구는 변수·표본·모형·식별을 더 선명하게 한다. 그 대가로 국가·기간·시장·가정의 범위가 좁아진다. 그러므로 Working Paper가 플래그십 보고서를 ‘대체’하는 것이 아니라, 보고서가 제시한 위험·정책 문제를 **검증 가능하지만 더 조건적인 주장**으로 바꾸는 역할을 한다.

### 3. 제도·분배 연구는 평균 효과의 해석을 바꾼다

[[World-Bank-WDR-2017-Governance-Law]]와 [[IMF-WEO-2024-Structural-Reform-Acceptability]]는 공공투자·구조개혁의 경제적 타당성만으로는 충분하지 않다는 실행 조건을 추가한다. [[ILO-WESO-2024-Labour-Resilience-Fragility]]와 [[World-Inequality-Report-2022-Distribution-Accounts]]는 성장·고용의 평균이 개선돼도 누가 회복에서 배제되거나 어떤 자산·소득 경로가 악화되는지를 묻는다. 이 연구들은 평균효과를 반박하기보다, 평균효과가 **정책 평가의 충분통계량이 아님**을 보여 주는 보완물이다.

### 4. 재정·금융안정 연구는 정책 시나리오의 적용 범위를 좁힌다

[[IMF-Fiscal-Monitor-2023-Climate-Crossroads]]나 [[IMF-WEO-2025-Industrial-Policy-Tradeoffs]]의 조건부 정책 시나리오는 정책 목표와 비용의 관계를 보여 준다. [[IMF-Fiscal-Monitor-2024-Public-Debt]]와 [[IMF-GFSR-2024-Uncertainty-Financial-Stability]]는 부채 꼬리위험·금융취약성·시장여건 때문에 같은 정책이 모든 국가에서 같은 속도와 비용으로 시행될 수 없음을 상기시킨다. 즉, 후자는 전자를 반박하는 연구가 아니라 **국가별 적용의 여력·순서·완충장치**를 묻게 만드는 연구다.

|---:|---|---|---|
| 1 | 플래그십 진단 | 식별·미시 연구 | 평균·시나리오를 어떤 충격·집단·행동으로 분해할 수 있는가? |
| 2 | 기제·구조모형 | 다른 표본·국가·도구 연구 | 이 기제는 어디에서, 어떤 가정 아래, 어떤 정책수단과 함께 작동하는가? |
| 3 | 정책 수단 분석 | 제도·수용성·분배 연구 | 누가 비용을 부담하며, 집행·보상·신뢰의 조건은 무엇인가? |
| 4 | 성장·전환 시나리오 | 재정·금융안정 연구 | 부채·금융여건·시장구조가 적용 가능성을 어떻게 제한하는가? |
