# IMF WEO 2025-10 Ch. 3 — 산업정책의 성장·회복력 트레이드오프

이 장은 산업정책을 특정 기업·부문에 공적지원을 집중해 국내 경제구조를 바꾸려는 국가행위로 정의하고, 이론·실증·사례·다부문 무역모형을 함께 사용해 효과와 비용을 분석한다.[1] 최근 정책은 주로 직접지원과 보조금융융자 형태이며, 전략경쟁력·에너지안보·공급망 회복력이 주요 동기로 제시된다.[1]

| 핵심 결과 | 해석 |
|---|---|
| 규모수익·학습효과가 강한 유치산업에서는 생산·기술추격을 도울 수 있다.[1] | 효과는 기술격차·학습속도·시장규모·설계에 민감하다. |
| 최근 정책은 목표 부문의 성과개선과 연관되지만 평균 효과는 작고 다른 부문으로의 파급은 식별이 어렵다.[1] | 목표부문 성과가 전체 생산성 개선을 보장하지 않는다. |
| 자원 재배치로 비목표 고생산성 부문이 위축되면 총생산성이 낮아질 수 있다.[1] | 부문별 성과와 일반균형 효과를 구분해야 한다. |
| 보조금은 소비자가격·재정비용·정책기회비용을 수반할 수 있다.[1] | 재정공간·집행능력·시장규율·보완개혁이 필수 조건이다. |

원문은 산업정책을 일괄적으로 찬반하는 대신, 시장실패·목표설정·한시성·평가·재정투명성·경쟁과 구조개혁의 보완성을 따로 평가하라고 제시한다.[1] 에너지 부문의 경우 수입 화석연료 의존을 낮추는 효과와 비에너지 부문의 생산성 손실 가능성이 함께 존재한다.[1]
