# BIS AER 2021 Ch. III — CBDC와 통화체계

## 질문과 관점

BIS는 CBDC를 기술자산의 유행이 아니라, 디지털 경제에서 **중앙은행 화폐의 공공재적 기능**을 어떻게 구현할지에 관한 제도설계 문제로 다룬다.[1] 이 장에서 CBDC는 중앙은행의 직접 채무인 국가 단위 계정화폐 표시 디지털 지급수단이며, 결제최종성·유동성·무결성이라는 중앙은행 화폐의 속성을 디지털로 구현할 가능성을 갖는다.[1]

> 이 장의 핵심은 CBDC의 채택 여부 자체보다, 디지털 결제의 시장구조와 데이터 거버넌스가 접근성·경쟁·혁신을 선순환시키는지, 아니면 데이터 집중과 시장지배력을 강화하는지에 있다.[1]

| 항목 | 원문에서 확인한 내용 |
|---|---|
| 공공재 논리 | 중앙은행은 단위계산, 최종결제, 결제유동성, 결제시스템 감독·공정경쟁이라는 역할로 통화·결제의 신뢰 기반을 제공한다고 본다.[1] |
| 시장구조 | 빅테크의 데이터·네트워크·활동(DNA) 순환은 접근성·낮은 비용의 선순환 또는 데이터 사일로·시장집중의 악순환을 만들 수 있다.[1] |
| 설계 | 소매 CBDC는 현금처럼 일반 대중이 보유하는 중앙은행 직접청구권이고, 도매 CBDC는 금융기관 간 결제용이다.[1] |
| 데이터·프라이버시 | 계정 기반 CBDC는 디지털 ID와 결합할 수 있으며, 자금세탁 방지와 개인정보 보호의 설계적 균형이 중요하다.[1] |
| 국제결제 | 상호 운용 가능한 CBDC·ID·규칙을 통해 국경간 결제의 비용·속도·투명성을 개선할 수 있지만 국제협력이 필요하다.[1] |

## 핵심 독해

BIS는 암호자산과 스테이블코인을 기존 화폐의 대체물로 낙관적으로 보지 않는다. 이 장의 시점에서 암호자산은 투기자산 성격과 불법활동·에너지 문제를, 스테이블코인은 준비자산과 거버넌스에 대한 신뢰·유동성 분절의 문제를 지닌다고 평가한다.[1] 다만 이것은 2021년의 기관 보고서 관점이며, 이후 시장·규제 변화의 최신 평가로 사용해서는 안 된다.

소매 CBDC의 설계는 금융중개를 중앙은행이 모두 대신한다는 의미가 아니다. BIS가 제시하는 2계층 체계에서는 중앙은행이 최종 결제와 공공 인프라의 기반을 제공하고, 은행·비은행 지급서비스제공자(PSP)가 이용자 접점과 혁신을 담당한다.[1] 문제는 개방형 표준·API·상호운용성·사용자 데이터 통제가 결여될 때 네트워크 효과가 기존 대형 플랫폼의 지배력을 더 강화할 수 있다는 점이다.[1]

국제통화체계의 관점에서, 외국 CBDC가 디지털이라는 이유만으로 통화대체를 일으키는 것은 아니라는 논지가 중요하다. BIS는 실제 통화대체가 금융시장 깊이·개방성·통화가치 신뢰·제도 인프라에 좌우되며, 계정 기반 CBDC의 ID·접근 통제와 국내 법정통화 규칙, 국제협력은 위험을 제한할 수 있다고 설명한다.[1] 반대로 ID 상호인정·데이터보호·KYC 기준의 비호환성은 국경간 결제의 실질적 병목이 될 수 있다.[1]
