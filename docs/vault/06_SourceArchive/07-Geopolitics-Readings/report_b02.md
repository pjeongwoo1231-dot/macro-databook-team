## 검증 방식

인용문은 문서별 `[[page N]]` 구간에서 다시 대조했습니다. PDF 텍스트 추출 과정의 줄바꿈 하이픈(예: `pop-` 줄바꿈 `ulism`)은 논리적으로 같은 단어로 접합해 비교했지만, 원문에 없는 문구는 허용하지 않았습니다. 모든 인용은 정규화 후 40자 이상이며, 기록된 `quote_locator`와 대조된 물리 쪽이 일치합니다.

## 해석 유의사항

이 코퍼스는 기고·논평 성격의 매체입니다. 따라서 `claims[].type`은 글쓴이의 주장 성격을 분리한 것이며, 사실로 확정하거나 외부 자료로 검증한 결과는 아닙니다. 이슈 전체에는 다수의 기고자가 포함되므로 단일 `author`와 `author_affiliation`은 부여하지 않았고 `null`로 유지했습니다.
