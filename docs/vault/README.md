# 볼트 노트 사본 — 같이 공부하려고 둔다

`MacroVault`의 **연구 노트 1,197개**다. Obsidian Sync가 본선이고 이건 사본이다.
Sync 초대를 아직 못 받았거나 Obsidian을 안 쓰는 사람도 읽을 수 있게 두었다.

## 어디부터 읽나

| 먼저 | 무엇 |
|---|---|
| `03_MOC/시황 분석 진입점.md` | **판정 규칙 60여 개의 호출 목록.** 분석은 여기서 시작한다 |
| `03_MOC/좋은 시황의 규칙.md` | 주장 하나에 근거 셋(추세·사례·이론). 보고서와 볼트 노트를 나누는 기준 |
| `03_MOC/제텔 소환 인덱스.md` | §1이 **금지·제한 규칙**이다. 지표를 보는 순간 걸리는 제약 |
| `팀 안내 (먼저 읽기).md` | 볼트를 함께 쓰는 법 |

## 뺀 것과 그 이유

| 뺀 것 | 이유 |
|---|---|
| `06_SourceArchive/` (1,509) | 논문 PDF 색인. **저자 이메일 21개 파일**이 들어 있어 공개 저장소에 두지 않는다 |
| **PDF 210개 (261MB)** | 저작권 있는 논문 원문. 공개 배포 대상이 아니다 |
| `04_DataBook/` | 수집기가 매번 덮어쓰는 자동 생성물. `python -m databook run`이 만든다 |
| `.smart-env/` (545MB) | 임베딩 캐시. 각 기기에서 새로 만들어진다 |
| `_System/backup/` | 병합 전 백업. 원본이 볼트에 있다 |

**PDF가 필요하면 Obsidian Sync로 볼트를 받아야 한다.** 노트가 `[[파일명.pdf]]`로
거는 링크는 여기서는 열리지 않는다.

## 읽을 때 지킬 것

- **`verification` 프론트매터가 인용 가능 여부를 정한다.**
  수치·계수는 `full`만, 서술은 `partial` 이상, 그 밖은 "원문 미대조"를 병기한다.
- **수치를 인용할 땐 기준일을 함께 쓴다.** "중국 M2 9.0%"가 아니라 "9.0%(2026-02)".
- 같은 지표가 출처별로 값이 다를 수 있다. 어느 쪽인지 밝힌다.

## ⚠ 사본이라 갈라진다

원본은 볼트다. 여기서 고치면 볼트에 반영되지 않고, 볼트를 고치면 여기가 낡는다.
**노트를 고칠 일이 있으면 볼트에서 고친다.** 이 사본은 갱신 시점에 다시 복사한다.
