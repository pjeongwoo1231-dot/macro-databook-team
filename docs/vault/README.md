## 읽을 때 지킬 것

- **`verification` 프론트매터가 인용 가능 여부를 정한다.**
  수치·계수는 `full`만, 서술은 `partial` 이상, 그 밖은 "원문 미대조"를 병기한다.
- **수치를 인용할 땐 기준일을 함께 쓴다.** "중국 M2 9.0%"가 아니라 "9.0%(2026-02)".
- 같은 지표가 출처별로 값이 다를 수 있다. 어느 쪽인지 밝힌다.

## ⚠ 사본이라 갈라진다

원본은 볼트다. 여기서 고치면 볼트에 반영되지 않고, 볼트를 고치면 여기가 낡는다.
**노트를 고칠 일이 있으면 볼트에서 고친다.** 이 사본은 갱신 시점에 다시 복사한다.
(2026-08-31 복사)

## clone 이 무겁다

PDF 때문에 저장소가 약 290MB다. 노트만 필요하면:

```bash
git clone --filter=blob:none --sparse https://github.com/pjeongwoo1231-dot/macro-databook-team
cd macro-databook-team && git sparse-checkout set docs/vault databook docs/prompts
```
