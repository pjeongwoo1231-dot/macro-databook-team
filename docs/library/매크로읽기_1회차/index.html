매크로 경제 읽기 1회차
「경기와 물가」 독학판

발표용 47장 슬라이드를 혼자 읽어도 이해되는 4권짜리 자습서로 다시 썼다. 선배 애널리스트가 신입에게 설명하듯, 정의보다 왜를 먼저 말한다.

전 4권 총 학습시간 약 6시간 실물경제 진단 파트 (2회차는 정책·자산시장)

이 자료가 기존 슬라이드와 다른 점

  1. 4권 분할 — 한 권이 45~55페이지 분량이라 한 번에 완독 가능하다. 47장을 통으로 읽는 부담이 없다.
  2. 과외식 서술 — 정보 나열이 아니라 질문 → 개념 → 비유 → 함정 → 실전 순서로 설명한다.
  3. 함정을 지표와 세트로 — 모든 단원에 "신입이 틀리는 지점"이 붙어 있다. 실무에서 실제로 물리는 지점들이다.
  4. 리포트 해독 훈련 — 실제 리서치 문장을 한 줄씩 뜯는 블록이 각 권에 들어 있다.
  5. 셀프체크 40문항 — 권당 10문항. 답을 가린 채 먼저 떠올리고 확인하는 구조.

HOW TO USE

읽는 순서와 방법

순서대로 읽는 것을 전제로 설계했다. 뒤 권이 앞 권의 개념을 계속 불러 쓴다.

권장 학습 방법

  1. 1권씩, 한 번에 끝까지. 중간에 끊으면 사슬이 끊긴다. 권당 80~100분을 잡아라.
  2. "신입이 틀리는 지점" 블록은 두 번 읽어라. 시험에 나오는 게 아니라 실무 발표에서 물리는 지점이다.
  3. 셀프체크는 반드시 답을 먼저 떠올린 뒤 펼쳐라. 펼쳐서 읽기만 하면 아는 것 같은 착각만 남는다.
  4. FRED 코드는 실제로 한 번씩 쳐봐라. 부록의 코드를 fred.stlouisfed.org/series/[코드]에 넣으면 즉시 차트가 뜬다.
  5. 4부 7장의 결론 문장 템플릿을 매주 한 번 채워보는 것이 이 자료의 최종 목표다.
